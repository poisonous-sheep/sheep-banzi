# 线性基

**用途与条件：** GF(2)消元维护可达异或空间，支持最大值、可表示判定、第k小及最大权线性无关集。

**复杂度：** insert/exist/qur O(B)，kth O(B²)，空间O(B)，B=63。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `insert(x)`：独立时加入并返回true；相关时记录非空零组合
- `exist/qur(x)`：判可表示；在x基础上求最大异或
- `kth(k,nonempty)`：默认非空子集的1基第k小；nonempty=false则含空集且k为0基

[原题](https://www.luogu.com.cn/problem/P3812)

**题意：** 从给定整数中选任意子集，使异或和最大。

**为什么使用：** 所有子集异或构成向量空间，逐位贪心最大化。

**如何调用：** 逐个insert，输出qur()。

**复杂度：** O(nB)时间、O(B)空间。

### P4151 最大XOR和路径

[原题](https://www.luogu.com.cn/problem/P4151)

**题意：** 无向连通图求1到n的最大异或权路径，可重复边点。

**为什么使用：** 任意路径异或为一条树路径值加环空间组合；每条非树边产生环异或。

**如何调用：** DFS计算dis并insert(dis[u]^dis[v]^w)，最后qur(dis[n])。

**复杂度：** O((n+m)B)时间、O(n+m+B)空间。

### P4570 元素

[原题](https://www.luogu.com.cn/problem/P4570)

## 易错点

- 输入限制0<=x<2^63，位移用1ULL避免第63位符号溢出。
- 相关向量使0可由非空子集构成；空集与非空的排名含义必须分清。
- 第k小先消成低位无干扰的基，原按低位组合但未消元的写法不保证顺序。
