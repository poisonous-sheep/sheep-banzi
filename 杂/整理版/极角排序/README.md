# 极角排序

**用途与条件：** 按半平面再叉积排序非零向量，使圆周相邻关系和连续方向区间可枚举。

**复杂度：** O(n log n)排序时间、O(log n)排序辅助栈。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `run(a)/cmp`：从正x轴逆时针排序；同方向按长度排序

## 例题

### CF598C Nearest vectors

[原题](https://codeforces.com/contest/598/problem/C)

**题意：** 寻找最小夹角的一对非零向量。

**为什么使用：** 最小夹角一定来自极角序的相邻向量；包含首尾圆周相邻。

**如何调用：** 按cmp排序带原编号向量，逐对用atan2(abs(det),dot)取夹角。

**复杂度：** O(n log n)时间、O(n)空间。

### ABC139F Engines

[原题](https://atcoder.jp/contests/abc139/tasks/abc139_f)

**题意：** 选择若干向量，使和的长度最大。

**为什么使用：** 最优向量集合可取为沿某个方向点积非负的半平面；极角序中是连续区间。枚举所有圆周连续区间必覆盖最优。

**如何调用：** 过滤零向量，run排序，枚举起点并累加最多n个向量。

**复杂度：** O(n²+n log n)时间、O(n)空间。

## 易错点

- 零向量应预先过滤；对任意浮点数叉积仍有精度风险，整数大坐标用__int128。
- 圆周相邻还需考虑最后和第一个的跨0夹角。
