# 极角排序

**类型：** 思维型

**适用场景：** 按半平面再叉积排序非零向量，使圆周相邻关系和连续方向区间可枚举。

**复杂度与条件：** O(n log n)排序时间、O(log n)排序辅助栈。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 最小夹角必发生在圆周排序相邻方向。最优向量和S的选中向量投影到S方向非负、未选非正，因此可表示为一个半平面内连续方向段。

**状态与建模：** CF598C对带原编号的向量按半平面及叉积排序，比较相邻含首尾。ABC139F枚举排序后环形连续段，维护(sumx,sumy)和平方长度。

**优化与限制：** CF O(nlog n)，ABC n≤100，O(n^2)枚举适用；结果sqrt后用足够精度输出。叉积用__int128避免坐标乘法溢出。

## 例题 1：CF598C Nearest vectors

[原题](https://codeforces.com/contest/598/problem/C)

**题意：** 寻找最小夹角的一对非零向量。

**观察与规模：** 寻找最小夹角的一对非零向量。 最小夹角一定来自极角序的相邻向量；包含首尾圆周相邻。 一个模型求最近方向夹角，另一个求若干向量和长度最大；长度和的选择不是逐个取大向量。

**朴素思路：** 所有夹角点对O(n^2)；枚举向量子集2^n。

**关键突破：** 最小夹角必发生在圆周排序相邻方向。最优向量和S的选中向量投影到S方向非负、未选非正，因此可表示为一个半平面内连续方向段。

**状态与建模：** CF598C对带原编号的向量按半平面及叉积排序，比较相邻含首尾。ABC139F枚举排序后环形连续段，维护(sumx,sumy)和平方长度。

**本题映射：** 寻找最小夹角的一对非零向量。 最小夹角一定来自极角序的相邻向量；包含首尾圆周相邻。 按cmp排序带原编号向量，逐对用atan2(abs(det),dot)取夹角。

**转移与正确性：** CF非邻接两方向之间若夹了另一方向，则至少一个相邻间距更小。ABC若选中投影负向量，去掉使|S|增大；未选正投影向量加入也增大，故最优集合满足连续半平面结构，边界零投影可纳入枚举。

**初始化与顺序：** 方向排序必须区分上下半平面，叉积0再确定稳定顺序；环形复制或取模枚举。空集合长度0；零向量方向未定义，几何接口应单列或跳过。

**优化与限制：** CF O(nlog n)，ABC n≤100，O(n^2)枚举适用；结果sqrt后用足够精度输出。叉积用__int128避免坐标乘法溢出。

**本题复杂度：** O(n log n)时间、O(n)空间。

[完整函数题解](%E4%BE%8B%E9%A2%98/CF598C-Nearest%20vectors-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 先用交换/增删论证找出最优集合必须满足的方向条件，再考虑排序连续段；极角排序本身并没有解决子集最大化。

## 共同思路与易错点

- 零向量应预先过滤；对任意浮点数叉积仍有精度风险，整数大坐标用__int128。
- 圆周相邻还需考虑最后和第一个的跨0夹角。

共同启发：先用交换/增删论证找出最优集合必须满足的方向条件，再考虑排序连续段；极角排序本身并没有解决子集最大化。
