# 度数根号分治

**类型：** 混合型

**适用场景：** 小度点广播直接修改邻居，大度点广播记录时间戳；查询从相邻大点恢复最后一次颜色。

**复杂度与条件：** 预处理O(n+m)，每次O(B+m/B)，B约sqrt(m)；空间O(n+m)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `add_edge/build(a)`：静态无向图，a为1基初始颜色
- `qur(u)`：读取含懒广播影响的当前颜色
- `change(u,c,self)`：向所有邻居广播c；self=true也更新自己

## 例题 1：ABC219G Propagation

[原题](https://atcoder.jp/contests/abc219/tasks/abc219_g)

**题意：** 查询点将自身数字复制给所有邻居，最终输出所有点数字。

**观察与规模：** 查询点将自身数字复制给所有邻居，最终输出所有点数字。 高次数邻居更新用重度懒广播规避星形图退化。 图中向全部邻居传播颜色的操作，扫描高出度顶点很贵。

**朴素思路：** 每次传播遍历邻居最坏O(qm)；给所有边维护全套历史也浪费。

**关键突破：** 高出度点个数≤2m/B，可以延迟存广播；低出度点直接更新邻居。

**状态与建模：** val\[u\]/time\[u\]是已直接收到的最新信息；tag\[h\]/stamp\[h\]是重邻居最后一次广播。heavy_neighbors\[u\]仅列出u的重邻居。

**本题映射：** 查询点将自身数字复制给所有邻居，最终输出所有点数字。 高次数邻居更新用重度懒广播规避星形图退化。 build初始col\[i\]=i；每次x先qur(x)，再change(x,c,false)。

**转移与正确性：** 读u前比较自身时间和全部重邻居广播时间，取最新者。轻点传播直接写邻居，重点传播仅改tag；时间戳的最大值确保多次覆盖等价原操作顺序。

**初始化与顺序：** 先按度标重并建重邻居表；初始时间0，每操作递增时间。传播前必须refresh(u)，否则可能广播已过期颜色。

**优化与限制：** O(m+q(B+m/B))及邻接存储，阈值约sqrt(m)。Typical90-083自己和邻居都改为给定颜色；ABC219G以当前u颜色传邻居，操作语义不同，读取/更新顺序照原题。

**本题复杂度：** O(n+m+q sqrt m)时间、O(n+m)空间。

## 共同思路与易错点

- qur必须先于广播读取当前颜色，懒标记比较时间戳。
- 建图后build一次，动态增边不适用。
- 大点只有O(m/B)个，因此查询扫描的大点邻居有上界。

共同启发：延迟处理不仅需要lazy值，还要能比较多个来源的新旧；时间戳让覆盖操作满足最后写入胜出。
