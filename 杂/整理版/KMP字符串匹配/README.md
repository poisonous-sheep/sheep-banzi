# KMP字符串匹配

**用途与条件：** 前缀函数失配跳转在线性时间查找全部匹配；数字序列与字符串共用接口。

**复杂度：** O(n+m)时间、O(m+匹配数)空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(pattern)`：建立模式前缀函数nxt，0基数组
- `find(text)`：返回全部1基匹配起点，支持重叠匹配

## 例题

### P3375 KMP

[原题](https://www.luogu.com.cn/problem/P3375)

**题意：** 输出模式串所有出现位置及每个前缀的最长border。

**为什么使用：** 重复扫描通过前缀函数复用已知匹配长度。

**如何调用：** init(s2)，find(s1)，依次输出nxt。

**复杂度：** O(|s1|+|s2|)时间、O(|s2|+匹配数)空间。

### CF471D MUH and Cube Walls

[原题](https://codeforces.com/contest/471/problem/D)

**题意：** 允许整体上下平移，统计目标高度序列出现次数。

**为什么使用：** 两序列可整体平移等价相邻差相同，转成整数序列匹配。

**如何调用：** w=1直接答n；否则差分后init和find。

**复杂度：** O(n+w)时间与O(n+w)空间。

## 易错点

- 匹配后回退到nxt[m-1]，不能直接置0，否则漏重叠。
- 空模式按接口定义匹配n+1个边界；实际竞赛例题模式非空。
- 差分会出现负数，不能用char保存数字模式。
