# 步长根号分治

**类型：** 混合型

**适用场景：** 小步长预维护/预处理，大步长暴力跳跃；收录动态模下标和与静态跳跃两个模型。

**复杂度与条件：** 动态修改O(B)、查询O(1)或O(n/B)，空间O(n+B²)；跳跃预处理O(nB)、空间O(nB)，B约sqrt(n)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `change/qur`：动态单点加与下标模k等于r求和
- `build_jump/jump_count`：静态正数数组跳到p+a[p]+k，求越界前次数

## 例题 1：CF1207F Remainder Problem

[原题](https://codeforces.com/problemset/problem/1207/F)

**题意：** 单点增加，查询所有下标模x等于y的位置和。

**观察与规模：** 单点增加，查询所有下标模x等于y的位置和。 小模数一次修改影响B个桶，大模数查询最多n/B个位置。 查询涉及步长b：小步长覆盖点多但种类少，大步长种类多却路径短。

**朴素思路：** 每次沿等差位置遍历最多O(n)，或为所有b预处理O(n^2)。

**关键突破：** 用阈值B把“值小可预处理”和“值大可直接枚举”合起来，平衡n/B与B。

**状态与建模：** CF1207F对小b维护各余数类之和，更新x时改所有b≤B的sum\[b\]\[x%b\]。CF797E dp\[k\]\[p\]是从p反复跳p+a\[p\]+k到越界的步数。

**本题映射：** 单点增加，查询所有下标模x等于y的位置和。 小模数一次修改影响B个桶，大模数查询最多n/B个位置。 init(500000)，操作1用change，操作2用qur。

**转移与正确性：** CF1207F大b查询直接遍历余数类；小b直接读表。CF797E小k倒序dp=1+dp\[next\]，因a\[p\],k正故next>p；大k每步前进至少k，枚举次数≤n/k。

**初始化与顺序：** 更新前所有表0；离线数组跳跃先读固定a，再预计算小k；越界dp=0。余数类是否含位置0由真实下标条件处理。

**优化与限制：** B约sqrt(n)，更新/询问O(B+n/B)或预处理O(nB)，空间O(B^2)或O(nB)。CF797E允许改a则预处理失效。

**本题复杂度：** O(q sqrt N)时间、O(N)空间。

## 共同思路与易错点

- 跳跃版必须a[i]>0，才能保证预处理依赖右侧与大步长次数界。
- 两个模型独立使用同一对象，不要build_jump后再用动态tag。
- jump计数存int32_t避免long long宏把nB内存翻倍。

共同启发：分治阈值由两种代价公式平衡，不能只背sqrt(n)；明确哪部分是参数种类少、哪部分是操作次数少。
