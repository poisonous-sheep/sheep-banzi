# 并查集

**类型：** 模板型

**适用场景：** 动态合并连通块，查询连通性与大小；编号0..n均可用。

**复杂度与条件：** 初始化O(n)，按大小合并与路径压缩均摊O(alpha(n))，空间O(n)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `root(x)`：沿用原名，压缩路径
- `merge(x,y)`：返回是否成功合并
- `same(x,y)`：判断同一连通块
- `size(x)`：连通块大小
