# 并查集

**用途与条件：** 动态合并连通块，查询连通性与大小；编号0..n均可用。

**复杂度：** 初始化O(n)，按大小合并与路径压缩均摊O(alpha(n))，空间O(n)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `root(x)`：沿用原名，压缩路径
- `merge(x,y)`：返回是否成功合并
- `same(x,y)`：判断同一连通块
- `size(x)`：连通块大小

## 例题

### practice2_a Disjoint Set Union

[原题](https://atcoder.jp/contests/practice2/tasks/practice2_a)

**题意：** 加无向边或询问两点是否连通。

**为什么使用：** 加边只会合并连通块，适用普通DSU。

**如何调用：** 0操作merge，1操作same；题目点号0-based。

**复杂度：** O((n+q)alpha(n))时间、O(n)空间。

### ABC120D Decayed Bridges

[原题](https://atcoder.jp/contests/abc120/tasks/abc120_d)

**题意：** 按顺序删桥，输出每次删除后的不连通点对数。

**为什么使用：** 逆序变成加边；合并大小a,b的块减少a*b对。

**如何调用：** 从空图开始，先记答案，读取size后merge。

**复杂度：** O((n+m)alpha(n))时间、O(n+m)空间。

## 易错点

- 不支持删除边；删除类题优先考虑倒序离线。
- 若需要回滚，应另用不压缩路径的变体。
