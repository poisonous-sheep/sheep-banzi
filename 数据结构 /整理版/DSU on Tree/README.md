# DSU on Tree

**类型：** 混合型

**适用场景：** 轻子树算完清空、重子树保留，以单一统计容器回答所有子树询问。

**复杂度与条件：** O(n log n)次增删；总时间再乘增删与询问成本；O(n)树结构空间。

[完整C++17板子](模板.cpp)。

## 核心接口

- `add_edge`：加入无向树边
- `run(change,answer,root)`：change(u,+1/-1)增删，answer(u)读取完整子树状态

## 例题 1：CF600E Lomsat gelral

[原题](https://codeforces.com/problemset/problem/600/E)

**题意：** 求子树众数颜色编号和。

**观察与规模：** 求子树众数颜色编号和。 DSU保留重子树，颜色增删同时更新每个频率的颜色和与种类数。 子树询问具有可插入/删除的频率统计，重儿子可复用；CF375D还要问频率至少k。

**朴素思路：** 每个节点清空并扫描子树O(n^2)。普通map小并大有额外log开销。

**关键突破：** 保留重子树计数，轻子树完成答案后清理；最后统一加入轻子树和当前点。

**状态与建模：** cnt\[color\]是当前保留集合的颜色频次；sum/mx记录众数信息。ge\[k\]是当前出现次数≥k的颜色数，频次从f到f+1仅使ge\[f+1\]加1。

**本题映射：** 求子树众数颜色编号和。 DSU保留重子树，颜色增删同时更新每个频率的颜色和与种类数。 change维护cnt、freqSum、freqCount及mx；answer读freqSum\[mx\]。

**转移与正确性：** 轻孩子keep=false，重孩子keep=true；add轻侧时跳过重子树，只增需要新进入的元素。读出答案后若本节点不保留，则删除整个子树。重链贡献不被反复扫描。

**初始化与顺序：** 先dfs1求siz/heavy和Euler序，再dfs2统计；空计数重置mx/sum，删除时正确维护频次统计。CF600E输出众数编号和，CF375D取ge\[k\]。

**优化与限制：** 每点经过轻边数量O(log n)，总O(nlog n)，计数O(1)时优于map。删改后的最大频率维护依赖当前实现整体清理，不可随意改为任意在线删除。

**本题复杂度：** O(n log n)时间、O(n+颜色值域)空间。

## 共同思路与易错点

- 移除必须与加入完全互逆；原“直接清零”仅限清空整个容器的特定统计，不适合通用回调。
- run最终清空统计；多次运行须初始化外部答案和桶。
- 递归深度O(n)，链树可能需要较大栈。

共同启发：先找可增删的答案统计，再应用重轻复用；遍历顺序是正确性的一部分，不是无条件替换树形DP。
