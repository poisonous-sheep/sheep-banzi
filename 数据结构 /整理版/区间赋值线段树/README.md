# 区间赋值线段树（区间覆盖）

**类型：** 模板型（C++17，1-based，闭区间）。

**用途：** 区间全部赋值为指定数字、区间求和、区间最大值、单点赋值。支持负数、赋值为 0、重复覆盖。

**复杂度：** `build` 为 O(n)，`modify/change/qur` 为 O(log n)，空间 O(n)。

[完整 C++17 板子](模板.cpp)（可独立编译；`solve()` 为自定义操作演示）。

## API 速查

| 调用 | 含义 |
| --- | --- |
| `seg.build(a)` | 用 1-based 数组 `a[1..n]` 建树 |
| `seg.modify(l, r, {1, k})` | 将闭区间 `[l,r]` **全部赋值**为 `k` |
| `seg.change(pos, val)` | 单点赋值 |
| `seg.qur(l, r).sum` | 闭区间和 |
| `seg.qur(l, r).mx` | 闭区间最大值 |
| `seg.qur(l, r).len` | 查询区间长度 |

## 核心设计

- 个人模板风格：`struct SegTree { struct info; struct tag; struct node; }`，用 `operator+` 合并子节点。
- `info{sum,len,mx}`：`update` 合并时，区间和相加、长度相加、最大值取 `max`。
- `tag{is,change}`：`is=1` 表示当前区间有待下传的赋值，`change` 是赋值目标。
- `settag(id,{1,k})`：直接令 `sum=k*len`、`mx=k`，并用新标记**覆盖**原标记。
- `pushdown`：仅当 `is=1` 时覆盖两个子节点，之后清空父节点标记。
- **`info qur()` 不使用 `res`**：完全落在左边、完全落在右边、跨过中点三种情况分别返回。这使全负数时的最大值查询也正确。

## 易错点

1. 调用区间覆盖一定写 `seg.modify(l,r,{1,k})`，不能写成 `{k}`（那会填到 `is` 字段）。
2. 赋值为 `0` 是合法操作，必须用 `tag.is` 判断是否下传，不能用 `tag.change != 0`。
3. 单点赋值时必须同时更新叶子 `sum`、`mx`，并清除叶子懒标记。
4. 查询只在有效非空区间合并两个真实节点；如果调用 `qur(l,r)` 且 `l>r`，返回 `len=0` 的空 `info`，此时**不要读取 `mx`**。
5. 多次赋值采用后一次覆盖前一次；这与区间加懒标记的累加完全不同。
6. 需确保 `k*len` 及区间和不会溢出 `long long`。

## 演示输入输出

`solve()` 支持三类自定义指令：`1 l r k` 区间赋值，`2 l r` 查询区间和，`3 l r` 查询区间最大值。移植到具体 OJ 题目时，请按实际操作格式修改 `solve()`。

输入：

```text
5 9
-5 -3 -7 -9 -2
3 1 5
1 2 4 0
2 1 5
3 2 4
1 1 5 -6
2 1 5
3 1 5
1 3 3 8
3 1 5
```

输出：

```text
-2
-7
0
-30
-6
8
```

**验证：** C++17 编译通过；200 组随机生成的区间覆盖 / 区间和 / 区间最大值操作与暴力数组结果一致；未在线提交原题。
