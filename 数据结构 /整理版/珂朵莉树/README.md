# 珂朵莉树

**类型：** 模板型

**适用场景：** 用 set 保存分段常数区间；区间赋值使区间数减少，支持逐段操作。

**复杂度与条件：** 每次 O(log n+s)，s 为访问区间数；第k小另需 O(s log s)。最坏 O(nq)，空间 O(n)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `init(n,v)`：建立全值v的1..n区间
- `split(x)`：在x处分割；n+1返回end
- `assign/add(l,r,v)`：闭区间赋值或增加
- `kth/qur`：第k小、幂次和模p

## 共同思路与易错点

- 必须先 split(r+1) 再 split(l)，否则旧迭代器可能失效。
- 随机数据下常用，不保证普通对抗数据的高效；P3740只有覆盖操作可另用线段树。
- k必须在区间长度内，p>0；拆分不自动合并相邻等值段。
