# 对顶堆与中位数

**用途与条件：** 动态插入删除，查询下中位数与到中位数的绝对值和；允许重复。

**复杂度：** 增删O(log n)，mid/cost为O(1)，空间O(n)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `add(x)`：加入一个值
- `del(x)`：删除一个已存在的值
- `mid()`：非空集合下中位数
- `cost()`：最小绝对偏差和，空集为0

## 例题

### ABC127F Absolute Minima

[原题](https://atcoder.jp/contests/abc127/tasks/abc127_f)

**题意：** 不断加入|x-a|+b，查询使函数最小的最小x及最小值。

**为什么使用：** 最小x是下中位数；常数b单独累加。

**如何调用：** add(a)，查询mid()和cost()+常数和。

**复杂度：** O(q log q)时间、O(q)空间。

### P1168 中位数

[原题](https://www.luogu.com.cn/problem/P1168)

**题意：** 依次读入整数，对每个奇数长度前缀输出中位数。

**为什么使用：** 插入后保持两个集合的大小与顺序，中位数直接取L最大值。

**如何调用：** 逐个add，奇数次插入后输出mid()。

**复杂度：** O(n log n)时间、O(n)空间。

### LeetCode480 滑动窗口中位数

[原题](https://leetcode.cn/problems/sliding-window-median/description/)

## 易错点

- L大小等于R或多1，且max(L)<=min(R)。
- 和与代价不得溢出；删除只删除一个重复值。
