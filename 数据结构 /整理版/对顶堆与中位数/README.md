# 对顶堆与中位数

**类型：** 模板型

**适用场景：** 动态插入删除，查询下中位数与到中位数的绝对值和；允许重复。

**复杂度与条件：** 增删O(log n)，mid/cost为O(1)，空间O(n)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `add(x)`：加入一个值
- `del(x)`：删除一个已存在的值
- `mid()`：非空集合下中位数
- `cost()`：最小绝对偏差和，空集为0

## 共同思路与易错点

- L大小等于R或多1，且max(L)<=min(R)。
- 和与代价不得溢出；删除只删除一个重复值。
