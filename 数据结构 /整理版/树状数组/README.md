# 树状数组

**类型：** 模板型

**适用场景：** 单点加、前缀和、区间和；非负频率时支持前缀排名二分。

**复杂度与条件：** 初始化O(n)，修改/查询/select为O(log n)，空间O(n)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `add(x,v)`：下标1..n；禁止x=0
- `sum(x)`：前缀[1,x]，sum(0)=0
- `rangeSum(l,r)`：闭区间和
- `select(k)`：最后一个前缀和<=k的下标；第k小可用select(k-1)+1

## 例题 3：P1966 火柴排队

[原题](https://www.luogu.com.cn/problem/P1966)

**题意：** 两列高度互异的火柴，可相邻交换，先最小化平方距离，再求最少交换数。

**观察与建模：** 同秩配对最小化平方差；把第一列每个秩映射到第二列对应位置，最少相邻交换就是该位置排列逆序数。

**初始化、数据组织、接口与答案：** 排序两列(value,index)，构造位置排列，用BIT频率统计先前更大元素，结果模100000000-3。

**本题复杂度：** O(n log n)时间/O(n)空间。
