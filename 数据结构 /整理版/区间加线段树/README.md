# 区间加线段树

**类型：** 模板型

**适用场景：** 闭区间加、区间和、单点赋值；1-based。

**复杂度与条件：** 建树O(n)，修改/查询O(log n)，空间O(n)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `modify(l,r,{x})`：区间加x
- `change(pos,val)`：赋值前下放标记
- `qur(l,r)`：区间和
