# 区间加线段树

**用途与条件：** 闭区间加、区间和、单点赋值；1-based。

**复杂度：** 建树O(n)，修改/查询O(log n)，空间O(n)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `modify(l,r,{x})`：区间加x
- `change(pos,val)`：赋值前下放标记
- `qur(l,r)`：区间和

[原题](https://www.luogu.com.cn/problem/P3372)

**题意：** 区间加和区间求和。

**如何调用：** build后将1操作映射modify，2操作映射qur。
