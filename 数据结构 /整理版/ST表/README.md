# ST表

**类型：** 模板型

**适用场景：** 静态区间最小值与最大值；重叠两段要求合并幂等。

**复杂度与条件：** 建表O(n log n)，查询O(1)，空间O(n log n)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `build(a)`：1-based数组；按实际n动态分配
- `qur(l,r)`：闭区间，返回mn/mx
