# ST表

**用途与条件：** 静态区间最小值与最大值；重叠两段要求合并幂等。

**复杂度：** 建表O(n log n)，查询O(1)，空间O(n log n)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `build(a)`：1-based数组；按实际n动态分配
- `qur(l,r)`：闭区间，返回mn/mx
