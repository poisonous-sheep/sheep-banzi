# 普通线段树

**用途与条件：** 单点赋值、区间最小值；数组1-based，查询为闭区间。

**复杂度：** 建树O(n)，修改/查询O(log n)，空间O(n)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `build(a)`：a[1..n]建树
- `change(pos,val)`：单点赋值
- `qur(l,r).mn`：闭区间最小值

[原题](https://www.luogu.com.cn/problem/P1816)

**如何调用：** build(a)，每个区间qur(l,r).mn。

### P1198 最大数

[原题](https://www.luogu.com.cn/problem/P1198)

**题意：** 在线追加数，查询末尾L个数的最大值；追加依赖上次答案。

**为什么使用：** 把追加视为预留数组上的单点赋值，查询变为后缀区间最大值。

**如何调用：** 预留M个位置build；change(++len,x)，qur(len-L+1,len)。

**复杂度：** O(M log M)时间、O(M)空间。

**变体：** 只将info的min合并改为max；成员mn沿用原名表示最大值。

原：`return {min(l.mn, r.mn)};`；改为：`return {max(l.mn, r.mn)};`。

## 易错点

- n必须为正；不支持懒标记。
- 自定义info必须满足结合律；保留合并左右顺序。
