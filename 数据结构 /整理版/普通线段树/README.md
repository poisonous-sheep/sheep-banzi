# 普通线段树

**类型：** 模板型

**适用场景：** 单点赋值、区间最小值；数组1-based，查询为闭区间。

**复杂度与条件：** 建树O(n)，修改/查询O(log n)，空间O(n)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `build(a)`：a[1..n]建树
- `change(pos,val)`：单点赋值
- `qur(l,r).mn`：闭区间最小值

## 例题 2：P1198 最大数

[原题](https://www.luogu.com.cn/problem/P1198)

**题意：** 在线追加数，查询末尾L个数的最大值；追加依赖上次答案。

**观察与建模：** 把追加视为预留数组上的单点赋值，查询变为后缀区间最大值。

**初始化、数据组织、接口与答案：** 预留M个位置build；change(++len,x)，qur(len-L+1,len)。

**特殊修改：** 只将info的min合并改为max；成员mn沿用原名表示最大值。

**本题复杂度：** O(M log M)时间、O(M)空间。
