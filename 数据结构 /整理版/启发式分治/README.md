# 启发式分治

**用途与条件：** 允许划分不均衡，但寻找分界或统计只扫描短侧；保留双端唯一元素判定，增加最大值分界的短侧枚举。

**复杂度：** non_boring O(n log n)时间/O(n)空间；maximum_pairs O(n log n)时间/空间（ST预处理）。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(a)`：1基数组
- `non_boring()`：每个非空子区间都有唯一出现元素
- `maximum_pairs()`：a必须为1..n排列；计数ai+aj=max(a[i..j])

## 例题

### UVA1608 Non-boring sequences

[原题](https://onlinejudge.org/external/16/1608.pdf)

**题意：** 判定任意子区间是否都有只出现一次的值。

**为什么使用：** 选当前区间唯一值为分界，含分界的所有区间已合法，只递归左右。

**如何调用：** init后non_boring，多测输出non-boring或boring。

**复杂度：** O(n log n)时间、O(n)空间。

## 易错点

- 从单侧扫描唯一元素会退化为O(n²)。
- 枚举短侧并用值到位置映射查另一端，不能同时暴力枚举两侧。
- 递归可能是链，深度O(n)，栈风险与时间复杂度是两回事。
