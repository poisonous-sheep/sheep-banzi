# 启发式分治

**类型：** 思维型

**适用场景：** 允许划分不均衡，但寻找分界或统计只扫描短侧；保留双端唯一元素判定，增加最大值分界的短侧枚举。

**复杂度与条件：** non_boring O(n log n)时间/O(n)空间；maximum_pairs O(n log n)时间/空间（ST预处理）。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** Non-boring从两端同时找区间唯一值；Special Segments以最大值分界，跨界仅枚举短側并用值反查位置。

**状态与建模：** pre/nxt判断某元素在当前区间唯一：pre\[i\]<l且nxt\[i\]>r。排列题pos\[value\]给唯一位置，ST提供当前区间argmax。

**优化与限制：** 短侧元素每次被扫描后所属区间至少减半，总O(nlog n)；ST占O(nlog n)，递归仍可能深O(n)而导致栈RE。非排列有重复值时pos唯一性证明失效。

## 例题 1：UVA1608 Non-boring sequences

[原题](https://onlinejudge.org/external/16/1608.pdf)

**题意：** 判定任意子区间是否都有只出现一次的值。

**观察与规模：** 判定任意子区间是否都有只出现一次的值。 选当前区间唯一值为分界，含分界的所有区间已合法，只递归左右。 分界未必均衡；如果每层只扫描短侧，仍可控制总工作。

**朴素思路：** 从左到右找分界在极端数组每次扫描大段，退化O(n^2)。区间最大值跨段对双枚举也会平方。

**关键突破：** Non-boring从两端同时找区间唯一值；Special Segments以最大值分界，跨界仅枚举短側并用值反查位置。

**状态与建模：** pre/nxt判断某元素在当前区间唯一：pre\[i\]<l且nxt\[i\]>r。排列题pos\[value\]给唯一位置，ST提供当前区间argmax。

**本题映射：** 判定任意子区间是否都有只出现一次的值。 选当前区间唯一值为分界，含分界的所有区间已合法，只递归左右。 init后non_boring，多测输出non-boring或boring。

**转移与正确性：** 若找到唯一元素，其覆盖的全部含它区间合法，只递归两侧；若没有，则当前区间已是反例。排列以最大值m分界，跨界端点满足另一值=a\[m\]-已知值，只需检查其pos是否落另一侧。

**初始化与顺序：** pre初0、nxt初n+1；空区间Non-boring合法，单点排列贡献0。递归扫描双端，分界后递归，不需改成手写栈。

**优化与限制：** 短侧元素每次被扫描后所属区间至少减半，总O(nlog n)；ST占O(nlog n)，递归仍可能深O(n)而导致栈RE。非排列有重复值时pos唯一性证明失效。

**本题复杂度：** O(n log n)时间、O(n)空间。

## 共同思路与易错点

- 从单侧扫描唯一元素会退化为O(n²)。
- 枚举短侧并用值到位置映射查另一端，不能同时暴力枚举两侧。
- 递归可能是链，深度O(n)，栈风险与时间复杂度是两回事。

共同启发：时间与递归深度分别证明：短侧代价可控不代表栈浅。出现不均衡分治应问能否把代价只记在小的一侧。
