# 动态开点权值线段树

**类型：** 模板型

**适用场景：** 值域可重集合增删、区间次数、第k小/大；支持负值域。

**复杂度与条件：** 操作O(1+log V)，空间O(1+D log V)，删除不回收节点。

[完整C++17板子](模板.cpp)。

## 核心接口

- `init(L,R)`：清空旧树
- `change(x,{c})`：修改出现次数
- `qur(l,r).cnt`：值域闭区间次数
- `kth(k)/kth_max(k)`：1-based排名，非法返回-1
