# 动态开点权值线段树

**用途与条件：** 值域可重集合增删、区间次数、第k小/大；支持负值域。

**复杂度：** 操作O(1+log V)，空间O(1+D log V)，删除不回收节点。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(L,R)`：清空旧树
- `change(x,{c})`：修改出现次数
- `qur(l,r).cnt`：值域闭区间次数
- `kth(k)/kth_max(k)`：1-based排名，非法返回-1

## 例题

### ABC253C Max-Min Query

[原题](https://atcoder.jp/contests/abc253/tasks/abc253_c)

**题意：** 增删元素，查询最大值与最小值之差。

**为什么使用：** 次数叶子可批量删除，最值是排名端点。

**如何调用：** 先查次数再change；kth(1)、kth_max(1)。

**复杂度：** O(Q log V)时间、O(D log V)空间。

### ABC241D Sequence Query

[原题](https://atcoder.jp/contests/abc241/tasks/abc241_d)

**题意：** 查询<=x的第k大或>=x的第k小。

**为什么使用：** 离散化1e18值域，将限制排名映射到全局排名。

## 易错点

- 删除前保证足够数量。
- -1可能是合法值，先验证排名。
- 中点使用__int128；节点编号32位，计数64位。
