# 01Trie

**类型：** 模板型

**适用场景：** 非负整数的动态可重集合与最大异或查询；最高位B<=62。

**复杂度与条件：** 增删/查询O(B)，空间O(D*B)，删除不回收节点。

[完整C++17板子](模板.cpp)。

## 核心接口

- `update(x)`：插入
- `eras(x)`：删除一个值，不存在时返回false且不修改状态
- `qur(x)`：最大x xor y

## 例题 2：P4551 最长异或路径

[原题](https://www.luogu.com.cn/problem/P4551)

**题意：** 树上找边权异或最大的路径。

**观察与建模：** 两点路径异或等于根到两点的前缀异或之xor，将所有前缀放入Trie。

**初始化、数据组织、接口与答案：** DFS计算前缀；update每个前缀，再qur求最大。

**本题复杂度：** O(nB)时间、O(nB)空间。
