# 01Trie

**用途与条件：** 非负整数的动态可重集合与最大异或查询；最高位B<=62。

**复杂度：** 增删/查询O(B)，空间O(D*B)，删除不回收节点。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `update(x)`：插入
- `eras(x)`：删除一个值，不存在时返回false且不修改状态
- `qur(x)`：最大x xor y

## 例题

### CF706D Vasiliy’s Multiset

[原题](https://codeforces.com/problemset/problem/706/D)

**题意：** 初始有0的集合，支持增删和最大异或。

**为什么使用：** Trie逐位优先走相反位，贪心取得最大异或值。

**如何调用：** init，update(0)；+用update，-用eras，?用qur。

**复杂度：** O(qB)时间、O(qB)空间。

### P4551 最长异或路径

[原题](https://www.luogu.com.cn/problem/P4551)

**题意：** 树上找边权异或最大的路径。

**为什么使用：** 两点路径异或等于根到两点的前缀异或之xor，将所有前缀放入Trie。

**如何调用：** DFS计算前缀；update每个前缀，再qur求最大。

**复杂度：** O(nB)时间、O(nB)空间。
