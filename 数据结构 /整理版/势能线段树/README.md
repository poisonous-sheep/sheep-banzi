# 势能线段树

**类型：** 模板型

**适用场景：** 非负数组区间开方、区间取模、单点赋值和区间和；用mx跳过不变节点。

**复杂度与条件：** 开方每值只改变O(log log A)次；取模有效改变使值至少减半，累计O((n+m)log A log n)；查询O(log n)，空间O(n)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `update_sqrt(l,r)`：向下取整开方
- `modify_mod(l,r,x)`：x>0，区间取模
- `change(p,x)`：非负赋值
- `qur(l,r).sum`：区间和
