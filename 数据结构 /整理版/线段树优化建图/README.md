# 线段树优化建图

**用途与条件：** 点到区间、区间到点建有向边；两棵树方向相反，原点共享叶子。

**复杂度：** 建图O(n+q log n)，非负最短路O((n+q log n)log(n+q))，空间O(n+q log n)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `add_edge(u,v,w)`：普通边，允许新增辅助点
- `add_out(v,l,r,w)`：点到区间
- `add_in(l,r,v,w)`：区间到点
- `dijkstra(s)`：非负边权，返回距离

## 例题

### CF786B Legacy

[原题](https://codeforces.com/problemset/problem/786/B)

**题意：** 三类点/区间边，求源点到所有原点的距离。

**为什么使用：** 每个区间拆成O(log n)个树节点，保持原图可达与代价。

**如何调用：** 按op1/2/3调用add_edge/add_out/add_in，dijkstra只输出原点。

**复杂度：** O((n+q log n)log n)时间、O(n+q log n)空间。

### P6348 Journeys

[原题](https://www.luogu.com.cn/problem/P6348)

**题意：** 区间间建立双向通信线路，求起点到各站的最少线路数。

**为什么使用：** 区间到辅助点0，辅助点到另一段1；反向另建辅助点。

**如何调用：** 每条线路新增两个点，add_in与add_out组合；Dijkstra求代价。

**复杂度：** O((n+m log n)log(n+m))时间、O(n+m log n)空间。

## 易错点

- 不能把in/out两棵树方向反写。
- INF需大于可达最短路，d+w不溢出。
- 辅助点需要先++tot，add_edge动态扩容。
