# 线段树优化建图

**类型：** 混合型

**适用场景：** 点到区间、区间到点建有向边；两棵树方向相反，原点共享叶子。

**复杂度与条件：** 建图O(n+q log n)，非负最短路O((n+q log n)log(n+q))，空间O(n+q log n)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `add_edge(u,v,w)`：普通边，允许新增辅助点
- `add_out(v,l,r,w)`：点到区间
- `add_in(l,r,v,w)`：区间到点
- `dijkstra(s)`：非负边权，返回距离

## 例题 1：CF786B Legacy

[原题](https://codeforces.com/problemset/problem/786/B)

**题意：** 三类点/区间边，求源点到所有原点的距离。

**观察与规模：** 三类点/区间边，求源点到所有原点的距离。 每个区间拆成O(log n)个树节点，保持原图可达与代价。 单点到区间/区间到单点的边大量出现，朴素真实边数可达nq。

**朴素思路：** 把每条区间边展开成所有端点后，最短路时间和内存随nq增长。

**关键突破：** 区间只需拆成O(log n)个线段树节点，节点之间用0费边表达包含关系。

**状态与建模：** 建立入树和出树：入树孩子到父亲，出树父亲到孩子；叶子与真实点连0边。区间到点从入树节点出边，点到区间向出树节点入边。

**本题映射：** 三类点/区间边，求源点到所有原点的距离。 每个区间拆成O(log n)个树节点，保持原图可达与代价。 按op1/2/3调用add_edge/add_out/add_in，dijkstra只输出原点。

**转移与正确性：** 区间边费用只在实际查询边付一次；其他0边选择区间中的真实端点。两棵树方向相反防止普通节点通过同一树无条件跳到别点。

**初始化与顺序：** 先init/build建立节点编号；读操作后add单边或区间边；最后以真实起点跑Dijkstra，未到达输出-1。所有新增边要求非负权。

**优化与限制：** O(n+qlog n)节点/边规模，Dijkstra再乘堆log。P6348区间到区间用中间点桥接两方向，避免两区间节点笛卡尔积；不要在两段桥接边上重复付1。

**本题复杂度：** O((n+q log n)log n)时间、O(n+q log n)空间。
