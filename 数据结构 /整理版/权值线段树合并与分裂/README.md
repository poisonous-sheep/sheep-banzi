# 权值线段树合并与分裂

**类型：** 模板型

**适用场景：** 同值域多棵可重集合树；破坏性合并、分裂出最大的k个。

**复杂度与条件：** 插入/排名/分裂O(log V)，合并O(实际同时非空访问节点数)；空间O(累计新建节点)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `change(root,pos,c)`：返回新根，必须接收
- `merge(x,y)`：返回合并根，旧y不能继续独立使用
- `split(root,k)`：返回{剩余,最大的k个}
- `kth(root,k)`：原接口第k大，非法返回-1

## 共同思路与易错点

- 根之间不能共享节点；merge(x,x)非法。
- 第k小要转换为第size-k+1大。
- 按值域分裂由两次排名分裂实现；移走树之后及时清空旧根。
