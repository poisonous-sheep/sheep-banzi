# 权值线段树合并与分裂

**用途与条件：** 同值域多棵可重集合树；破坏性合并、分裂出最大的k个。

**复杂度：** 插入/排名/分裂O(log V)，合并O(实际同时非空访问节点数)；空间O(累计新建节点)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `change(root,pos,c)`：返回新根，必须接收
- `merge(x,y)`：返回合并根，旧y不能继续独立使用
- `split(root,k)`：返回{剩余,最大的k个}
- `kth(root,k)`：原接口第k大，非法返回-1

### P5494 线段树分裂

[原题](https://www.luogu.com.cn/problem/P5494)

**题意：** 维护多个集合，按值域拆分、合并、加频率和排名查询。

**为什么使用：** 按<x和>y的次数切排名，将中间值域移到新根。

**如何调用：** 两次split；merge两侧；所有变根操作接收返回值。

**复杂度：** 分裂/更新/查询O(log n)，合并按节点交叠计；空间O((n+m)log n)。

### P3224 永无乡

[原题](https://www.luogu.com.cn/problem/P3224)

**题意：** 合并岛屿，查询连通块内重要度第k小的岛编号。

**为什么使用：** DSU维护块代表；每块一棵权值树，合并时破坏性merge。

**如何调用：** 建立排名到编号映射；DSU合并前取两根，合并后挂到新代表。

**复杂度：** 总合并访问量按节点计，查询O(log n)；空间O(n log n)。

## 易错点

- 根之间不能共享节点；merge(x,x)非法。
- 第k小要转换为第size-k+1大。
- 按值域分裂由两次排名分裂实现；移走树之后及时清空旧根。
