# 离线二维数点

**用途与条件：** 按x扫描，树状数组维护y；四次前缀容斥回答闭矩形计数，允许重复点。

**复杂度：** O((n+q)log(n+q))时间、O(n+q)空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `add(x,y)`：加入一个点，可重复
- `ask(l,b,r,t)`：加入闭矩形询问
- `run()`：返回询问顺序的计数

## 例题

### P2163 园丁的烦恼

[原题](https://www.luogu.com.cn/problem/P2163)

**题意：** 查询二维平面闭矩形内树木棵数。

**为什么使用：** 静态点与离线矩形查询正好对应二维前缀容斥。

**如何调用：** 逐点add，逐询问ask，run后输出每个答案。

**复杂度：** O((n+m)log(n+m))时间与O(n+m)空间。

### P1972 HH的项链

[原题](https://www.luogu.com.cn/problem/P1972)

**题意：** 询问区间内不同颜色数。

**为什么使用：** 颜色只统计区间内第一次出现的位置；位置i贡献当且仅当pre[i]<l且l<=i<=r。映射为点(pre[i],i)。

**如何调用：** 读数组时用map保存上次位置并add；ask(0,l,l-1,r)。

**复杂度：** O((n+m)log(n+m))时间与O(n+m)空间。

## 易错点

- 严格小于端点的事件在等坐标点加入前处理；无需端点减1，支持LLONG_MIN。
- y仅离散化点坐标，空点集也能运行。
