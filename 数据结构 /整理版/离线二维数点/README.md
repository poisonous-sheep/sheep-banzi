# 离线二维数点

**类型：** 混合型

**适用场景：** 按x扫描，树状数组维护y；四次前缀容斥回答闭矩形计数，允许重复点。

**复杂度与条件：** O((n+q)log(n+q))时间、O(n+q)空间。

[完整C++17板子](模板.cpp)。

## 核心接口

- `add(x,y)`：加入一个点，可重复
- `ask(l,b,r,t)`：加入闭矩形询问
- `run()`：返回询问顺序的计数

## 例题 1：P2163 园丁的烦恼

[原题](https://www.luogu.com.cn/problem/P2163)

**题意：** 查询二维平面闭矩形内树木棵数。

**观察与规模：** 查询二维平面闭矩形内树木棵数。 静态点与离线矩形查询正好对应二维前缀容斥。 矩形计数和区间不同数都可表示二维点的支配计数，所有询问已知。

**朴素思路：** 每问扫描所有点O(nq)；二维动态结构比题目所需更复杂。

**关键突破：** 矩形用四次前缀包含-排除；按x排序消除一维，BIT维护另一维累计频次。

**状态与建模：** P2163点为(x,y)，事件为前缀矩形(X,Y)。P1972对位置i取点(i,pre\[i\])，区间\[l,r\]中一个值仅其首次出现位置满足pre\[i\]<l。

**本题映射：** 查询二维平面闭矩形内树木棵数。 静态点与离线矩形查询正好对应二维前缀容斥。 逐点add，逐询问ask，run后输出每个答案。

**转移与正确性：** 矩形答案F(x2,y2)-F(x1-1,y2)-F(x2,y1-1)+F(x1-1,y1-1)。扫描事件X之前加入x≤X点，查询BIT的y≤Y前缀。不同数为F(r,l-1)-F(l-1,l-1)。

**初始化与顺序：** y离散化保留顺序，加入点用lower_bound，查询边界用upper_bound数出≤Y的坐标。空前缀自然为0，同x必须先纳入点再答包含边界事件。

**优化与限制：** O((n+q)log(n+q))，空间O(n+q)。不是在线修改模型；坐标减1必须在原题范围内，闭区间条件不可混成<。

**本题复杂度：** O((n+m)log(n+m))时间与O(n+m)空间。
