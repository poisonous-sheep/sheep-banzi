# 交错位取反：把 `00 ↔ 11` 变成相邻交换

> 类型：思维 Trick / 异或差分 / 奇偶染色（交错掩码） / 相邻交换贪心  
> 记录：2026-10-27，ARC216 A - Reversi 3  
> [原题](https://atcoder.jp/contests/arc216/tasks/arc216_a) · [官方题解](https://atcoder.jp/contests/arc216/editorial/17806)

## 一句话速记

**当相邻两位只允许 `00 ↔ 11` 时，把偶数位置取反，操作就变成 `01 ↔ 10`（相邻交换）。**

这样原本会改变 1 的数量的操作，变成数量不变的操作，可以使用「按顺序匹配同色元素」贪心。

## 为什么会想到“偶数位取反”？

观察操作：

```text
00 <-> 11
```

这个操作把 **相同** 的一对数同时翻转，不方便直接贪心。

如果希望它变成「交换 0 和 1」，目标应该是：

```text
01 <-> 10
```

要让原来的两个 **相同位** 变成 **不同位**，只需额外翻转这对中的恰好一个位置。

对任意相邻位置都要满足这个条件，最简单的固定方案就是：

```text
位置 (1-based)： 1 2 3 4 5 6 ...
交错掩码：      0 1 0 1 0 1 ...
新数组 u[i] = d[i] XOR (i 为偶数)
```

这样任何相邻位置上的掩码必然不同，故

```text
00 XOR 01 = 01
11 XOR 01 = 10
```

从而 `00 ↔ 11` 等价于 `01 ↔ 10`。（如果这对掩码是 `10`，结论同样成立。）

**核心启发：遇到“相邻两位同时翻转”的操作，尝试 XOR 一个交替的 0101… 掩码，把“翻转”变成“交换”。**

## ARC216 A 的完整推导

### 1. 原操作

给定两个 01 字符串 A、B，允许选内部位置 i（2 ≤ i ≤ N-1），**仅当 A[i-1] = A[i+1]** 时翻转 A[i]，求将 A 变为 B 的最少操作次数。

位置 1 和位置 N 均不能直接修改，所以首先必须有 `A[1] = B[1]`。

### 2. 先做异或差分

定义（此处下标为 1-based）：

```text
d[i] = A[i] XOR A[i+1]，1 ≤ i < N
```

翻转 A[i]，只会使 `d[i-1]` 和 `d[i]` 同时翻转。

而合法条件 `A[i-1] = A[i+1]` 等价于：

```text
d[i-1] = d[i]
```

所以差分数组上的合法操作恰好为：

```text
00 <-> 11
```

（用普通差分也能观察到 `(1,-1) ↔ (0,0)`、`(-1,1) ↔ (0,0)`，但异或差分更简洁。）

### 3. 再把偶数位置取反

定义 `u[i] = d[i] XOR (i % 2 == 0)`（**1-based，下标 2、4、6… 取反**）。

连续两位的掩码必然是 `01` 或 `10`，合法操作变成：

```text
01 <-> 10
```

这正是两个不同元素的**相邻交换**。

### 4. 判无解并求最小次数

分别对 A、B 做上述变换，得到 X、Y。

- 如果 `A[1] != B[1]`，无解。
- 如果 X、Y 中 1 的数量不同，无解；相邻交换无法改变 1 的数量。
- 否则必定有解。设 X 中第 k 个 1 的位置为 `p[k]`，Y 中第 k 个 1 的位置为 `q[k]`，最少交换次数：

```text
ans = Σ |p[k] - q[k]|
```

原因：只做相邻交换时，1 彼此不需要交叉；从左往右把第 k 个 1 移动到目标的第 k 个 1 位置，总代价最小。每次交换恰好使一个 1 移动一格。

注意：原串最后一位同样不会改变，但不用单独判断。已知首位相同、且变换后 1 的个数相同，结合异或差分即可推出尾位也相同。

### 5. 手算例子（样例 1）

```text
A          = 0001
B          = 0111

异或差分： dA = 001
           dB = 100

掩码：          010

交错取反： X  = 011   -> 1 的位置 [2,3]
           Y  = 110   -> 1 的位置 [1,2]

ans = |2-1| + |3-2| = 2
```

## 赛场易错点

1. **先判断首位**：差分不能表示原串首位，所以只匹配差分不够。
2. **下标奇偶不要反**：本笔记用 1-based 差分时，偶数位取反；若循环 `i=0..N-2`，翻转的是 `i&1` 为 1 的下标。
3. **相邻交换仅适用于两位不同**：对应差分操作合法条件始终存在；不能把“任意同时翻转两位”也当作相邻交换。
4. **顺序匹配，而不是任选最近的 1**：第 k 个对第 k 个才能证明最优。
5. 若变换后的 1 的数量不同，要输出 -1；答案用 64 位整数。

时间 `O(N)`，空间 `O(N)`；多组数据 N 总和不超过 1e6。

## 可以迁移的场景

- 邻接位置受到相同的翻转/加减操作约束；
- 操作依赖于位置奇偶，或可以利用二分染色化简；
- 想把局部的「同时变化」转为「相邻交换、移动棋子」；
- 变换后若操作变成相邻交换，优先检查 **颜色数量不变量 + 顺序匹配 + 距离和**。

这不是普通的“答案贪心” Trick，真正值得记住的是：**主动设计奇偶掩码，改变操作的表现形式。**
