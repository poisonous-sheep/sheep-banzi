# 两互质面额不可表示数

**类型：** 思维型

**适用场景：** 两个互质正面额的非负整数线性组合，最大不可表示数ab-a-b，不可表示正整数个数(a-1)(b-1)/2。

**复杂度与条件：** 算式O(1)，断言gcd检查O(log min(a,b))；O(1)空间。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 0,b,2b,...,(a-1)b遍历模a的全部余数，每个余数类的最小可表示数因此确定。

**状态与建模：** 余数r的最小表示是kb，k∈\[0,a-1\]唯一；其后每隔a均可表示，之前同余的正数都不可表示。

**优化与限制：** O(log min(a,b))验证GCD后O(1)公式，中间乘法__int128。非互质时有无限正数不能表示，公式失效；三个以上面额也不能套用。

## 例题 1：P3951 小凯的疑惑

[原题](https://www.luogu.com.cn/problem/P3951)

**题意：** 两种无限互质金币面额，求不能支付的最高价格。

**观察与规模：** 两种无限互质金币面额，求不能支付的最高价格。 每个模a余数由0..a-1个b恰好遍历；每个余数类最高空缺在其最小可表示数之前一个a，最大值ab-a-b。 两个正面额、数量无限且互质；不是一般多面额背包问题。

**朴素思路：** 向上枚举金额无终止依据。有限容量DP可验证小数据，但无法从经验猜出最大缺口。

**关键突破：** 0,b,2b,...,(a-1)b遍历模a的全部余数，每个余数类的最小可表示数因此确定。

**状态与建模：** 余数r的最小表示是kb，k∈\[0,a-1\]唯一；其后每隔a均可表示，之前同余的正数都不可表示。

**本题映射：** 两种无限互质金币面额，求不能支付的最高价格。 每个模a余数由0..a-1个b恰好遍历；每个余数类最高空缺在其最小可表示数之前一个a，最大值ab-a-b。 maximum(a,b)，题目保证存在正数不可表示。

**转移与正确性：** 各类最高缺口为kb-a，最大在k=a-1，得到ab-a-b。总缺口Σfloor(kb/a)=(a-1)(b-1)/2，因为非零余数恰为1..a-1。类间余数不同，不重不漏。

**初始化与顺序：** a或b为1时没有正缺口，最大公式给-1，计数0；P3951保证存在正不可表示金额。HDU到EOF独立计算。

**优化与限制：** O(log min(a,b))验证GCD后O(1)公式，中间乘法__int128。非互质时有无限正数不能表示，公式失效；三个以上面额也不能套用。

**本题复杂度：** O(log min(a,b))时间/O(1)空间（含gcd断言）。

**启发式总结：** 小数据规律应落实到余数类最小代表的证明。公式里除2来自完整余数求和，不需要模逆元。

## 共同思路与易错点

- 必须gcd(a,b)=1；非互质时有无限多个不可表示数，没有最大值。
- 非负组合和Bezout允许负系数的线性组合不同。
- 乘积使用__int128，返回值必须落入long long。

共同启发：小数据规律应落实到余数类最小代表的证明。公式里除2来自完整余数求和，不需要模逆元。
