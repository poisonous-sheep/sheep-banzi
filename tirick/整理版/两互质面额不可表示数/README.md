# 两互质面额不可表示数

**用途与条件：** 两个互质正面额的非负整数线性组合，最大不可表示数ab-a-b，不可表示正整数个数(a-1)(b-1)/2。

**复杂度：** 算式O(1)，断言gcd检查O(log min(a,b))；O(1)空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `maximum(a,b)`：互质正面额；任一为1时返回-1，表示无不可表示正整数
- `count(a,b)`：不可表示正整数总数

## 例题

### P3951 小凯的疑惑

[原题](https://www.luogu.com.cn/problem/P3951)

**题意：** 两种无限互质金币面额，求不能支付的最高价格。

**为什么使用：** 每个模a余数由0..a-1个b恰好遍历；每个余数类最高空缺在其最小可表示数之前一个a，最大值ab-a-b。

**如何调用：** maximum(a,b)，题目保证存在正数不可表示。

**复杂度：** O(log min(a,b))时间/O(1)空间（含gcd断言）。

[原题](https://acm.hdu.edu.cn/showproblem.php?pid=1792)

## 易错点

- 必须gcd(a,b)=1；非互质时有无限多个不可表示数，没有最大值。
- 非负组合和Bezout允许负系数的线性组合不同。
- 乘积使用__int128，返回值必须落入long long。
