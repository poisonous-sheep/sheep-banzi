# 异或比较与最高不同位

**类型：** 思维型

**适用场景：** 非负数满足|x-y|≤x xor y≤x+y；异或比较由最高不同位决定，低位值域可截断DP转移。

**复杂度与条件：** subsequence O(n*2^B)时间/O(n)空间；max_xor O(log r)时间/O(1)空间。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** D1中高于第7位只有下标贡献；若j<i且不在同一个256块，高位会让a\[j\] xor i大于a\[i\] xor j。合法前驱必距i不到256。

**状态与建模：** D1 dp\[i\]是以0基i结尾的最长合法子序列。CF276D令k为l xor r最高置位，区间上方所有位固定，只有k及以下可能产生差异。

**优化与限制：** D1 O(256n)，依赖小ai；D2的值域扩大后此窗口无效。区间公式仅是任意选两数最大异或，不用于固定数组最大异或。

## 例题 1：CF1720D1 Xor-Subsequence (easy version)

[原题](https://codeforces.com/problemset/problem/1720/D1)

**题意：** ai≤200，选最长子序列，使相邻所选下标i<j满足ai xor j < aj xor i，下标从0起。

**观察与规模：** ai≤200，选最长子序列，使相邻所选下标i<j满足ai xor j < aj xor i，下标从0起。 高于第7位只有下标贡献，间距≥256必然失败；仅枚举最近255个前驱。 异或的大小由最高不同位决定；D1中a\[i\]≤200，而下标可很大。

**朴素思路：** 最长子序列枚举所有前驱O(n^2)，区间最大异或枚举所有点对更不可行。

**关键突破：** D1中高于第7位只有下标贡献；若j<i且不在同一个256块，高位会让a\[j\] xor i大于a\[i\] xor j。合法前驱必距i不到256。

**状态与建模：** D1 dp\[i\]是以0基i结尾的最长合法子序列。CF276D令k为l xor r最高置位，区间上方所有位固定，只有k及以下可能产生差异。

**本题映射：** ai≤200，选最长子序列，使相邻所选下标i<j满足ai xor j < aj xor i，下标从0起。 高于第7位只有下标贡献，间距≥256必然失败；仅枚举最近255个前驱。 读T、a，subsequence(a,8)。

**转移与正确性：** D1枚举最近255个j，验证原不等式后dp\[i\]=max(dp\[i\],dp\[j\]+1)。CF276D在最高不同位处分成0/1两半，选边界的互补后缀可令下k+1位全1，且不超过公共前缀界。

**初始化与顺序：** dp全1，i正序；l=r时异或0。生成全1答案用逐位累积而非有符号1<<63。

**优化与限制：** D1 O(256n)，依赖小ai；D2的值域扩大后此窗口无效。区间公式仅是任意选两数最大异或，不用于固定数组最大异或。

**本题复杂度：** O(256n)时间/O(n)空间。

**启发式总结：** 看到异或比较先定位最高不同位，再利用值域把“不可能的远处候选”排掉；不能把经验窗口当证明。

## 共同思路与易错点

- 下标差≥2^B时，高位大小已经使CF1720条件不可能成立；只能在值域小于2^B时截断。
- D2没有D1的ai≤200限制，不能照用窗口256。
- max_xor由l xor r最高位确定，l=r时答案0。

共同启发：看到异或比较先定位最高不同位，再利用值域把“不可能的远处候选”排掉；不能把经验窗口当证明。
