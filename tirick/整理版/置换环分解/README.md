# 置换环分解

**类型：** 思维型

**适用场景：** 排列分解为互不相交的环；任意交换最小次数n-环数。环上的局部选择可独立计数。

**复杂度与条件：** build/min_swaps/sort_swaps O(n)时间与空间；cover_ways O(n)时间与空间。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 一次任意交换能令环数改变±1；排序目标有n个单点环，最优必须每次拆环。

**状态与建模：** build得到cycle。ABC350C维护a与逆位置pos；ABC436E只需每环长度。ABC247F通过第一个排列的逆位置映射，将每张卡连接为环上的相邻覆盖关系。

**优化与限制：** 全部O(n)/O(n)，取模计数乘积必须用64位。环顶点覆盖是卡片至少覆盖，不等价于每个数恰好覆盖；非排列输入也不能直接环分解。

## 例题 1：ABC350C Sort

[原题](https://atcoder.jp/contests/abc350/tasks/abc350_c)

**题意：** 将排列用最多n-1次任意交换排好，并输出交换。

**观察与规模：** 题目只要求≤n-1次操作，贪心同时达到最少次数；交换后的两个pos都要改，否则后续会引用旧位置。 每个值恰出现一次，因此函数图每点入度出度均1，必为若干互不相交的环。

**朴素思路：** 盲目交换可能把两个环合并，使离目标更远；卡牌子集逐个枚举是2^n。

**关键突破：** 一次任意交换能令环数改变±1；排序目标有n个单点环，最优必须每次拆环。

**状态与建模：** build得到cycle。ABC350C维护a与逆位置pos；ABC436E只需每环长度。ABC247F通过第一个排列的逆位置映射，将每张卡连接为环上的相邻覆盖关系。

**本题映射：** 将排列用最多n-1次任意交换排好，并输出交换。 每次把位置i正确值换入，拆分置换环，总次数正好n-环数。 init，sort_swaps，输出操作列表。

**转移与正确性：** 排序把正确值i换到位置i，不破坏更早位置；每次拆一个环，恰n-环数次。最优第一步任意同环两点都能拆环，共ΣL(L-1)/2。选卡计数等价环顶点覆盖，按第一点是否选分类得到F\[L-1\]+F\[L+1\]，自环只能选。

**初始化与顺序：** 排序逐位置扫描并同步修改两个pos；环构建vis清0。F\[0\]=0,F\[1\]=1，正序递推。长1环单独用1，避免错误把两种边界方案重复。

**优化与限制：** 全部O(n)/O(n)，取模计数乘积必须用64位。环顶点覆盖是卡片至少覆盖，不等价于每个数恰好覆盖；非排列输入也不能直接环分解。

**本题复杂度：** O(n)时间/O(n)空间。

## 例题 3：ABC436E Minimum Swap

[原题](https://atcoder.jp/contests/abc436/tasks/abc436_e)

**观察与规模：** 问最少交换排序方案的首步数；只有原来同环两点能把环数加1，跨环交换会使剩余最少次数增加。 每个值恰出现一次，因此函数图每点入度出度均1，必为若干互不相交的环。

- 任意交换和相邻交换不同；相邻交换应计算逆序对。
- 一个长度L环最少L-1次交换。
