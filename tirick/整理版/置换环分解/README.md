# 置换环分解

**用途与条件：** 排列分解为互不相交的环；任意交换最小次数n-环数。环上的局部选择可独立计数。

**复杂度：** build/min_swaps/sort_swaps O(n)时间与空间；cover_ways O(n)时间与空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(1-based排列)`：校验1..n各出现一次
- `build()/cycle`：遍历所有置换环
- `sort_swaps()`：返回排序所需最少交换，修改a/pos
- `cover_ways(mod)`：每个环选点覆盖全部相邻环边的方案乘积

### ABC247F Cards

[原题](https://atcoder.jp/contests/abc247/tasks/abc247_f)

**题意：** 每张卡两面分别来自两个排列，选卡使1..n每个数至少出现在一张所选卡的任一面上，计数。

**为什么使用：** 用排列p的逆位置把卡映射成i→pos[q[i]]的置换。每个数是相邻两卡共享的环边，选卡等价于环顶点覆盖。长度L方案F[L-1]+F[L+1]。

**如何调用：** 构造a，init，cover_ways；自环专门处理。

**复杂度：** O(n)时间/O(n)空间。

### ABC436E Minimum Swap

[原题](https://atcoder.jp/contests/abc436/tasks/abc436_e)

**题意：** 计数能作为最少交换排序方案第一步的交换。

**为什么使用：** 最优步骤必须令环数加1，因此两点必须在同一个原置换环内；任意同环两点都能拆成两个环。

**如何调用：** init、build，对每个cycle长度L累加L(L-1)/2。

**复杂度：** O(n)时间/O(n)空间。

## 易错点

- 任意交换和相邻交换不同；相邻交换应计算逆序对。
- 一个长度L环最少L-1次交换。
- ABC247F长度1的自环只有选此卡一种；长度2允许平行边，方案数3。
