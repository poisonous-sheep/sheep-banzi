# 前缀关系计数

**用途与条件：** 把满足条件的区间转为两个前缀的相同键值，按顺序统计此前相同前缀数。

**复杂度：** n次add期望O(n)时间/O(n)空间；unordered_map最坏可O(n²)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(n)`：清空并预留容量
- `add(key)`：累计此前等key前缀数量，返回这次新增对数
- `ans`：当前前缀对数，即合法区间数

## 例题

### CF1398C Good Subarrays

[原题](https://codeforces.com/problemset/problem/1398/C)

**题意：** 数字字符串中求元素和等于长度的子区间数。

**为什么使用：** s[r]-s[l]=r-l转为s[r]-r=s[l]-l，键为前缀和减前缀长度。

**如何调用：** init(n+1)，add(0)，逐位计算sum-i并add，输出ans。

**复杂度：** 期望O(n)时间/O(n)空间。

### ABC105D Candy Distribution

[原题](https://atcoder.jp/contests/abc105/tasks/abc105_d)

**题意：** 求数组区间和能被m整除的区间数。

**为什么使用：** 两前缀和同余，键为前缀和模m。

**如何调用：** add空前缀0，逐个取模加入，输出ans。

**复杂度：** 期望O(n)时间/O(min(n,m))空间。

## 易错点

- 先加入空前缀，再逐点加入，才能统计从位置1开始的区间。
- 区间计数最高n(n+1)/2，需要64位。
- 使用模前缀时负余数要归一化；对恶意哈希可改map获得O(n log n)最坏界。
