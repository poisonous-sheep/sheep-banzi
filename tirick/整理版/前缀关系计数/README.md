# 前缀关系计数

**类型：** 思维型

**适用场景：** 把满足条件的区间转为两个前缀的相同键值，按顺序统计此前相同前缀数。

**复杂度与条件：** n次add期望O(n)时间/O(n)空间；unordered_map最坏可O(n²)。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 把条件移项成两个前缀键相等，就能用历史频次一次统计所有合法左端点。

**状态与建模：** CF1398C键为prefixSum\[i\]-i；ABC105D键为prefixSum\[i\] mod M。cnt\[key\]为当前右端点之前相同键的前缀数量。

**优化与限制：** 哈希期望O(n)，恶意冲突有退化风险，排序离线O(nlog n)可替代。答案最大n(n+1)/2用64位；负数同余需统一归一化。

## 例题 1：CF1398C Good Subarrays

[原题](https://codeforces.com/problemset/problem/1398/C)

**题意：** 数字字符串中求元素和等于长度的子区间数。

**观察与规模：** 数字字符串中求元素和等于长度的子区间数。 s\[r\]-s\[l\]=r-l转为s\[r\]-r=s\[l\]-l，键为前缀和减前缀长度。 区间和/长度来自两个前缀差，求的是区间数量而非具体位置。

**朴素思路：** 枚举左右端点O(n^2)；只存每种键是否出现会漏掉重复前缀形成的多个区间。

**关键突破：** 把条件移项成两个前缀键相等，就能用历史频次一次统计所有合法左端点。

**状态与建模：** CF1398C键为prefixSum\[i\]-i；ABC105D键为prefixSum\[i\] mod M。cnt\[key\]为当前右端点之前相同键的前缀数量。

**本题映射：** 数字字符串中求元素和等于长度的子区间数。 s\[r\]-s\[l\]=r-l转为s\[r\]-r=s\[l\]-l，键为前缀和减前缀长度。 init(n+1)，add(0)，逐位计算sum-i并add，输出ans。

**转移与正确性：** 处理右端点r时，答案加cnt\[key\[r\]\]，然后才把当前前缀加入。每个区间只在自己的右端点计一次，不重不漏。也可离线用ΣC(cnt,2)。

**初始化与顺序：** 必须先加入空前缀key\[0\]=0。多组数据清map和ans；先查询后插入，否则把空区间也算进去。

**优化与限制：** 哈希期望O(n)，恶意冲突有退化风险，排序离线O(nlog n)可替代。答案最大n(n+1)/2用64位；负数同余需统一归一化。

**本题复杂度：** 期望O(n)时间/O(n)空间。

[完整函数题解](%E4%BE%8B%E9%A2%98/CF1398C-Good%20Subarrays-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 区间条件先写成前缀差的方程，再移项寻找可比较的键。计数对象是有序位置对l<r，不能只统计值集合。

## 共同思路与易错点

- 先加入空前缀，再逐点加入，才能统计从位置1开始的区间。
- 区间计数最高n(n+1)/2，需要64位。
- 使用模前缀时负余数要归一化；对恶意哈希可改map获得O(n log n)最坏界。

共同启发：区间条件先写成前缀差的方程，再移项寻找可比较的键。计数对象是有序位置对l<r，不能只统计值集合。
