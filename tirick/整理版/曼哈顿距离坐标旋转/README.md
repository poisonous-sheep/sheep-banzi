# 曼哈顿距离坐标旋转

**类型：** 混合型

**适用场景：** 用u=x+y,v=x-y把平面曼哈顿距离变为旋转坐标的切比雪夫距离；最大距离只需两维极值。

**复杂度与条件：** add/qur/diameter O(1)；建n点O(n)时间/O(1)额外空间。

[完整C++17板子](模板.cpp)。

## 核心接口

- `add(x,y)`：加入点，维护两维极值
- `diameter()`：已有点中最大曼哈顿距离
- `qur(x,y)`：询问到已有点的最大曼哈顿距离

## 例题 1：ABC178E Dist Max

[原题](https://atcoder.jp/contests/abc178/tasks/abc178_e)

**题意：** 求平面n点两两曼哈顿距离的最大值。

**观察与规模：** 求平面n点两两曼哈顿距离的最大值。 max(|Δu|,|Δv|)的最大值由每一维最大减最小得到。 平面L1距离有绝对值，求最远点或维护区间极值；不是最近邻问题。

**朴素思路：** 每问遍历全部点O(nq)，动态区间询问还需扫描区间。

**关键突破：** 令u=x+y、v=x-y，|Δx|+|Δy|=max(|Δu|,|Δv|)，消掉绝对值组合。

**状态与建模：** 集合信息仅需u/v各自最小最大四个数；这些信息可逐点加入，也可由两个集合逐维min/max合并。

**本题映射：** 求平面n点两两曼哈顿距离的最大值。 max(|Δu|,|Δv|)的最大值由每一维最大减最小得到。 add所有点，diameter。

**转移与正确性：** 全局直径为max(maxu-minu,maxv-minv)；给定点最远距离比较其到四个极值的距离。动态区间用线段树存同一四元信息，取查询区间的合并结果再计算。

**初始化与顺序：** 空集合极值LLONG_MAX/LLONG_MIN，至少加入一点才能查询；动态每叶先init再add，父节点merge。ABC437F查询不得直接使用全局集合。

**优化与限制：** 静态预处理O(n)、每问O(1)，动态建树/初始化按现实现O(nlog n)、每操作O(log n)。x±y及差必须容纳64位。高维有2^d符号组合，不能只留四极值。

**本题复杂度：** O(n)时间/O(1)额外空间。

## 共同思路与易错点

- 坐标和、差、最终距离均须在long long内。
- 旋转后的整数坐标满足奇偶约束，若反求点或统计格点必须检查；本最大值问题不需要。
- 仅维护極值无法回答最小距离。

共同启发：把绝对值距离改为有限个线性投影，再观察投影统计能否合并；最近距离不由全局极值决定。
