# 同余差与GCD

**类型：** 思维型

**适用场景：** 所有数同余模m当且仅当m整除全部差；最大可行模或步长来自差值GCD。

**复杂度与条件：** stride/from O(n log A)时间/O(1)额外空间；partitions O(n*tau(n)*log A)时间。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 同一位置相邻块的差已经足够，其余块间差可连加；最大公共模数由差的GCD刻画。

**状态与建模：** CF1920C对每个n的因数k，g=gcd(|a\[i\]-a\[i-k\]|)。ABC109C求所有|city-X|的GCD。

**优化与限制：** CF O(nτ(n)log A)，城市O(nlog A)。abs(LLONG_MIN)溢出，实际数值差需在64位内；g=0不得当无解。

## 例题 1：CF1920C Partitioning the Array

[原题](https://codeforces.com/problemset/problem/1920/C)

**题意：** 对n的每个因数k将数组分成长度k块，存在m≥2使各块对应位置模m相同则计数。

**观察与规模：** 对n的每个因数k将数组分成长度k块，存在m≥2使各块对应位置模m相同则计数。 对应位置的相邻块差为a\[i\]-a\[i-k\]；它们的GCD不为1正是存在合法模数。 “存在某模数使一组值同余”等价于模数整除所有两两差；移动固定步长也有同样不变量。

**朴素思路：** 枚举所有可能模数没有可靠上界；CF1920C直接比较所有块对会重复。

**关键突破：** 同一位置相邻块的差已经足够，其余块间差可连加；最大公共模数由差的GCD刻画。

**状态与建模：** CF1920C对每个n的因数k，g=gcd(|a\[i\]-a\[i-k\]|)。ABC109C求所有|city-X|的GCD。

**本题映射：** 对n的每个因数k将数组分成长度k块，存在m≥2使各块对应位置模m相同则计数。 对应位置的相邻块差为a\[i\]-a\[i-k\]；它们的GCD不为1正是存在合法模数。 partitions(a)，枚举因数并调用stride。

**转移与正确性：** CF存在m≥2当且仅当g!=1：g≥2可取g，g=0表示所有差0，可取任意m≥2。移动题D必须整除全部差，取GCD既满足又最大。

**初始化与顺序：** GCD初始0，gcd(0,x)=x；只枚举整除n的k。城市题原输入保证有异于X的城市，正最大步长存在。

**优化与限制：** CF O(nτ(n)log A)，城市O(nlog A)。abs(LLONG_MIN)溢出，实际数值差需在64位内；g=0不得当无解。

**本题复杂度：** O(n*tau(n)*log A)时间/O(n)空间。

[完整函数题解](%E4%BE%8B%E9%A2%98/CF1920C-Partitioning%20the%20Array-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 寻找不变量时先减掉公共基准，再问“所有差的公因数”。存在性和求最大值使用同一GCD，但0的含义要单独解释。

## 共同思路与易错点

- GCD=0表示所有差为0，任意正模均可，不是无解。
- CF1920C需要存在m≥2，因此g!=1，0也可行。
- llabs(a-b)先相减可能溢出，本例限定差值在long long内。
