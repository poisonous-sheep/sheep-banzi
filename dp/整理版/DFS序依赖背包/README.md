# DFS序依赖背包

**用途与条件：** 选节点则继续DFS下一点，不选则跳过其整个子树；依赖环先缩点为共同选择的软件包。

**复杂度：** O(nM)时间/空间；SCC另加O(n+m)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `add_edge/a/w`：依赖森林：父为前提，子为依赖项；允许w=0
- `run(root,exact)`：默认容量不超过M；exact=true为恰好M
- `id/r`：id是DFS序节点，r[u]是子树末尾后一位置

## 例题

### P2014 选课 DFS序版

[原题](https://www.luogu.com.cn/problem/P2014)

**题意：** 按先修条件恰好选m门课。

**为什么使用：** 先修树的合法点集在DFS序中只能“选当前”或“跳整子树”。

**如何调用：** 真实课w=1、虚根w=0，run(0,true)。

**复杂度：** O(nm)时间/空间。

### P2515 软件安装

[原题](https://www.luogu.com.cn/problem/P2515)

**题意：** 有最多一个依赖的软件选择，可能存在依赖环，限定容量求最大价值。

**为什么使用：** 环中软件必须全选或全不选；SCC缩点后依赖变森林，再DFS序背包。

**如何调用：** SCC.scc取得col，合计包w/a；无前提包接虚根；run(0)。

**复杂度：** O(nM+n)时间、O(nM)空间。

## 易错点

- 图必须是依赖森林，一般多前提DAG不能直接套。
- 虚根0的w=a=0，SCC缩点后每包最多一个外部先修。
- 原课堂固定规模数组省略了tot+1行；整理版显式分配结束状态。
