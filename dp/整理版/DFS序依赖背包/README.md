# DFS序依赖背包

**类型：** 混合型

**适用场景：** 选节点则继续DFS下一点，不选则跳过其整个子树；依赖环先缩点为共同选择的软件包。

**复杂度与条件：** O(nM)时间/空间；SCC另加O(n+m)。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 先把依赖环缩成SCC；DFS先序中子树连续，不选一个点就能直接跳过整棵子树。

**状态与建模：** id\[i\]为DFS序第i个点，r\[u\]为其子树结束后的第一位置；dp\[i\]\[j\]为从位置i以后合法选择、容量为j的最大收益。exact=true时j是恰好用量，否则是不超过容量。

**优化与限制：** 缩点O(n+m)，DFS序DP O(nM)/O(nM)。依赖任意多前驱时缩点后可能是一般DAG，不能当森林跳子树；本题单前驱是关键。

## 例题 1：P2014 选课 DFS序版

[原题](https://www.luogu.com.cn/problem/P2014)

**题意：** 按先修条件恰好选m门课。

**观察与规模：** 恰选m门课且每门至多一个先修；虚根0不计数量，必须允许森林但不能丢掉恰好数量约束。 每点只有一个直接前置依赖；P2515允许依赖形成环，P2014要求恰好选m门。

**朴素思路：** 普通树背包要枚举两个数量分配；环上按点逐个选择会破坏“全部选或全部不选”。

**关键突破：** 先把依赖环缩成SCC；DFS先序中子树连续，不选一个点就能直接跳过整棵子树。

**状态与建模：** id\[i\]为DFS序第i个点，r\[u\]为其子树结束后的第一位置；dp\[i\]\[j\]为从位置i以后合法选择、容量为j的最大收益。exact=true时j是恰好用量，否则是不超过容量。

**本题映射：** 按先修条件恰好选m门课。 先修树的合法点集在DFS序中只能“选当前”或“跳整子树”。 真实课w=1、虚根w=0，run(0,true)。

**转移与正确性：** 不选u：dp\[r\[u\]\]\[j\]；选u：dp\[i+1\]\[j-w\[u\]\]+a\[u\]。选择父亲后才能走进下一位置的后代，跳子树保证没有选父亲时后代也不选。缩点累加重量和价值，依赖边连接不同SCC。

**初始化与顺序：** 逆DFS序计算。exact末尾仅dp\[tot+1\]\[0\]=0，其余-INF；不超过容量时末尾全0。虚根0重量价值均0，用它接多个无依赖分量。SCC需先init、加边、run。

**优化与限制：** 缩点O(n+m)，DFS序DP O(nM)/O(nM)。依赖任意多前驱时缩点后可能是一般DAG，不能当森林跳子树；本题单前驱是关键。

**本题复杂度：** O(nm)时间/空间。

**启发式总结：** 看到“不选后全部后代失效”可尝试DFS序跳跃。优化来自状态的两种去向，不是把树背包循环机械删一层。

## 例题 2：P2515 软件安装

[原题](https://www.luogu.com.cn/problem/P2515)

## 共同思路与易错点

- 图必须是依赖森林，一般多前提DAG不能直接套。
- 虚根0的w=a=0，SCC缩点后每包最多一个外部先修。
- 原课堂固定规模数组省略了tot+1行；整理版显式分配结束状态。
