# 自相似序列奇偶分治

**类型：** 思维型

**适用场景：** 利用f(2x)、f(2x+1)与f(x)的关系缩小下标；包含Thue-Morse模式计数与三字符替换查询变体。

**复杂度与条件：** calc的上界与模式不断折半，记忆化状态约O(log² L)，每状态O(m)；transform O(min(t,log k))时间/栈空间。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 下标除2回到父字符，奇偶决定当前是哪个孩子；连续限制也可按起点奇偶缩回上一层。

**状态与建模：** ABC242D transform(s,t,k)是第t轮0基第k位字母编号。QOJ calc(L,s)是满足限制串s、起点0..L的合法起点数，memo键为完整(L,s)，不能只存长度。

**优化与限制：** 查询无需生成序列。边界t大于log k必须快速停止；QOJ两种对齐方式不是同一种抽样，不能遗漏补出的首位。

## 例题 1：QOJ12409 Bit Sequence

[原题](https://qoj.ac/problem/12409)

**题意：** 统计0..L中，popcount(x+i)奇偶序列与给定模式相符的x个数。

**观察与规模：** 匹配0/1限制串的起点上界L；两种奇偶对齐的父层串不同，(L,s)才是完整记忆化键。 序列反复替换后长度指数增长，查询下标/匹配前缀却只用很少信息。

**朴素思路：** 真正展开t轮无法存储；按长度线性递归会被大t卡住。

**关键突破：** 下标除2回到父字符，奇偶决定当前是哪个孩子；连续限制也可按起点奇偶缩回上一层。

**状态与建模：** ABC242D transform(s,t,k)是第t轮0基第k位字母编号。QOJ calc(L,s)是满足限制串s、起点0..L的合法起点数，memo键为完整(L,s)，不能只存长度。

**本题映射：** 统计0..L中，popcount(x+i)奇偶序列与给定模式相符的x个数。 Thue-Morse的偶数位置继承，奇数位置取反；起点奇偶两类各自将模式压半。 每组init清memo，整数数组转01字符串，calc(L,s)。

**转移与正确性：** ABC每回上一层(k/2)，字母增量1+k%2(mod3)。QOJ按起点偶/奇两类：检查对应相邻对是否相反，取父层代表位；奇起点要补由首字符反推的前导位，再用(L-1)/2。

**初始化与顺序：** ABC t=0直接原串；k=0后直接累加t(mod3)，使递归深度由log k控制。QOJ空限制返回L+1，L<0返回0，单字符用全局计数性质；每组清memo。

**优化与限制：** 查询无需生成序列。边界t大于log k必须快速停止；QOJ两种对齐方式不是同一种抽样，不能遗漏补出的首位。

**本题复杂度：** 记忆化约O(m log² L)时间，上界状态空间同阶。

[完整函数题解](%E4%BE%8B%E9%A2%98/QOJ12409-Bit%20Sequence-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 自相似问题先从一个最终位置追踪祖先，或按对齐余数分组。状态应保留被缩小后仍影响合法性的短限制串。

## 例题 2：ABC242D ABC Transform

[原题](https://atcoder.jp/contests/abc242/tasks/abc242_d)

**题意：** ABC字符同时替换t轮后，查询第k个字符，t可能很大。

## 共同思路与易错点

- 原calc在L=0或模式长1时可能无限递归，显式加入终止情形。
- 奇数起点的补位必须转换字符0/1；不要对ASCII直接产生非数字字符。
- transform是三字符变体，不能把mod2的翻转直接换成同一题输入。

共同启发：自相似问题先从一个最终位置追踪祖先，或按对齐余数分组。状态应保留被缩小后仍影响合法性的短限制串。
