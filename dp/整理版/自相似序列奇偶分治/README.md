# 自相似序列奇偶分治

**用途与条件：** 利用f(2x)、f(2x+1)与f(x)的关系缩小下标；包含Thue-Morse模式计数与三字符替换查询变体。

**复杂度：** calc的上界与模式不断折半，记忆化状态约O(log² L)，每状态O(m)；transform O(min(t,log k))时间/栈空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init/calc(L,s)`：0..L内Thue-Morse序列匹配模式字符串s的起点数
- `transform(s,t,k)`：ABC->BC/CA/AB替换t次后的0基位置k

## 例题

### QOJ12409 Bit Sequence

[原题](https://qoj.ac/problem/12409)

**题意：** 统计0..L中，popcount(x+i)奇偶序列与给定模式相符的x个数。

**为什么使用：** Thue-Morse的偶数位置继承，奇数位置取反；起点奇偶两类各自将模式压半。

**如何调用：** 每组init清memo，整数数组转01字符串，calc(L,s)。

**复杂度：** 记忆化约O(m log² L)时间，上界状态空间同阶。

### ABC242D ABC Transform

[原题](https://atcoder.jp/contests/abc242/tasks/abc242_d)

**题意：** ABC字符同时替换t轮后，查询第k个字符，t可能很大。

**为什么使用：** 每个字符生成左右两子字符，0基位置的奇偶决定对子字符编号增加1或2；逆向回父位置。

**如何调用：** 将k转0基，transform(S,t,k-1)，返回值+A。

**复杂度：** 每询问O(min(t,log k))时间与递归空间。

## 易错点

- 原calc在L=0或模式长1时可能无限递归，显式加入终止情形。
- 奇数起点的补位必须转换字符0/1；不要对ASCII直接产生非数字字符。
- transform是三字符变体，不能把mod2的翻转直接换成同一题输入。
