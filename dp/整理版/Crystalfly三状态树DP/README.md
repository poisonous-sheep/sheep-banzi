# Crystalfly三状态树DP

**例题数量待补：** 目前仅核实1道独立原题。洛谷P9847、QOJ6438为同题镜像，不计作第二道例题。

**用途与条件：** 树上抓蝴蝶，邻点第一次被惊动后t≤3秒末消失。f是不计当前点收益的最优，g=f+a，h表示抓当前点后立刻返回的收益。

**复杂度：** O(n)时间/O(n)空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `a[u],t[u]`：填写正收益与1..3的消失延迟
- `add_edge; run(root)`：无根树建边，从起点返回最大收益

## 例题

### Gym103470H Crystalfly

[原题](https://codeforces.com/gym/103470/problem/H)

**题意：** 在树上行走抓晶蝶，邻点晶蝶被首次惊动后延迟1..3秒消失，求最大收益。

**为什么使用：** t≤3使一个父亲处最多及时取得两个子点收益；枚举立即返回的第一子点，配不同的t=3第二子点，保留深入与后续失收益遍历两种贡献。

**如何调用：** 读T、n、a、t、边，调用run(1)。

**复杂度：** O(n)时间/O(n)空间。

[solve及辅助代码](%E4%BE%8B%E9%A2%98/Gym103470H-Crystalfly.cpp)；依赖本节模板，替换原solve后组合编译。

## 易错点

- 第1秒下到某子点再立即返回，该子点不要求t=3；第3秒进入的第二个子点才要求t=3。原OCR版误限制第一点，官方第二样例即反例。
- 不能用本板子处理t>3，状态会不足。
- mx记录点编号，排除同一子点，避免相同a导致混淆。
- 会在之后访问已失去自身收益的子树，f仍须加到基础sum中。
- 长链递归须注意栈容量；64位存收益和。
