# 区间石子合并

**类型：** 思维型

**适用场景：** 相邻堆合并的区间DP；保留一次合并L..R堆三维状态，并提供二元合并与环形最大/最小版本。

**复杂度与条件：** binary O(n³)时间/O(n²)空间；arity O(n³R)时间/O(n³)空间，n<=100。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 倒着看最后一次合并：它必把\[l,k\]和\[k+1,r\]两堆合成一堆；最后成本只依赖区间总和。

**状态与建模：** dp\[l\]\[r\]是把区间合成一堆的最小成本。边界两堆的内部历史不影响下一次合并，所以端点足够。

**优化与限制：** 前缀和把每次区间求和降至O(1)，整体O(n^3)/O(n^2)。课堂L到R堆合并要增加剩余堆数k：先拼出k堆，再付区间和变为1堆；不能直接套二叉转移。

## 例题 1：DP_N Slimes

[原题](https://atcoder.jp/contests/dp/tasks/dp_n)

**题意：** 相邻两堆合并，总代价最小。

**观察与规模：** n≤400、a_i≤10^9，O(n^3)符合规模，答案及前缀和用64位。最后输出dp\[1\]\[n\]。 相邻合并保留原顺序，最终每堆对应一个连续区间；n为几百，区间三重枚举可行。

**朴素思路：** 直接枚举合并顺序会产生大量重复的中间区间。贪心每次合并最小相邻和没有一般正确性。

**关键突破：** 倒着看最后一次合并：它必把\[l,k\]和\[k+1,r\]两堆合成一堆；最后成本只依赖区间总和。

**状态与建模：** dp\[l\]\[r\]是把区间合成一堆的最小成本。边界两堆的内部历史不影响下一次合并，所以端点足够。

**本题映射：** 相邻两堆合并，总代价最小。 最后一次合并将区间分为左右两堆，枚举最后断点。 读a后binary(a)。

**转移与正确性：** dp\[l\]\[r\]=min_k(dp\[l\]\[k\]+dp\[k+1\]\[r\]+sum(l,r))。枚举最后分界不重不漏；求最大值时把min改max。环形复制数组，枚举长度n的窗口，表示最后保留的断点。

**初始化与顺序：** dp\[i\]\[i\]=0；最小值其余置INF，最大值置-INF。按长度从2到n计算，左右子区间必已完成。环形只计算长度不超过n。

**优化与限制：** 前缀和把每次区间求和降至O(1)，整体O(n^3)/O(n^2)。课堂L到R堆合并要增加剩余堆数k：先拼出k堆，再付区间和变为1堆；不能直接套二叉转移。

**本题复杂度：** O(n³)时间、O(n²)空间。

**启发式总结：** 出现相邻对象合并，先问最后一步分成几段、成本是否仅由整段决定。环形断开后窗口长度必须固定；多叉合并需要明确可达的堆数。

## 例题 2：P1880 石子合并

[原题](https://www.luogu.com.cn/problem/P1880)

**题意：** 圆周相邻两堆合并，求最小和最大总代价。

**观察与规模：** 环形起点自由，复制两遍后枚举恰好n个数的窗口；最小和最大分别计算，不能用长度2n的结果。 相邻合并保留原顺序，最终每堆对应一个连续区间；n为几百，区间三重枚举可行。

**朴素思路：** 直接枚举合并顺序会产生大量重复的中间区间。贪心每次合并最小相邻和没有一般正确性。

**关键突破：** 倒着看最后一次合并：它必把\[l,k\]和\[k+1,r\]两堆合成一堆；最后成本只依赖区间总和。

**状态与建模：** dp\[l\]\[r\]是把区间合成一堆的最小成本。边界两堆的内部历史不影响下一次合并，所以端点足够。

**本题映射：** 圆周相邻两堆合并，求最小和最大总代价。 复制数组后枚举长度n区间，覆盖全部断环位置；状态合并改min/max。 binary(a,true,false)与binary(a,true,true)。

**转移与正确性：** dp\[l\]\[r\]=min_k(dp\[l\]\[k\]+dp\[k+1\]\[r\]+sum(l,r))。枚举最后分界不重不漏；求最大值时把min改max。环形复制数组，枚举长度n的窗口，表示最后保留的断点。

## 共同思路与易错点

- 单堆费用0；三维k不能超过区间长度。
- DP_N n=400必须用binary，不可使用O(n⁴)的课堂多元版本。
- INF状态不要直接相加；费用和须小于INF。

共同启发：出现相邻对象合并，先问最后一步分成几段、成本是否仅由整段决定。环形断开后窗口长度必须固定；多叉合并需要明确可达的堆数。
