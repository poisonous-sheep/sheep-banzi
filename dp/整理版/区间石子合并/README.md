# 区间石子合并

**用途与条件：** 相邻堆合并的区间DP；保留一次合并L..R堆三维状态，并提供二元合并与环形最大/最小版本。

**复杂度：** binary O(n³)时间/O(n²)空间；arity O(n³R)时间/O(n³)空间，n<=100。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `binary(a,circle,maximum)`：a无1基占位；circle复制一圈，maximum求最大费用
- `arity(a,L,R)`：每次合并L..R堆，返回INF表示无法合成一堆

## 例题

### DP_N Slimes

[原题](https://atcoder.jp/contests/dp/tasks/dp_n)

**题意：** 相邻两堆合并，总代价最小。

**为什么使用：** 最后一次合并将区间分为左右两堆，枚举最后断点。

**如何调用：** 读a后binary(a)。

**复杂度：** O(n³)时间、O(n²)空间。

## 易错点

- 单堆费用0；三维k不能超过区间长度。
- DP_N n=400必须用binary，不可使用O(n⁴)的课堂多元版本。
- INF状态不要直接相加；费用和须小于INF。
