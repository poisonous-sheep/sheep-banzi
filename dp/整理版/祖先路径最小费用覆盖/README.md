# 祖先路径最小费用覆盖

**用途与条件：** 从给定非负费用祖先—后代路径中选若干条覆盖全部点，可重叠。保留最高到达深度DP，补充适合大数据的可并堆费用扣减版。

**复杂度：** 深度DP O(n²+m)时间/最坏O(n²)空间；可并堆O((n+m)log(m+1))时间/O(n+m)空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `add_edge(父,子); build(root)`：先建有根树与深度
- `add_path(bottom,top,cost)`：top必须是bottom祖先或自身；费用非负
- `run(root)`：课堂深度DP，小数据；-1表示无解
- `run_heap(root)`：大数据可并堆版；根也需要覆盖

## 例题

### CF1675D Vertical Paths

[原题](https://codeforces.com/problemset/problem/1675/D)

**题意：** 将有根树分成最少条向下的互不相交路径，输出路径划分。

**为什么使用：** 每个叶子至少需要一条路径；把所有根到叶路径作为费用1候选，用覆盖接口得到叶子数。逐叶上溯切去已经覆盖的前缀，保持最优条数且每点恰好一次。

**如何调用：** 从parent确定任意root；build，每个叶子add_path(leaf,root,1)，run_heap；另用used恢复不重叠路径。

**复杂度：** 本通用调用O(n log n)时间/O(n)空间；此特例可仅用构造降为O(n)。

### CF671D Roads in Yusland

[原题](https://codeforces.com/problemset/problem/671/D)

**题意：** 给定工人各可修一条祖先路径，付费雇佣工人覆盖所有树边，求最小总费用。

**为什么使用：** 把边(parent[x],x)映射为点x。u到v的边集合变成u到v下一层孩子的点路径；忽略u=v的空路径，根用免费单点覆盖。

**如何调用：** DFS建立fa、倍增表；将v下方孩子作为top，add_path；run_heap。原题n,m≤300000，不能调用O(n²)深度DP。

**复杂度：** O(n log n+(n+m)log(m+1))时间；O(n log n+m)空间。

## 易错点

- 原稿merge只有f[k]+后缀min(child)一侧；必须补child[k]+后缀min(f)。
- 合并前哨兵表示u未覆盖，合并后必须禁用该哨兵才能返回父亲。
- 堆中的费用是剩余费用：各子树先缴费，再把全部候选统一减去已缴最小值；每个候选只被删除一次。
- 边覆盖改成点覆盖时，路径最高点应为原top下方的孩子；根加费用0的单点路径。
- CF1675D是所有根到叶路径费用1的特例；允许重叠的最优值等于叶子数，可切去重复前缀获得原题恰好覆盖一次的输出。
- 树的长链递归有栈风险。
