# 祖先路径最小费用覆盖

**类型：** 混合型

**适用场景：** 从给定非负费用祖先—后代路径中选若干条覆盖全部点，可重叠。保留最高到达深度DP，补充适合大数据的可并堆费用扣减版。

**复杂度与条件：** 深度DP O(n²+m)时间/最坏O(n²)空间；可并堆O((n+m)log(m+1))时间/O(n+m)空间。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 覆盖当前点后，只需记选中路径能向上延伸的最浅深度；合并两个方案的延伸深度取min。

**状态与建模：** dp\[u\]\[d\]是覆盖u子树、且所选路径最高能到深度d的最小费用。哨兵depth\[u\]+1只表示合并尚未覆盖u；返回父亲前必须禁用。堆记录路径top深度和尚未付清的残余费用。

**优化与限制：** 深度DP最坏O(n^2)，仅作推导/小数据参考；左偏堆合并及lazy残余扣减约O((n+m)log(n+m))。CF671D把每条边映射为较深端点，路径u到v的top改成v下一层，根免费覆盖。

## 例题 1：CF1675D Vertical Paths

[原题](https://codeforces.com/problemset/problem/1675/D)

**题意：** 将有根树分成最少条向下的互不相交路径，输出路径划分。

**观察与规模：** n及所有测试n之和≤2×10^5；竖直路径只沿祖先到后代，要求每个顶点恰好出现一次，并输出路径。

**朴素思路：** 套一般有权路径覆盖会多维护费用和候选，本题所有竖直链都可用，且只求最少分组，可以先找结构下界。

**关键突破：** 一条竖直链最多包含一个原树叶子，所以路径条数至少为叶子数。

**状态与建模：** fa\[u\]为父亲、has_child\[u\]标记是否有真孩子、used\[u\]标记已分组。只从叶子开始向上收集尚未覆盖的连续前缀。

**转移与正确性：** 到已访问点即停，再反转得到从祖先到叶子的路径。各节点只加入一次；任一内部点都有叶子后代，必被某次上爬覆盖。恰每个叶子产一条，达到下界，故构造最优。

**初始化与顺序：** 根以fa\[root\]=root标识；建has_child时不把自父关系当真孩子。每组清used，单点树产一条含根路径。

**优化与限制：** 上爬过程中每个节点被标记一次，总O(n)时间、O(n)空间，无需可并堆。输出允许多种正确方案，以覆盖、不重和父子连续性验证。

**特殊修改：** 本题是无权竖直链分组，采用O(n)直接构造；一般有权覆盖模型用于下一例CF671D。

**本题复杂度：** O(n)时间、O(n)空间；每个顶点只被上爬加入一次。

[完整函数题解](%E4%BE%8B%E9%A2%98/CF1675D-Vertical%20Paths-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 先找不可合并的对象提供下界，再构造恰好达到下界的分组。若允许非竖直路径，一条路径能含两个叶子，下界与构造都需重做。

## 例题 2：CF671D Roads in Yusland

[原题](https://codeforces.com/problemset/problem/671/D)

**题意：** 给定工人各可修一条祖先路径，付费雇佣工人覆盖所有树边，求最小总费用。

**观察与规模：** 给定工人各可修一条祖先路径，付费雇佣工人覆盖所有树边，求最小总费用。 把边(parent\[x\],x)映射为点x。u到v的边集合变成u到v下一层孩子的点路径；忽略u=v的空路径，根用免费单点覆盖。 路径从后代到祖先，费用非负；课堂覆盖点，CF671D覆盖边，CF1675D只需无权竖直路径分组。

**朴素思路：** 枚举路径子集指数级；深度状态合并若枚举两状态O(depth^2)，链上也可能有大量状态。

**关键突破：** 覆盖当前点后，只需记选中路径能向上延伸的最浅深度；合并两个方案的延伸深度取min。

**状态与建模：** dp\[u\]\[d\]是覆盖u子树、且所选路径最高能到深度d的最小费用。哨兵depth\[u\]+1只表示合并尚未覆盖u；返回父亲前必须禁用。堆记录路径top深度和尚未付清的残余费用。

**本题映射：** 给定工人各可修一条祖先路径，付费雇佣工人覆盖所有树边，求最小总费用。 把边(parent\[x\],x)映射为点x。u到v的边集合变成u到v下一层孩子的点路径；忽略u=v的空路径，根用免费单点覆盖。 DFS建立fa、倍增表；将v下方孩子作为top，add_path；run_heap。原题n,m≤300000，不能调用O(n²)深度DP。

**转移与正确性：** 合并(a,b)按min深度分类，a\[k\]+min_(j≥k)b\[j\]或b\[k\]+min_(j≥k)a\[j\]；后缀min把双枚举降一维。堆在每点支付最小残余价，再对所有覆盖该点的候选扣同样的价。把支付量看作该点的对偶价格，每条路径上的累计价格不超过原费用，故价格总和是任何覆盖方案的下界。支付后记录一条残余0的紧路径，按根到叶回溯，只为尚未覆盖点选其当时记录的路径。已变0且能到某祖先的路径会使该祖先支付0，因此选出的路径不重复覆盖正价格点，原费用总和恰等于下界，证明最优。祖先链结构与非负费用是此证明的关键。

**初始化与顺序：** 本点路径初始化dp\[u\]\[top\]=cost，未处理孩子前哨兵为0，最终哨兵INF。堆合并孩子后加入本点路径，弹出top>depth\[u\]，空堆即无解。每次run_heap重建堆并清answer/ok。

**优化与限制：** 深度DP最坏O(n^2)，仅作推导/小数据参考；左偏堆合并及lazy残余扣减约O((n+m)log(n+m))。CF671D把每条边映射为较深端点，路径u到v的top改成v下一层，根免费覆盖。

**本题复杂度：** O(n log n+(n+m)log(m+1))时间；O(n log n+m)空间。

[完整函数题解](%E4%BE%8B%E9%A2%98/CF671D-Roads%20in%20Yusland-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 状态压缩必须解释“向上还保留什么能力”。覆盖边转换点要排除上端点；任意树上路径或负费用破坏此模型，不能把堆维护误读为每点独立选最便宜路径。

## 共同思路与易错点

- 原稿merge只有f[k]+后缀min(child)一侧；必须补child[k]+后缀min(f)。
- 合并前哨兵表示u未覆盖，合并后必须禁用该哨兵才能返回父亲。
- 堆中的费用是剩余费用：各子树先缴费，再把全部候选统一减去已缴最小值；每个候选只被删除一次。
- 边覆盖改成点覆盖时，路径最高点应为原top下方的孩子；根加费用0的单点路径。
- CF1675D是所有根到叶路径费用1的特例；允许重叠的最优值等于叶子数，可切去重复前缀获得原题恰好覆盖一次的输出。
- 树的长链递归有栈风险。

共同启发：状态压缩必须解释“向上还保留什么能力”。覆盖边转换点要排除上端点；任意树上路径或负费用破坏此模型，不能把堆维护误读为每点独立选最便宜路径。
