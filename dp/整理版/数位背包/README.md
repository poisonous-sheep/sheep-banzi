# 数位背包

**用途与条件：** 体积拆成奇数*2^b，高位到低位下放剩余容量，用奇数部分总和截断状态。

**复杂度：** O((63+n)*LIM)时间、O(n+LIM)空间；LIM=min(W,Σ奇数部分)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init/add(w,v)`：0/1物品，w>0
- `qur(W)`：最大价值，允许不装满

## 例题

### P3188 梦幻岛宝珠

[原题](https://www.luogu.com.cn/problem/P3188)

**题意：** 重量很大但w=a*2^b且a<=10的0/1背包。

**为什么使用：** Σ奇数部分<=10n，使容量与2^30脱钩。

**如何调用：** 每组建立对象add全部物品，qur(W)，读到-1 -1终止。

**复杂度：** O((63+n)*10n)时间、O(n)量级状态空间。

### P1048 采药

[原题](https://www.luogu.com.cn/problem/P1048)

**题意：** 每株草药只能采一次，限定时间内最大收益。

**为什么使用：** 普通0/1背包也可按体积幂分组；容量小会把LIM进一步截到W。

**如何调用：** 输入先T后M；逐个add(时间,价值)，qur(T)。

**复杂度：** O((63+M)*min(T,Σodd(w)))时间、O(T+M)空间。

## 易错点

- 剩余容量语义的0/1转移必须j从小到大，反向会重复选同一物品。
- 只有奇数部分和小才适合大容量；普通采药例题展示可用但传统背包更直接。
- 不能对0重量调用ctzll；价值和须在long long内。
