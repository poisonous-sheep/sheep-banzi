# 树上最大连通块权和

**用途与条件：** 含根的最优连通块权和为自身加所有正的子树贡献；二次DFS给每点换根答案。

**复杂度：** O(n)时间与空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init/add_edge/a`：初始化树、无向边、1基点权
- `run(root)`：f是固定根视图的子树答案；ans是整棵树中含该点的最优权和

## 例题

### P1122 最大子树和

[原题](https://www.luogu.com.cn/problem/P1122)

**题意：** 修剪树后保留非空连通子树使权和最大。

**为什么使用：** 任何连通块在固定根下有唯一最高点；取所有f的最大值。

**如何调用：** 写入a、add_edge、run，然后max f[1..n]。

**复杂度：** O(n)时间/空间。

### CF1324F Maximum White Subtree

[原题](https://codeforces.com/contest/1324/problem/F)

**题意：** 对每点求包含它的连通块中白数减黑数的最大值。

**为什么使用：** 白点权+1，黑点权-1；换根把子树答案扩展为整树答案。

**如何调用：** 把输入颜色转为2*a-1，run后输出ans。

**复杂度：** O(n)时间/空间。

## 易错点

- 不能把全负树答案初始化成0，题目要求非空。
- 换根必须扣去当前孩子的正贡献，再传给该孩子。
- 链树递归O(n)深度，注意评测栈限制。
