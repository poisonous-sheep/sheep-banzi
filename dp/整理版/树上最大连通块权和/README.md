# 树上最大连通块权和

**类型：** 思维型

**适用场景：** 含根的最优连通块权和为自身加所有正的子树贡献；二次DFS给每点换根答案。

**复杂度与条件：** O(n)时间与空间。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 固定必须包含u后，各孩子分支独立：贡献负就完全放弃，贡献正就接上。

**状态与建模：** f\[u\]为u子树内包含u的最大连通块权和。ans\[u\]为整棵树中包含u的最大值；up是父亲方向的最优可接贡献。

**优化与限制：** 两遍O(n)/O(n)，长链递归深度O(n)。全负时最大f仍是某个负点，不能把答案初始化为0后忽略非空要求。

## 例题 1：P1122 最大子树和

[原题](https://www.luogu.com.cn/problem/P1122)

**题意：** 修剪树后保留非空连通子树使权和最大。

**观察与规模：** 取任意非空连通块，所有点负时取最大单点；答案取全部f的最大值而非根的ans。 要求连通，树上通往每个分支的连接唯一；点权可负，空集不能当最终非空答案。

**朴素思路：** 枚举所有连通点集指数级；直接取全部正点可能不连通，连接负点有代价。

**关键突破：** 固定必须包含u后，各孩子分支独立：贡献负就完全放弃，贡献正就接上。

**状态与建模：** f\[u\]为u子树内包含u的最大连通块权和。ans\[u\]为整棵树中包含u的最大值；up是父亲方向的最优可接贡献。

**本题映射：** 修剪树后保留非空连通子树使权和最大。 任何连通块在固定根下有唯一最高点；取所有f的最大值。 写入a、add_edge、run，然后max f\[1..n\]。

**转移与正确性：** f\[u\]=a\[u\]+Σmax(0,f\[v\])。换根ans\[u\]=f\[u\]+max(0,up)，传给v的是ans\[u\]-max(0,f\[v\])，排除v自己的贡献，避免重复。

**初始化与顺序：** 叶子f=a，第一遍子树后序；第二遍父到子传up，根up=0。全局最优P1122取max f，CF1324F对白/黑赋+1/-1再输出各ans。

**优化与限制：** 两遍O(n)/O(n)，长链递归深度O(n)。全负时最大f仍是某个负点，不能把答案初始化为0后忽略非空要求。

**本题复杂度：** O(n)时间/空间。

[完整函数题解](%E4%BE%8B%E9%A2%98/P1122-%E6%9C%80%E5%A4%A7%E5%AD%90%E6%A0%91%E5%92%8C-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 树上连通选择常用“必须含当前根”消除耦合，再把不选孩子解释为贡献0；换根必须显式扣除目标孩子这一侧。

## 例题 2：CF1324F Maximum White Subtree

[原题](https://codeforces.com/contest/1324/problem/F)

**题意：** 对每点求包含它的连通块中白数减黑数的最大值。

**观察与规模：** 每点都要输出含该点的最优连通块，白/黑点映射+1/-1，第二遍换根必不可少。 要求连通，树上通往每个分支的连接唯一；点权可负，空集不能当最终非空答案。

**朴素思路：** 枚举所有连通点集指数级；直接取全部正点可能不连通，连接负点有代价。

**本题映射：** 对每点求包含它的连通块中白数减黑数的最大值。 白点权+1，黑点权-1；换根把子树答案扩展为整树答案。 把输入颜色转为2*a-1，run后输出ans。

## 共同思路与易错点

- 不能把全负树答案初始化成0，题目要求非空。
- 换根必须扣去当前孩子的正贡献，再传给该孩子。
- 链树递归O(n)深度，注意评测栈限制。
