# Kingdom军队遍历树DP

**例题数量待补：** 目前仅核实1道独立原题；未将另一种军队同时移动的题混作本板子例题。

**用途与条件：** 根可派任意多支军队，每次只能移动一支一步，求访问全树的最小总步数。保留原稿按父编号倒序合并的线性算法。

**复杂度：** O(n)时间/O(n)空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `fa[2..n]`：填写父亲，需满足fa[u]<u
- `run()`：最小总移动步数

## 例题

### Gym102769K Kingdom’s Power

[原题](https://codeforces.com/gym/102769/problem/K)

**题意：** 根有无限军队，每秒指定一支沿边移动一步，最少多久访问全树。

**为什么使用：** 单兵闭合分支每条边往返付2；开放分支可以接已有军队或另从根派兵，三种合并择优。

**如何调用：** 读T及每组n、父数组，run，输出Case #x: ans。

**复杂度：** O(n)时间/O(n)空间。

## 易错点

- dp0是从u出发并返回u、完整访问当前已合并子树的闭合行走费用，dp1允许额外从根派兵并保留未闭合行走；原稿把0/1的返回语义写反，已按转移修正。
- 倒序合并依赖父编号较小；其他编号应按后序处理，不能原样调用。
- 原题每秒仅一支军队移动，不能改成所有军队同时移动后的完成时间。
