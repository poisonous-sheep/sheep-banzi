# 区间同色配对与涂色

**类型：** 思维型

**适用场景：** 压缩相邻同色后，配对相同端点节省操作；收录原Cities最大节省状态与清空/涂色的次数接口。

**复杂度与条件：** O(n³)最坏时间、O(n²)空间；每色最多f次时O(fn²)。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 把同色块放在同一次操作中可以节省一次。选最左块，枚举与它配对的后续同色块，中间必须先解决。

**状态与建模：** 代码dp\[l\]\[r\]是区间能节省的操作数，答案为块数-dp\[1\]\[n\]；这与直接定义最少操作次数等价，不能把dp误读为次数。

**优化与限制：** 压缩相邻重复，预建同色后继；最坏仍O(n^3)/O(n^2)。涂色的覆盖顺序须按删除方案逆序理解。课堂把所有段变成一种颜色可少一次，但CF1114D的染色规则不同，不可混用。

## 例题 1：CF1132F Clear the String

[原题](https://codeforces.com/contest/1132/problem/F)

**题意：** 每次删除一段相同字符，求清空字符串最少次数。

**观察与规模：** 每次只能删除当前连续同色段，配对两块时先删其间内容；不能一次删散布的所有同色字符。 相邻相同字符可压成一个块；两题分别删除同色段、覆盖涂色，操作历史看似不同。

**朴素思路：** 逐次枚举所有段和所有操作序列是指数级；总是删除最长段会破坏后续同色块合并。

**关键突破：** 把同色块放在同一次操作中可以节省一次。选最左块，枚举与它配对的后续同色块，中间必须先解决。

**状态与建模：** 代码dp\[l\]\[r\]是区间能节省的操作数，答案为块数-dp\[1\]\[n\]；这与直接定义最少操作次数等价，不能把dp误读为次数。

**本题映射：** 每次删除一段相同字符，求清空字符串最少次数。 先清空两个同色位置中间内容，使两端可共同删除，节省一次。 字符转整数，init后clear_min。

**转移与正确性：** 不配对时继承dp\[l+1\]\[r\]；配到同色位置x时为dp\[l+1\]\[x-1\]+dp\[x\]\[r\]+1。内部先消除/覆盖，再共享端点操作。所有方案按最左块是否与后面共享分类。

**初始化与顺序：** 空区间及单块节省0；l从右向左，r从l向右，确保更靠右的起点已完成。nxt链只访问同色位置。

**优化与限制：** 压缩相邻重复，预建同色后继；最坏仍O(n^3)/O(n^2)。涂色的覆盖顺序须按删除方案逆序理解。课堂把所有段变成一种颜色可少一次，但CF1114D的染色规则不同，不可混用。

**本题复杂度：** O(n³)时间、O(n²)空间。

[完整函数题解](%E4%BE%8B%E9%A2%98/CF1132F-Clear%20the%20String-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 区间内相同端点可能共享代价时，尝试把一端固定，枚举下一次同色配对；必须证明中间段可独立处理。

## 例题 2：P4170 涂色

[原题](https://www.luogu.com.cn/problem/P4170)

**题意：** 每次将连续区间涂同一颜色，可覆盖旧颜色，形成目标串最少次数。

**观察与规模：** 覆盖绘画的执行顺序与删除同色段相反；压缩后也必须保留颜色相对顺序。 相邻相同字符可压成一个块；两题分别删除同色段、覆盖涂色，操作历史看似不同。

**朴素思路：** 逐次枚举所有段和所有操作序列是指数级；总是删除最长段会破坏后续同色块合并。

**本题映射：** 每次将连续区间涂同一颜色，可覆盖旧颜色，形成目标串最少次数。 一次同色涂色可先跨过中间区间，再补涂中间；与端点同色配对的省操作转移一致。 目标颜色串转整数，init后clear_min。

## 共同思路与易错点

- 配对后右子区间必须从x开始，而非x+1，因为x仍能继续配对。
- 原读入循环缺读n并改写n导致易错，整理版先读后压缩。
- 固定一个起点的Flood Fill是另一模型，不能直接假定uniform_min适用。
