# 区间同色配对与涂色

**用途与条件：** 压缩相邻同色后，配对相同端点节省操作；收录原Cities最大节省状态与清空/涂色的次数接口。

**复杂度：** O(n³)最坏时间、O(n²)空间；每色最多f次时O(fn²)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(a)`：整数色序列，压缩相邻相同并计算最大节省dp
- `clear_min()`：删除同色连续块直到空，等价从空白涂目标序列的最小次数
- `uniform_min()`：允许任意同色连续块改色、使整串同色的最小次数；Cities模型

## 例题

### CF1132F Clear the String

[原题](https://codeforces.com/contest/1132/problem/F)

**题意：** 每次删除一段相同字符，求清空字符串最少次数。

**为什么使用：** 先清空两个同色位置中间内容，使两端可共同删除，节省一次。

**如何调用：** 字符转整数，init后clear_min。

**复杂度：** O(n³)时间、O(n²)空间。

### P4170 涂色

[原题](https://www.luogu.com.cn/problem/P4170)

**题意：** 每次将连续区间涂同一颜色，可覆盖旧颜色，形成目标串最少次数。

**为什么使用：** 一次同色涂色可先跨过中间区间，再补涂中间；与端点同色配对的省操作转移一致。

**如何调用：** 目标颜色串转整数，init后clear_min。

**复杂度：** O(n³)时间、O(n²)空间。

## 易错点

- 配对后右子区间必须从x开始，而非x+1，因为x仍能继续配对。
- 原读入循环缺读n并改写n导致易错，整理版先读后压缩。
- 固定一个起点的Flood Fill是另一模型，不能直接假定uniform_min适用。
