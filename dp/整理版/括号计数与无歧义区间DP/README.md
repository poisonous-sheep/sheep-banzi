# 括号计数与无歧义区间DP

**类型：** 思维型

**适用场景：** 普通通配括号用余额状态；超级括号用首个完整括号块唯一分解，避免拼接计数重复。

**复杂度与条件：** normal O(n²)时间/O(n)空间；super O(n³)时间/O(n²)空间。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 普通括号的未来只依赖当前余额。超级括号用最左完整括号块及其右侧余串确定唯一分解。

**状态与建模：** normal中f\[d\]是已处理前缀余额为d的方案数。super中f是合法串，wrap是一个最外括号包裹的块，left/right是星号串接合法串，star是长度不超过k的全星号段。

**优化与限制：** 普通滚动数组O(n^2)/O(n)。超级枚举分界O(n^3)/O(n^2)；星号长度限制必须同时用于left/right。计数取模，禁止用“方案存在”代替方案数相乘。

## 例题 1：P7914 括号序列

[原题](https://www.luogu.com.cn/problem/P7914)

**题意：** 将?替换为括号或星号，使超级括号序列符合规范。

**观察与规模：** n≤500，问号替换为括号或星号；题面不允许最外星号段，故答案取f而非left/right；k限制每段星号。 普通括号只要求前缀余额非负且总余额0；超级括号另有连续星号上限及递归语法。

**朴素思路：** 枚举问号替换指数级；超级括号若任意切分合法串，会把同一字符串按多种括号分组重复计数。

**关键突破：** 普通括号的未来只依赖当前余额。超级括号用最左完整括号块及其右侧余串确定唯一分解。

**状态与建模：** normal中f\[d\]是已处理前缀余额为d的方案数。super中f是合法串，wrap是一个最外括号包裹的块，left/right是星号串接合法串，star是长度不超过k的全星号段。

**本题映射：** 将?替换为括号或星号，使超级括号序列符合规范。 规则是嵌套加合法块拼接，需区间计数与无歧义分解，不能套普通括号余额。 BracketDP(1e9+7).super(s,k)。

**转移与正确性：** 普通'('令d加1，')'仅在d>0令d减1，问号取两者。超级wrap内只能是空、S、A、SA、AS，不能凭空加SAS；f按第一个wrap及后面的A或SA连接，唯一首块保证无重计。

**初始化与顺序：** 普通f\[0\]=1，每个字符用清空的g转移，最后取f\[0\]。super先标star，空内层贡献1；按区间长度递增，非法类型默认0。

**优化与限制：** 普通滚动数组O(n^2)/O(n)。超级枚举分界O(n^3)/O(n^2)；星号长度限制必须同时用于left/right。计数取模，禁止用“方案存在”代替方案数相乘。

**本题复杂度：** O(n³)时间、O(n²)空间。

[完整函数题解](%E4%BE%8B%E9%A2%98/P7914-%E6%8B%AC%E5%8F%B7%E5%BA%8F%E5%88%97-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 语法计数先寻找唯一分解，再写状态。不同合法状态若有交集，简单相加就会重计；单括号余额模型不能直接解决递归星号语法。

## 共同思路与易错点

- 超级序列不接受空串、外侧星号或(SAS)；不能只看括号余额。
- 以第一个原始括号块wrap分解，不能任意枚举两个合法块拼接，否则重复计数。
- 原两状态笔记遗漏嵌套单侧星段；整理版显式维护left/right。

共同启发：语法计数先寻找唯一分解，再写状态。不同合法状态若有交集，简单相加就会重计；单括号余额模型不能直接解决递归星号语法。
