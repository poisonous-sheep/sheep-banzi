# 括号计数与无歧义区间DP

**用途与条件：** 普通通配括号用余额状态；超级括号用首个完整括号块唯一分解，避免拼接计数重复。

**复杂度：** normal O(n²)时间/O(n)空间；super O(n³)时间/O(n²)空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `normal(s)`：普通括号与?替换计数
- `super(s,k)`：超级括号规范：括号内可有单侧星段，完整块之间可有星段，每段长度<=k

### P7914 括号序列

[原题](https://www.luogu.com.cn/problem/P7914)

**题意：** 将?替换为括号或星号，使超级括号序列符合规范。

**为什么使用：** 规则是嵌套加合法块拼接，需区间计数与无歧义分解，不能套普通括号余额。

**如何调用：** BracketDP(1e9+7).super(s,k)。

**复杂度：** O(n³)时间、O(n²)空间。

## 易错点

- 超级序列不接受空串、外侧星号或(SAS)；不能只看括号余额。
- 以第一个原始括号块wrap分解，不能任意枚举两个合法块拼接，否则重复计数。
- 原两状态笔记遗漏嵌套单侧星段；整理版显式维护left/right。
