# 树上不相交给定路径

**用途与条件：** 选择给定带权路径，每个顶点至多使用一次。在LCA处决策，沿路径累加sdp-dp；保留课堂逐点版并提供DFS序树状数组优化。

**复杂度：** build O(n log n)；逐点版O(nm)，fast版O((n+m)log n)；空间O(n log n+m)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `add_edge(u,v); build(root)`：先建树，计算父亲、LCA与DFS序
- `add_path(x,y,w)`：将给定路径挂到其LCA，须先build
- `run(root,fast)`：返回最大权值和；false使用原逐点delta，true使用树状数组

## 例题

### HDU5293 Tree chain problem

[原题](https://acm.hdu.edu.cn/showproblem.php?pid=5293)

**题意：** 树上给出带权链，选择顶点互不相交的链使权值和最大。

**为什么使用：** 与课堂路径1的点不相交带权模型一致；delta之和扣掉所选路径占用顶点造成的子树最优损失。

**如何调用：** 读T；每组n,m、n-1条边、m条x,y,w；build后add_path，run使用优化版。

**复杂度：** O((n+m)log n)时间、O(n log n+m)空间。

### HDU4912 Paths on the tree

[原题](https://acm.hdu.edu.cn/showproblem.php?pid=4912)

**题意：** 从给定树上路径中选尽量多条，使所选路径顶点互不相交。

**为什么使用：** 把每条路径权重设为1就是同一带权选择问题；原题可用贪心，本例展示通用DP的等权特例。

## 易错点

- 点不相交，不能换成仅边不相交。
- 树状数组对子树加delta；查询端点时，尚未处理的当前LCA及更高祖先不会被计入。
- 可不选任何路径，所以负权自然被忽略。
- 长链递归有栈溢出风险。HDU原站题面与样例已核实，原题n,m≤100000，需使用fast版。
