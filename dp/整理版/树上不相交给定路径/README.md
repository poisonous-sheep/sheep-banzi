# 树上不相交给定路径

**类型：** 混合型

**适用场景：** 选择给定带权路径，每个顶点至多使用一次。在LCA处决策，沿路径累加sdp-dp；保留课堂逐点版并提供DFS序树状数组优化。

**复杂度与条件：** build O(n log n)；逐点版O(nm)，fast版O((n+m)log n)；空间O(n log n+m)。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 按LCA把路径挂在最高节点；在u处要么不用经过u的路径，要么仅选一条，因为所有这类路径共享u。

**状态与建模：** dp\[u\]是u子树最大选路权重，sdp\[u\]=Σdp\[v\]是不用u时各孩子独立最优。选路径x-y会占用它经过的每个祖先节点，必须释放相应子树最优占用。

**优化与限制：** 朴素沿路径累加改为Euler区间加、端点单查：delta\[z\]影响整棵z子树，两端各查询一次。O((n+m)log n)，不能提前插入u造成u计算两次。HDU4912把w设1，HDU5293读实际权值。

## 例题 1：HDU5293 Tree chain problem

[原题](https://acm.hdu.edu.cn/showproblem.php?pid=5293)

**题意：** 树上给出带权链，选择顶点互不相交的链使权值和最大。

**观察与规模：** 树上给出带权链，选择顶点互不相交的链使权值和最大。 与课堂路径1的点不相交带权模型一致；delta之和扣掉所选路径占用顶点造成的子树最优损失。 给定路径可带权，选出的路径不能共享顶点；路径是已给候选，不是任意自创。

**朴素思路：** 枚举路径子集2^m；将每条路径沿树逐点更新可能达O(nm)。

**关键突破：** 按LCA把路径挂在最高节点；在u处要么不用经过u的路径，要么仅选一条，因为所有这类路径共享u。

**状态与建模：** dp\[u\]是u子树最大选路权重，sdp\[u\]=Σdp\[v\]是不用u时各孩子独立最优。选路径x-y会占用它经过的每个祖先节点，必须释放相应子树最优占用。

**本题映射：** 树上给出带权链，选择顶点互不相交的链使权值和最大。 与课堂路径1的点不相交带权模型一致；delta之和扣掉所选路径占用顶点造成的子树最优损失。 读T；每组n,m、n-1条边、m条x,y,w；build后add_path，run使用优化版。

**转移与正确性：** 候选=sdp\[u\]+w+Σ_(两端到u且不含u)(sdp\[z\]-dp\[z\])。这保留路径旁的侧枝方案并去掉与路径冲突的最优项；每条路径仅在其LCA处理一次。

**初始化与顺序：** 先build得到父亲、Euler序和倍增表，再add_path挂LCA，后序dfs完成子树dp。计算u时BIT只保存已经完成的后代，u的delta在本节点候选全部计算后插入。

**优化与限制：** 朴素沿路径累加改为Euler区间加、端点单查：delta\[z\]影响整棵z子树，两端各查询一次。O((n+m)log n)，不能提前插入u造成u计算两次。HDU4912把w设1，HDU5293读实际权值。

**本题复杂度：** O((n+m)log n)时间、O(n log n+m)空间。

[完整函数题解](%E4%BE%8B%E9%A2%98/HDU5293-Tree%20chain%20problem-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 优化前先写出需要的路径和，再把“祖先贡献”转换成“子树覆盖端点”。点不相交与边不相交模型不同，不能仅改标题。

## 共同思路与易错点

- 点不相交，不能换成仅边不相交。
- 树状数组对子树加delta；查询端点时，尚未处理的当前LCA及更高祖先不会被计入。
- 可不选任何路径，所以负权自然被忽略。
- 长链递归有栈溢出风险。HDU原站题面与样例已核实，原题n,m≤100000，需使用fast版。

共同启发：优化前先写出需要的路径和，再把“祖先贡献”转换成“子树覆盖端点”。点不相交与边不相交模型不同，不能仅改标题。
