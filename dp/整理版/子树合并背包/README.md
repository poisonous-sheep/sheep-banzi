# 子树合并背包

**用途与条件：** 孩子背包卷积合并，固定点数连通选点；用户计数变体可把内部节点权重置0并扣启用边费用。

**复杂度：** 单位点数或叶子计数模型，限制循环到实际子树规模，总O(nM)，完整M=n时O(n²)；空间O(nM)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(n,M)/a/w`：默认每点计数1；点价值可负；用户模型仅内部节点w=0且a=0
- `add_edge(u,v,cost)`：有向父到子，选孩子非空时扣费用
- `run(root)/qur(u,k)`：恰好选k个计数单位、连通且含u的最优值；k=0表示可不选

## 例题

### P2014 选课

[原题](https://www.luogu.com.cn/problem/P2014)

**题意：** 恰好选m门课并满足先修依赖，使学分最大。

**为什么使用：** 无先修课程挂在虚根0，虚根w=0不计课程数；每个真实课程w=1。

**如何调用：** add_edge(先修,i)，run(0)，qur(0,m)。

**复杂度：** O(nm)时间/空间。

### P1273 有线电视网

[原题](https://www.luogu.com.cn/problem/P1273)

**题意：** 选择尽量多用户，在用户收益扣转播边费用后不亏本。

## 易错点

- 不可达初始化-INF，不能用0假装可达。
- 有先修关系必须使父节点被选才能合并孩子；最后提供空集0状态供父亲跳过。
- 任意非单位w不再有O(nM)规模证明，应改用DFS序依赖背包。
