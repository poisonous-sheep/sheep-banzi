# 子树合并背包

**类型：** 思维型

**适用场景：** 孩子背包卷积合并，固定点数连通选点；用户计数变体可把内部节点权重置0并扣启用边费用。

**复杂度与条件：** 单位点数或叶子计数模型，限制循环到实际子树规模，总O(nM)，完整M=n时O(n²)；空间O(nM)。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 将每个孩子子树视为一组方案，逐个做分组背包；只有取孩子非空方案才付该边费用。

**状态与建模：** dp\[u\]\[k\]为u子树选择数量/叶子数恰为k的最大净收益；非空状态包含u(内部网络节点重量为0)，k=0允许整棵子树不选。

**优化与限制：** 按真实子树可达数量裁剪数组并截到m；一般上界O(nm^2)，总量受树结构约束可更小。忽略边费或在j=0仍扣边费均错误。

## 例题 1：P2014 选课

[原题](https://www.luogu.com.cn/problem/P2014)

**题意：** 恰好选m门课并满足先修依赖，使学分最大。

**观察与规模：** 恰选m门课且每门至多一个先修；虚根0不计数量，必须允许森林但不能丢掉恰好数量约束。 选择孩子需要先选择父节点，或叶子带来收益但启用分支要付边费；数量上限m提供背包维度。

**朴素思路：** 枚举节点子集指数级；普通物品背包不记录依赖，会选到父亲未选的孩子。

**关键突破：** 将每个孩子子树视为一组方案，逐个做分组背包；只有取孩子非空方案才付该边费用。

**状态与建模：** dp\[u\]\[k\]为u子树选择数量/叶子数恰为k的最大净收益；非空状态包含u(内部网络节点重量为0)，k=0允许整棵子树不选。

**本题映射：** 恰好选m门课并满足先修依赖，使学分最大。 无先修课程挂在虚根0，虚根w=0不计课程数；每个真实课程w=1。 add_edge(先修,i)，run(0)，qur(0,m)。

**转移与正确性：** 合并时保留原方案(不选v)，或tmp\[i+j\]=max(tmp\[i+j\],dp\[u\]\[i\]+dp\[v\]\[j\]-cost)，j≥1。P2014每课程重1、虚根重0；P1273内部点重0、叶子重1，边费用减一次。

**初始化与顺序：** 先仅含u的状态dp\[u\]\[w\[u\]\]=a\[u\]，其余-INF。处理孩子前该状态不允许绕过u；所有孩子合并后才补dp\[u\]\[0\]=0。tmp独立缓冲防止复用同一孩子。

**优化与限制：** 按真实子树可达数量裁剪数组并截到m；一般上界O(nm^2)，总量受树结构约束可更小。忽略边费或在j=0仍扣边费均错误。

**本题复杂度：** O(nm)时间/空间。

[完整函数题解](%E4%BE%8B%E9%A2%98/P2014-%E9%80%89%E8%AF%BE-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 树形背包先明确背包维度计什么，再区别“完全不选子树”和“选根但数量0”。零重量内部点不能简单等同于没有选。

## 共同思路与易错点

- 不可达初始化-INF，不能用0假装可达。
- 有先修关系必须使父节点被选才能合并孩子；最后提供空集0状态供父亲跳过。
- 任意非单位w不再有O(nM)规模证明，应改用DFS序依赖背包。

共同启发：树形背包先明确背包维度计什么，再区别“完全不选子树”和“选根但数量0”。零重量内部点不能简单等同于没有选。
