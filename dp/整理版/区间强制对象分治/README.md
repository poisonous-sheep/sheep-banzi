# 区间强制对象分治

**用途与条件：** 选择一次事件作为区间分界，付当前费用后，左右不再互相影响。敌人模型由最远对象限定合法分界；切木棍模型由当前区间长度决定费用。

**复杂度：** n为敌人数、K≤2n为端点数：O(K²(n+K))时间/O(K²+n)空间；切木棍q切点：O(q³)时间/O(q²)空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init_enemies({l,r,w}列表)`：消灭期限区间内的敌人；费用为当前最远距离
- `init_cuts(length,cuts)`：切木棍；正且不同的切点需严格位于(0,length)
- `run()`：返回最小费用

## 例题

### P4766 Outer space invaders

[原题](https://www.luogu.com.cn/problem/P4766)

**题意：** 敌人在各时间区间出现，一次半径R的冲击波可击中当前距离≤R的敌人，费用R，求全灭最小费用。

**为什么使用：** 先考虑最远敌人被杀时刻k；该击可消灭所有跨k敌人，余下左右期限区间独立。

**如何调用：** 读T及期限a,b和距离d，init_enemies，run。

**复杂度：** O(n³)时间/O(n²)空间，离散时间点≤2n。

### UVA10003 Cutting Sticks

[原题](https://onlinejudge.org/external/100/10003.pdf)

**题意：** 在给定位置切断木棍，每次费用为正在切的那段长度，选切割顺序使总费用最小。

**为什么使用：** 把第一次切割k作为分界，左右后续独立。沿用相同dfs分界框架，将费用替换为两侧边界长度，允许分界为全部待切点。

**如何调用：** 循环读length直到0，读q和切点，init_cuts，run，输出指定英文句式。

**复杂度：** O(q³)时间/O(q²)空间。

## 易错点

- 左右必须递归[l,k-1]和[k+1,r]。原OCR版闭区间solve(l,k)+solve(k,r)可能无限递归，且l==r仍可能存在敌人。
- 敌人中跨过所选k的对象全部被此最远对象所需的一击消灭，剩余仅完全位于左右的期限区间。
- 压缩仅保留期限端点即可，总有最优射击时刻可移动到某端点。
- 切木棍的费用取两侧已切边界距离，和敵人最大距离属于同一分界递推的两种初始化；接口显式区分，不能混用。
