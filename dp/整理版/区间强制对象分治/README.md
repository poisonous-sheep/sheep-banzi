# 区间强制对象分治

**类型：** 思维型

**适用场景：** 选择一次事件作为区间分界，付当前费用后，左右不再互相影响。敌人模型由最远对象限定合法分界；切木棍模型由当前区间长度决定费用。

**复杂度与条件：** n为敌人数、K≤2n为端点数：O(K²(n+K))时间/O(K²+n)空间；切木棍q切点：O(q³)时间/O(q²)空间。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 选择当前区间必须负责的一次操作，让左右未处理对象互不影响。Enemies取完整落在区间内的最强敌人，其攻击时刻只能落在其窗口。

**状态与建模：** dp\[l\]\[r\]为端点离散化后当前区间的最小代价；切割模式表示尚需完成的切点\[l,r\]，敌人模式表示窗口完全在区间中的敌人。

**优化与限制：** 敌人n小，状态O(n^2)，每个扫描敌人及枚举时刻，O(n^3)量级；木棍O(q^3)/O(q^2)。离散化只需各敌人窗口端点，区间内部变化不影响可被覆盖集合。

## 例题 1：P4766 Outer space invaders

[原题](https://www.luogu.com.cn/problem/P4766)

**题意：** 敌人在各时间区间出现，一次半径R的冲击波可击中当前距离≤R的敌人，费用R，求全灭最小费用。

**观察与规模：** n≤300且攻击可在时间窗口内选择时刻；选最强对象不是贪心直接删它，而是枚举其负责攻击的时刻再划分左右。 切木棍按第一刀分治；Aliens在区间内有必须消灭的最强对象，其时间可选但强度确定。

**朴素思路：** 任意枚举攻击/切割顺序是阶乘级；每次选最低成本操作没有保证。

**关键突破：** 选择当前区间必须负责的一次操作，让左右未处理对象互不影响。Enemies取完整落在区间内的最强敌人，其攻击时刻只能落在其窗口。

**状态与建模：** dp\[l\]\[r\]为端点离散化后当前区间的最小代价；切割模式表示尚需完成的切点\[l,r\]，敌人模式表示窗口完全在区间中的敌人。

**本题映射：** 敌人在各时间区间出现，一次半径R的冲击波可击中当前距离≤R的敌人，费用R，求全灭最小费用。 先考虑最远敌人被杀时刻k；该击可消灭所有跨k敌人，余下左右期限区间独立。 读T及期限a,b和距离d，init_enemies，run。

**转移与正确性：** 枚举强制操作位置k：dfs(l,k-1)+dfs(k+1,r)+cost。最强攻击可代替所有跨越k且强度较小的攻击，左右剩余敌人窗口互不跨k；第一刀后左右木棍完全独立。

**初始化与顺序：** 空区间0，无敌人区间0；memo用-1表示未算，非负答案。单点窗口仍要攻击，不能把l==r直接当0。切点必须严格位于木棍内且互异。

**优化与限制：** 敌人n小，状态O(n^2)，每个扫描敌人及枚举时刻，O(n^3)量级；木棍O(q^3)/O(q^2)。离散化只需各敌人窗口端点，区间内部变化不影响可被覆盖集合。

**本题复杂度：** O(n³)时间/O(n²)空间，离散时间点≤2n。

[完整函数题解](%E4%BE%8B%E9%A2%98/P4766-Outer%20space%20invaders-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 区间DP不只有“最后一步”，也可找不可回避的最强/第一操作；左右独立必须由问题性质证明。

**观察与规模：** 切点最多50，先固定第一刀，成本为当前木棍长度x\[r+2\]-x\[l\]；不是切点数量，也不是原木总长。 切木棍按第一刀分治；Aliens在区间内有必须消灭的最强对象，其时间可选但强度确定。

## 共同思路与易错点

- 左右必须递归[l,k-1]和[k+1,r]。原OCR版闭区间solve(l,k)+solve(k,r)可能无限递归，且l==r仍可能存在敌人。
- 敌人中跨过所选k的对象全部被此最远对象所需的一击消灭，剩余仅完全位于左右的期限区间。
- 压缩仅保留期限端点即可，总有最优射击时刻可移动到某端点。
- 切木棍的费用取两侧已切边界距离，和敵人最大距离属于同一分界递推的两种初始化；接口显式区分，不能混用。

共同启发：区间DP不只有“最后一步”，也可找不可回避的最强/第一操作；左右独立必须由问题性质证明。
