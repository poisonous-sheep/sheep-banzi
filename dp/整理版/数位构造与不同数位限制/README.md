# 数位构造与不同数位限制

**类型：** 思维型

**适用场景：** 按字典序DFS构造>=n的最小数；收录至多k种与至少k种数位两个原资料变体。

**复杂度与条件：** at_most O(L*10)；at_least最多O(L²*1024*10)时间、O(L*1024)空间。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 同长度数的大小等于字典序；逐位从小到大试选，首次成功的完整串就是最小解。

**状态与建模：** dfs(pos,larger,cnt)记录位置、是否已大于下界、已用数字数；vis的十个计数记录哪些数字已出现，并保证回溯撤销正确。

**优化与限制：** F1也可枚举1或2种允许数字，再贪心找同长度最小合法数；F2采用回溯，严格前缀唯一，一旦变大，总可用已有数字补后缀。课堂至少k种要用(pos,mask,larger)可行性记忆化，并可能增加长度。

## 例题 1：CF1560F1 Nearest Beautiful Number easy

[原题](https://codeforces.com/contest/1560/problem/F1)

**题意：** k<=2时构造不小于n的最近美丽数。

**观察与规模：** k≤2，可枚举允许数字集合验证小难度性质；与F2是同一问题的两档限制，讲解应比较值域而非声称模型不同。 目标是最小的≥n且不同数字数≤k的数，数字只有10种；F1限制k≤2，F2允许更多。

**朴素思路：** 从n逐个加一可能跨越很长区间。局部选最小数字但不检查后缀可行性，也可能走进死路。

**关键突破：** 同长度数的大小等于字典序；逐位从小到大试选，首次成功的完整串就是最小解。

**状态与建模：** dfs(pos,larger,cnt)记录位置、是否已大于下界、已用数字数；vis的十个计数记录哪些数字已出现，并保证回溯撤销正确。

**本题映射：** k<=2时构造不小于n的最近美丽数。 按数位升序找第一个可完成方案就是最小合法数。 每组at_most(to_string(n),k)。

**转移与正确性：** 若larger=false，本位不能小于n对应位；新数字令cnt加1，超过k跳过。递归失败撤销vis和ans，成功立即返回；字典序遍历的第一条可行路径最优。

**初始化与顺序：** 初始pos=0、larger=false、cnt=0、vis清0。首位至少1；末位后返回成功。相同长度总有全9解(k≥1)，因此不需要额外加一位。

**优化与限制：** F1也可枚举1或2种允许数字，再贪心找同长度最小合法数；F2采用回溯，严格前缀唯一，一旦变大，总可用已有数字补后缀。课堂至少k种要用(pos,mask,larger)可行性记忆化，并可能增加长度。

**本题复杂度：** 每组O(L*10)时间、O(L+10)空间。

[完整函数题解](%E4%BE%8B%E9%A2%98/CF1560F1-Nearest%20Beautiful%20Number%20easy-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 最小构造常分为“枚举下一位”和“判断后缀可行”。至少与至多限制不可互换；禁止首位0、撤销计数和比较边界都是证明的一部分。

## 共同思路与易错点

- vis必须用计数整数，bool++/--错误且C++17禁止bool++。
- 至少k种不保证只增加一位，要一直尝试到max(原长度,k)。
- 至多k种的非tight合法前缀总可填已有数字，因此只在tight路径回溯。

共同启发：最小构造常分为“枚举下一位”和“判断后缀可行”。至少与至多限制不可互换；禁止首位0、撤销计数和比较边界都是证明的一部分。
