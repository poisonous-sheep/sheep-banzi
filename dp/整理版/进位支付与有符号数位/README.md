# 进位支付与有符号数位

**类型：** 思维型

**适用场景：** 每位选择直接支付或向更高币值进位并找零；二进制base=2就是原资料最少±2^k。

**复杂度与条件：** 幂倍币制O(n)个实际金额状态、map查找O(log n)；固定进制O(L)时间/O(1)空间。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 在相邻面额比为base的层次，低位余数r只需考虑付r张或收base-r张并进位。

**状态与建模：** dfs(i,x)是在第i种面额单位下支付x的最少总币数。更小面额已经决定，未来仅与剩余商及进位相关。十进制实现f/g分别表示当前前缀直接结清/结清前缀加1的最小成本。

**优化与限制：** 相邻整除保证只有相邻的两个商需要保留；任意面额系统不成立。字符串避免大金额溢出；递归按层数下降，记忆化合并重复的(i,x)。

## 例题 1：ABC231E Minimal payments

[原题](https://atcoder.jp/contests/abc231/tasks/abc231_e)

**题意：** 币值组成整倍数链，买X元物品时支付和找零总币数最少。

**观察与规模：** 每种币是前种的整数倍，X≤10^18；dfs中单位逐层缩小，只比较相邻两个商。 各面额逐级整除，允许付款并找零；单纯尽量用最大面额不一定省枚数。

**朴素思路：** 枚举每种币的正负使用数量无界；仅向下取整遗漏“多付一张大币再找零”。

**关键突破：** 在相邻面额比为base的层次，低位余数r只需考虑付r张或收base-r张并进位。

**状态与建模：** dfs(i,x)是在第i种面额单位下支付x的最少总币数。更小面额已经决定，未来仅与剩余商及进位相关。十进制实现f/g分别表示当前前缀直接结清/结清前缀加1的最小成本。

**本题映射：** 币值组成整倍数链，买X元物品时支付和找零总币数最少。 低位余数只有向下支付和向上进位两种有效选择。 读升序币值调用qur(a,X)。

**转移与正确性：** 递归取min(r+dfs(i+1,q), base-r+dfs(i+1,q+1))，r=0无需向上付。数字法nf=min(f+d,g+10-d)，ng=min(f+d+1,g+9-d)，分别对应新前缀及新前缀加1。

**初始化与顺序：** 递归最后面额只能用x张；每次qur清空memo。数字法空前缀f=0、g=1，按字符串从高位向低位更新，最终输出f。

**优化与限制：** 相邻整除保证只有相邻的两个商需要保留；任意面额系统不成立。字符串避免大金额溢出；递归按层数下降，记忆化合并重复的(i,x)。

**本题复杂度：** O(n log n)时间、O(n)状态空间。

[完整函数题解](%E4%BE%8B%E9%A2%98/ABC231E-Minimal%20payments-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 可找零的数位问题要同时保留“当前结清”和“借一位/进一位”，先用一位base进制算式推导，再压成常数状态。

## 例题 2：ABC155E Payment

[原题](https://atcoder.jp/contests/abc155/tasks/abc155_e)

## 共同思路与易错点

- 二进制由题目不限制最高幂时可以进到额外一位，末态允许一次大币找零。
- 原作业仅有口述伪代码，整理版明确了进位状态和收尾。
- 一般币制不满足整倍数时不能套此贪心转移。

共同启发：可找零的数位问题要同时保留“当前结清”和“借一位/进一位”，先用一位base进制算式推导，再压成常数状态。
