# 进位支付与有符号数位

**用途与条件：** 每位选择直接支付或向更高币值进位并找零；二进制base=2就是原资料最少±2^k。

**复杂度：** 幂倍币制O(n)个实际金额状态、map查找O(log n)；固定进制O(L)时间/O(1)空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `qur(coins,x)`：coins[0]=1且每个是前一个的整数倍
- `digits(s,base)`：s为高位到低位的0..9数字串，返回最少加减进制幂项数

## 例题

### ABC231E Minimal payments

[原题](https://atcoder.jp/contests/abc231/tasks/abc231_e)

**题意：** 币值组成整倍数链，买X元物品时支付和找零总币数最少。

**为什么使用：** 低位余数只有向下支付和向上进位两种有效选择。

**如何调用：** 读升序币值调用qur(a,X)。

**复杂度：** O(n log n)时间、O(n)状态空间。

## 易错点

- 二进制由题目不限制最高幂时可以进到额外一位，末态允许一次大币找零。
- 原作业仅有口述伪代码，整理版明确了进位状态和收尾。
- 一般币制不满足整倍数时不能套此贪心转移。
