# 树上距离分层计数

**用途与条件：** 用深度层节点数合并统计；原等距点集按中心各分支选点，固定距离数对用子树深度卷积。

**复杂度：** equidistant O(n²k)时间/O(nk)空间，适用n<=100；pairs O(nK)时间/空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `equidistant(k)`：所有大小k、两两等距的点集数模1e9+7
- `pairs(K)`：无序不同点对距离恰好K的精确个数

## 例题

### CF1551F Equidistant Vertices

[原题](https://codeforces.com/contest/1551/problem/F)

**题意：** 计数树上大小k的两两等距点集。

**为什么使用：** k>=3时必有唯一中心，所有选点距中心相同且来自不同分支。

**如何调用：** 多测，每组建树后equidistant(k)。

**复杂度：** O(n²k)时间、O(nk)空间。

### CF161D Distance in Tree

[原题](https://codeforces.com/contest/161/problem/D)

**题意：** 统计距离恰好K的无序点对。

**为什么使用：** 每对在LCA合并两条不同子树深度时唯一计入，深度和+1=K。

**如何调用：** 建树后pairs(K)。

## 易错点

- k=2任意点对均等距，必须单独处理；k>=3才有唯一顶点中心。
- 同中心不同分支才能选同距离点；每个分支至多选一个。
- pairs深度计数int32_t减少nK内存，乘法显式转long long。
