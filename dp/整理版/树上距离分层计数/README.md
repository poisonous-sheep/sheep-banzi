# 树上距离分层计数

**类型：** 思维型

**适用场景：** 用深度层节点数合并统计；原等距点集按中心各分支选点，固定距离数对用子树深度卷积。

**复杂度与条件：** equidistant O(n²k)时间/O(nk)空间，适用n<=100；pairs O(nK)时间/空间。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 路径在LCA汇合，点对只在首次合并所属两个不同分支时统计；k≥3等距点必须在中心不同分支且深度相同。

**状态与建模：** 点对f\[u\]\[d\]为已合并分支中距离u为d的点数。中心模型dp\[d\]\[j\]为当前中心、深度d上从已处理的不同分支各选一人，合计j人的方案数。

**优化与限制：** 固定距离O(nK)/O(nK)，计数表用32位，答案乘积转64位。等距模型枚举中心O(n^2k)，只用于原题的小n；不得对大树照抄。

## 例题 1：CF1551F Equidistant Vertices

[原题](https://codeforces.com/contest/1551/problem/F)

**题意：** 计数树上大小k的两两等距点集。

**观察与规模：** n≤100，对k≥3枚举公共中心；同一分支不能取两个同深度点，否则它们间距离小于2d。 CF161D只计固定距离点对；CF1551F要求k点任意两点等距，k≥3时出现唯一公共中心。

**朴素思路：** 枚举k点集合是指数级；枚举所有点对路径会到O(n^2)。

**关键突破：** 路径在LCA汇合，点对只在首次合并所属两个不同分支时统计；k≥3等距点必须在中心不同分支且深度相同。

**状态与建模：** 点对f\[u\]\[d\]为已合并分支中距离u为d的点数。中心模型dp\[d\]\[j\]为当前中心、深度d上从已处理的不同分支各选一人，合计j人的方案数。

**本题映射：** 计数树上大小k的两两等距点集。 k>=3时必有唯一中心，所有选点距中心相同且来自不同分支。 多测，每组建树后equidistant(k)。

**转移与正确性：** 合并孩子v先加Σf\[u\]\[d\]×f\[v\]\[K-d-1\]，再把f\[v\]\[d-1\]并入f\[u\]\[d\]，从而每对只在LCA计一次。中心模型按孩子计cnt\[d\]，dp\[d\]\[j\]+=dp\[d\]\[j-1\]×cnt\[d\]，每分支最多一人。

**初始化与顺序：** 点对f\[u\]\[0\]=1，子树后序。中心每个d的dp\[d\]\[0\]=1，j倒序防止同分支多选。k=1直接n，k=2所有点对均满足，不能套唯一中心法。

**优化与限制：** 固定距离O(nK)/O(nK)，计数表用32位，答案乘积转64位。等距模型枚举中心O(n^2k)，只用于原题的小n；不得对大树照抄。

**本题复杂度：** O(n²k)时间、O(nk)空间。

[完整函数题解](%E4%BE%8B%E9%A2%98/CF1551F-Equidistant%20Vertices-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 树上距离约束先寻找路径交点/中心，再考虑按深度分层。k=2与k≥3的几何性质不同，必须单独证明特殊分支。

## 例题 2：CF161D Distance in Tree

**观察与规模：** n≤50000、K≤500，只求点对距离K，先统计跨分支贡献再合并，防止同分支点被当成不同侧。 CF161D只计固定距离点对；CF1551F要求k点任意两点等距，k≥3时出现唯一公共中心。

## 共同思路与易错点

- k=2任意点对均等距，必须单独处理；k>=3才有唯一顶点中心。
- 同中心不同分支才能选同距离点；每个分支至多选一个。
- pairs深度计数int32_t减少nK内存，乘法显式转long long。

共同启发：树上距离约束先寻找路径交点/中心，再考虑按深度分层。k=2与k≥3的几何性质不同，必须单独证明特殊分支。
