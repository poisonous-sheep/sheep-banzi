# 树上行走与返回状态设计

**类型：** 思维型

**适用场景：** 从自由起终点遍历，到多军队，再到短倒计时：按题目约束重新推导子树与外界的状态接口。

**复杂度与条件：** 三个例题均O(n)时间、O(n)空间；递归代码长链栈风险另计。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 先用最简单的自由端点行走建立闭合/开放概念，再增加从根出发费用或局部时间条件。

**状态与建模：** ABC361E下行最长距离f\[u\]及两条最长分支描述直径。Kingdom dp\[u\]\[0\]是一支已到u的军队遍历已合并部分再回u的代价，不新增军队，dp\[u\]\[1\]是开放方案，包含可能新军从根到u的启动费用depth\[u\]。Crystalfly的f/g/h分别是自身已损失的自由探索、立即收自身再自由探索、收自身并限制先短返回的方案。

**优化与限制：** 三题均O(n)/O(n)，ABC边权和用64位；Kingdom需要原题父编号性质，任意编号应先求后序；Crystalfly只适用于t∈{1,2,3}短计时规则，任意长倒计时必须记录更多时间信息。

## 例题 1：ABC361E Tree and Hamilton Path 2

[原题](https://atcoder.jp/contests/abc361/tasks/abc361_e)

**题意：** 带正权树，任选起点和终点，访问所有顶点至少一次，求最短总路程。

**观察与规模：** N≤2×10^5、边权≤10^9，任意起终点；每边最少一次/两次的下界给出2Σw-diameter，并能沿直径实现。 三题都在树上行走，却分别允许任意起终点、从根新增军队、进入父点后触发短倒计时。限制变化会改变状态，不能共享一条转移。

**朴素思路：** 枚举行走序列既有重复绕行又有多个行动者，不能作为大树算法；单一“子树最优”没有说明是否返回，无法与父节点连接。

**关键突破：** 先用最简单的自由端点行走建立闭合/开放概念，再增加从根出发费用或局部时间条件。

**状态与建模：** ABC361E下行最长距离f\[u\]及两条最长分支描述直径。Kingdom dp\[u\]\[0\]是一支已到u的军队遍历已合并部分再回u的代价，不新增军队，dp\[u\]\[1\]是开放方案，包含可能新军从根到u的启动费用depth\[u\]。Crystalfly的f/g/h分别是自身已损失的自由探索、立即收自身再自由探索、收自身并限制先短返回的方案。

**本题映射：** 带正权树，任选起点和终点，访问所有顶点至少一次，求最短总路程。 非起终点路径的边至少走两次，路径边至少一次；选择最长路径省下最多重复代价。 后序DFS维护每点两条最长下行分支，得到直径；输出2*sum-diameter。

**转移与正确性：** ABC每条不在起终点路径上的边至少两次，路径边一次，答案2Σw-diameter。Kingdom合并孩子：闭合加dp\[v\]\[0\]+2；开放取旧开+子开、旧开+子闭+2、旧闭+子开三种。Crystalfly的基准sum=Σf\[v\]，h=a\[u\]+sum，f可先直接进入一个孩子拿a\[v\]，或短返孩子v贡献h\[v\]-f\[v\]后进入另一t=3孩子拿a\[w\]，g=f+a\[u\]。

**初始化与顺序：** ABC叶子最长分支0，后序更新全局直径。Kingdom初始闭0、开depth；原题fa\[i\]<i，逆编号正好后序。Crystalfly叶子f=0、g=h=a；子树后序，维护t=3孩子最大/次大a，排除第一孩子。第一孩子可为t=1，不能错误要求也为3。

**优化与限制：** 三题均O(n)/O(n)，ABC边权和用64位；Kingdom需要原题父编号性质，任意编号应先求后序；Crystalfly只适用于t∈{1,2,3}短计时规则，任意长倒计时必须记录更多时间信息。

**本题复杂度：** O(n)时间、O(n)邻接与递归空间。

[完整函数题解](%E4%BE%8B%E9%A2%98/ABC361E-Tree%20and%20Hamilton%20Path%202-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 先问返回接口、端点自由度、计时何时开始。不要把直径公式用于多军队题，也不要把任意子树最优当成能一条边返回的方案。

## 共同思路与易错点

- 自由端点、从根新军、捕获倒计时三种规则不能共享同一转移。
- Crystalfly第一孩子可为t=1，仅第二孩子须t=3；Kingdom逆编号依赖fa[i]<i。

共同启发：先问返回接口、端点自由度、计时何时开始。不要把直径公式用于多军队题，也不要把任意子树最优当成能一条边返回的方案。
