# 数位DP与有限状态

**用途与条件：** 把前缀必要信息编码为自动机状态，统一处理tight、前导零和区间前缀差；包含原数数三转移。

**复杂度：** O(L*S*10)时间、O(S)滚动空间；L是位数，S是状态数。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(S,mod)`：mod=0为精确计数；自定义go与accept，-1为禁止转移
- `windy/digit_sum/increasing_three`：配置相邻差、数位和、连续三位递增状态
- `qur(bound)`：统计0..bound，包括是否接受0由状态配置决定

## 例题

### P2657 windy数

[原题](https://www.luogu.com.cn/problem/P2657)

**题意：** 统计区间内相邻十进制数位之差至少2的正整数。

**为什么使用：** 状态仅需前一有效数位，前导零有独立状态。

**如何调用：** windy配置，然后qur(R)-qur(L-1)。

**复杂度：** O(位数*110)时间、O(11)空间。

### DP_S Digit Sum

[原题](https://atcoder.jp/contests/dp/tasks/dp_s)

**题意：** 1..K中数位和能被D整除的数字个数，K可达10000位。

**为什么使用：** 数位和只需模D的余数，滚动状态避免把巨大上界转整数。

**如何调用：** digit_sum(D,1e9+7)，qur(K)后减去0。

**复杂度：** O(|K|*D*10)时间、O(D)空间。

## 易错点

- 数数三不把前导0当有效位；digit_sum接受0，例题需减去。
- mod=0仅在总计数不会溢出long long时使用。
- 原框架的x+1与当前含上界API不同，区间统一qur(R)-qur(L-1)。
