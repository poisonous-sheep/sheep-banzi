# 数位DP与有限状态

**类型：** 模板型

**适用场景：** 把前缀必要信息编码为自动机状态，统一处理tight、前导零和区间前缀差；包含原数数三转移。

**复杂度与条件：** O(L*S*10)时间、O(S)滚动空间；L是位数，S是状态数。

[完整C++17板子](模板.cpp)。

## 核心接口

- `init(S,mod)`：mod=0为精确计数；自定义go与accept，-1为禁止转移
- `windy/digit_sum/increasing_three`：配置相邻差、数位和、连续三位递增状态
- `qur(bound)`：统计0..bound，包括是否接受0由状态配置决定

## 例题 1：P2657 windy数

[原题](https://www.luogu.com.cn/problem/P2657)

**题意：** 统计区间内相邻十进制数位之差至少2的正整数。

**观察与规模：** L,R≤2×10^9，先处理F(L-1)负上界；前导0不能参与相邻差检查，数字0本身不接受。 上界可有上万位，枚举每个数不可能；合法性由相邻数字或数位和决定。

**朴素思路：** 直接从1枚举到上界，即使检查单个数很快也无法完成。记住整个前缀又会有指数个状态。

**关键突破：** 只保留前缀对未来的影响，另加tight表示当前前缀是否仍等于上界。

**状态与建模：** dp\[s\]\[tight\]为已处理位置、自动机状态s及紧贴标记的前缀数。Windy状态0表示未开始，其余表示末位；Digit Sum状态是数位和模D。

**本题映射：** 统计区间内相邻十进制数位之差至少2的正整数。 状态仅需前一有效数位，前导零有独立状态。 windy配置，然后qur(R)-qur(L-1)。

**转移与正确性：** 枚举当前位d≤hi，经go\[s\]\[d\]转移至v，非法转移-1跳过；新tight=旧tight且d等于当前上界位。每个数字串对应唯一逐位路径。

**初始化与顺序：** 空前缀dp\[initial\]\[1\]=1，逐位正序并清空tmp。Windy前导0留在未开始状态，末位状态才接受；Digit Sum允许全0，最后减1去掉数字0。区间用F(R)-F(L-1)。

**优化与限制：** 时间O(位数×状态数×10)，空间O(状态数)。不取模时答案须能放入64位；相邻差限制的状态不能把未开始和末位0混为一谈。

**本题复杂度：** O(位数*110)时间、O(11)空间。

## 例题 2：DP_S Digit Sum

[原题](https://atcoder.jp/contests/dp/tasks/dp_s)

**题意：** 1..K中数位和能被D整除的数字个数，K可达10000位。

**观察与规模：** K可达10000位，D≤100；应将数位和只保留模D，不能把上界转成64位整数。 上界可有上万位，枚举每个数不可能；合法性由相邻数字或数位和决定。

## 共同思路与易错点

- 数数三不把前导0当有效位；digit_sum接受0，例题需减去。
- mod=0仅在总计数不会溢出long long时使用。
- 原框架的x+1与当前含上界API不同，区间统一qur(R)-qur(L-1)。
