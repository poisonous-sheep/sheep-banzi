# 二状态树形背包

**类型：** 思维型

**适用场景：** 每点选0/1状态，价值来自点费用和父子状态费用；背包维记录状态1点数，覆盖原Monster Hunter模型。

**复杂度与条件：** 按真实子树规模合并O(n²)时间；保存全部节点DP最坏O(n²)空间。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 只需把当前根的二值状态作为子树与外界的接口，父子之间的额外代价留到合并时付。

**状态与建模：** dp\[u\]\[k\]\[a\]为u子树特殊操作恰用k次、u状态a的最小费用。cost\[u\]\[a\]是点费用，edge_cost\[v\]\[a\]\[b\]是父u和子v状态对应的边费用。

**优化与限制：** 子树数量裁剪后总体O(n^2)时间/空间上界。Monster Hunter必须按k输出，保留数量表；P2016仅求最少哨兵，下一例压成经典两状态O(n)，无需额外数量维。

## 例题 1：Gym102992M Monster Hunter

[原题](https://codeforces.com/gym/102992/problem/M)

**题意：** 有限魔法可无成本杀任意怪，普通杀怪受父亲和存活孩子血量影响，求每个魔法次数的最小总力量。

**观察与规模：** n≤2000，施法次数k从0到n全部输出；父子都普通时子怪物多一次hp，点费和额外边费各付一次。 父子选择存在相互作用，且要按使用特殊操作数量输出最小代价；一个数量维无法判断边的费用。

**朴素思路：** 枚举施法/选择节点子集指数级；只记用了k次，会把父亲是否施法的信息丢掉。

**关键突破：** 只需把当前根的二值状态作为子树与外界的接口，父子之间的额外代价留到合并时付。

**状态与建模：** dp\[u\]\[k\]\[a\]为u子树特殊操作恰用k次、u状态a的最小费用。cost\[u\]\[a\]是点费用，edge_cost\[v\]\[a\]\[b\]是父u和子v状态对应的边费用。

**本题映射：** 有限魔法可无成本杀任意怪，普通杀怪受父亲和存活孩子血量影响，求每个魔法次数的最小总力量。 先施放所有魔法；普通点自己的hp付一次，只有父子均普通时，子hp还会在父亲被杀时再付一次。 普通cost=hp、魔法cost=0；edge_cost\[v\]\[0\]\[0\]=hp\[v\]，run后输出全部k。

**转移与正确性：** tmp\[i+j\]\[a\]=min(dp\[u\]\[i\]\[a\]+dp\[v\]\[j\]\[b\]+edge_cost\[v\]\[a\]\[b\])，枚举a,b∈{0,1}。Monster Hunter普通击杀点费hp；仅父子均普通时额外再付子hp，施法计入k且点费0。顶点覆盖把父子均不选设INF。

**初始化与顺序：** 初始dp\[u\]\[0\]\[0\]=cost\[u\]\[0\]，dp\[u\]\[1\]\[1\]=cost\[u\]\[1\]，其余INF。后序逐孩子合并，tmp置INF，禁止从无效状态做加法。

**优化与限制：** 子树数量裁剪后总体O(n^2)时间/空间上界。Monster Hunter必须按k输出，保留数量表；P2016仅求最少哨兵，下一例压成经典两状态O(n)，无需额外数量维。

**本题复杂度：** O(n²)时间/空间。

[完整函数题解](%E4%BE%8B%E9%A2%98/Gym102992M-Monster%20Hunter-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 两层状态分别回答“用了多少资源”和“外界要知道根是什么状态”。边上兼容性用禁止状态或额外费用表达，比口头假设更容易检验。

## 例题 2：P2016 战略游戏

[原题](https://www.luogu.com.cn/problem/P2016)

**题意：** 树上选最少士兵，使每条边至少一个端点被选。

**观察与规模：** n≤1500，树边只给一次但方向任意，求覆盖每条边的最少哨兵；没有要求输出每个选点数量。

**朴素思路：** 枚举哨兵点集2^n；给每条未覆盖边随便选一端，不保证最少点数。

**关键突破：** 一条父子边是否覆盖只与两个端点是否选有关，根的二值状态就是对子树外的充分接口。

**状态与建模：** dp\[u\]\[0\]为u不选时覆盖其子树内部全部边的最少点数；dp\[u\]\[1\]为u选时的相同目标。此直接题解省去Monster Hunter的数量维。

**转移与正确性：** u不选时每个孩子v必须选，dp\[u\]\[0\]=Σdp\[v\]\[1\]；u选时边已覆盖，孩子可取两态最小，dp\[u\]\[1\]=1+Σmin(dp\[v\]\[0\],dp\[v\]\[1\])。孩子之间无边，所以独立相加。

**初始化与顺序：** 叶子两态为0和1；建立无向图，以0为根后序DFS，跳过父亲，最后取根的两态最小。单点树答案0。

**优化与限制：** O(n)时间/空间。输入0基原样使用，不把任意输入方向当父子方向。若图有环，父亲跳边不够且独立相加失效。

**本题复杂度：** O(n)时间、O(n)邻接、状态及递归空间。

[完整函数题解](%E4%BE%8B%E9%A2%98/P2016-%E6%88%98%E7%95%A5%E6%B8%B8%E6%88%8F-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 只在题目需要按资源数量输出时才增加背包维度；同一个二值树模型可以从一般数量DP压到两状态。

## 共同思路与易错点

- 原Monster Hunter已把hp[v]包含在子DP中，父状态0子状态0只额外加hp[v]，不能再加2hp[v]。
- 所有边和点费用累计须远小于INF；不可达先判断再相加。
- 边费用依赖父子状态，不能把状态维省略。

共同启发：两层状态分别回答“用了多少资源”和“外界要知道根是什么状态”。边上兼容性用禁止状态或额外费用表达，比口头假设更容易检验。
