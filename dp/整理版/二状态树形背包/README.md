# 二状态树形背包

**用途与条件：** 每点选0/1状态，价值来自点费用和父子状态费用；背包维记录状态1点数，覆盖原Monster Hunter模型。

**复杂度：** 按真实子树规模合并O(n²)时间；保存全部节点DP最坏O(n²)空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `cost[u][state]`：点选择两状态的费用
- `edge_cost[v][父状态][子状态]`：父子费用，INF禁止组合
- `run(root)`：返回恰好k个状态1点的最小费用数组

## 例题

### Gym102992M Monster Hunter

[原题](https://codeforces.com/gym/102992/problem/M)

**题意：** 有限魔法可无成本杀任意怪，普通杀怪受父亲和存活孩子血量影响，求每个魔法次数的最小总力量。

**为什么使用：** 先施放所有魔法；普通点自己的hp付一次，只有父子均普通时，子hp还会在父亲被杀时再付一次。

**如何调用：** 普通cost=hp、魔法cost=0；edge_cost[v][0][0]=hp[v]，run后输出全部k。

**复杂度：** O(n²)时间/空间。

### P2016 战略游戏

[原题](https://www.luogu.com.cn/problem/P2016)

**题意：** 树上选最少士兵，使每条边至少一个端点被选。

**为什么使用：** 每点0/1表示放不放，费用0/1；父子都不放的边状态禁止，就是树最小点覆盖。

**如何调用：** 先建立无向邻接表，再DFS定根；cost={0,1}，父子均不选的边费用INF；run后取最小费用。

**复杂度：** 此统一背包版O(n²)时间/空间；只求最小值可去背包维得到O(n)专用DP。

## 易错点

- 原Monster Hunter已把hp[v]包含在子DP中，父状态0子状态0只额外加hp[v]，不能再加2hp[v]。
- 所有边和点费用累计须远小于INF；不可达先判断再相加。
- 边费用依赖父子状态，不能把状态维省略。
