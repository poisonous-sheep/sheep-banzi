# 二进制位贡献与Popcount计数

**类型：** 思维型

**适用场景：** 位独立贡献的乘法原理：原Meaningless Sequence加权和、按掩码统计1位次数、按popcount分类。

**复杂度与条件：** weighted O(L)时间/空间；masked O(log n)时间/O(1)空间；distribution O(log² n)时间/空间。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 每个小于N的数有唯一首次小于位置；此后后缀自由。独立一位的0/1权重为1/c，所以m位自由后缀权重和为(1+c)^m。

**状态与建模：** weighted的pre是固定前缀权重，ans累计已经小于上界的分支。distribution的ans\[k\]计数\[0,N\]恰有k个1的数；masked按位统计\[0,N\]该位为1的个数。

**优化与限制：** weighted O(位数)，distribution O(位数^2)，masked O(位数)。P4317对每类k做k^cnt\[k\]后相乘，0只有数字0并被排除。指数是精确计数，不能先模答案模数。

## 例题 1：Gym102832D Meaningless Sequence

[原题](https://codeforces.com/gym/102832/problem/D)

**题意：** 按原递推定义序列，求0..N的项和，N用二进制给出。

**观察与规模：** N为二进制字符串，目标Σc^popcount(i)；分支权重相乘而非置位数相加，答案包含0及N。 上界很大，目标由置位数、某些位的贡献或置位数的乘积决定；不能按数枚举。

**朴素思路：** 枚举0..N逐个popcount是O(N)。按位统计时若不分“首次小于上界”的位置，会重复或遗漏数。

**关键突破：** 每个小于N的数有唯一首次小于位置；此后后缀自由。独立一位的0/1权重为1/c，所以m位自由后缀权重和为(1+c)^m。

**状态与建模：** weighted的pre是固定前缀权重，ans累计已经小于上界的分支。distribution的ans\[k\]计数\[0,N\]恰有k个1的数；masked按位统计\[0,N\]该位为1的个数。

**本题映射：** 按原递推定义序列，求0..N的项和，N用二进制给出。 递推可化为c^popcount；首次低于上界后，剩余自由位贡献(1+c)^剩余位。 PopcountDP(1e9+7).weighted(N,c)。

**转移与正确性：** 上界某位为1时可放0，加入pre×(1+c)^剩余位，再沿等于分支令pre乘c。分布版加入C(剩余位,k)并累积已见1数。按位周期为2^(b+1)，整段各有2^b个1，余段再算超出前半的长度。

**初始化与顺序：** weighted从高位到低位，末尾加N本身。组合表C\[0\]\[0\]=1，Pascal递推；分布最后加N所在桶。周期长度与N+1用__int128，避免60位附近加法溢出。

**优化与限制：** weighted O(位数)，distribution O(位数^2)，masked O(位数)。P4317对每类k做k^cnt\[k\]后相乘，0只有数字0并被排除。指数是精确计数，不能先模答案模数。

**本题复杂度：** O(|N|)时间与空间。

[完整函数题解](%E4%BE%8B%E9%A2%98/Gym102832D-Meaningless%20Sequence-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 先问贡献可否按位线性拆开；乘积则按相同贡献分组。前缀分类和周期统计是两种不同工具，不能把所有位强行套同一个DP。

## 例题 2：ABC356D Masked Popcount

[原题](https://atcoder.jp/contests/abc356/tasks/abc356_d)

**题意：** 求0..N每个数与M按位与后的popcount总和。

## 共同思路与易错点

- 前导0在二进制统计中不改变popcount。
- c=0时0^0按序列a0=1处理，weighted仍正确。
- distribution输出精确指数，不对mod取模；指数模数也不能随意用答案模数。

共同启发：先问贡献可否按位线性拆开；乘积则按相同贡献分组。前缀分类和周期统计是两种不同工具，不能把所有位强行套同一个DP。
