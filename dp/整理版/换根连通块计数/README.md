# 换根连通块计数

**用途与条件：** 计算每点被包含的连通点集数量；前后缀乘积移除一个孩子，支持非素数模。

**复杂度：** O(n)时间与空间，mod<=1e9+7。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init/add_edge`：无向树与正模数
- `run(root)`：dp为含u子树块数，pd为父侧块数，ans为整树含u块数

## 例题

### DP_V Subtree

[原题](https://atcoder.jp/contests/dp/tasks/dp_v)

**题意：** 给每点求该点为黑且全部黑点连通的染色数。

**为什么使用：** 黑点集合就是包含指定点的连通点集，每个孩子选或不选。

**如何调用：** 读mod和树，run，逐行输出ans。

**复杂度：** O(n)时间与空间。

### CF543D Road Improvement

[原题](https://codeforces.com/contest/543/problem/D)

**题意：** 对每个首都，统计满足各路径最多一条未修路的道路修复方式。

**为什么使用：** 以首都为根时，若父边未修，整棵子树内所有边必须修；否则子树继续有dp种选择，所以同样是(dp[v]+1)乘积。

**如何调用：** 输入2..n父节点，add_edge，run；输出ans。

**复杂度：** O(n)时间与空间。

## 易错点

- 不能用逆元除去孩子贡献，非素数模或零贡献时不成立。
- 局部前后缀数组不会被递归覆盖；原共享数组需先算所有孩子再递归。
- 乘法两次取模，避免三个因子直接相乘溢出。
