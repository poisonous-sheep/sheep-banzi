# 换根连通块计数

**类型：** 思维型

**适用场景：** 计算每点被包含的连通点集数量；前后缀乘积移除一个孩子，支持非素数模。

**复杂度与条件：** O(n)时间与空间，mod<=1e9+7。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 树的每个邻接方向独立，每个方向要么不选，要么选一个与u连通的方案。

**状态与建模：** dp\[u\]为向下包含u的方案数；pd\[u\]为父方向必须连接父端点的方案数，不含“全部不选”选项。ans\[u\]=dp\[u\]×(pd\[u\]+1)。

**优化与限制：** 前后缀将每点所有孩子的排除乘积总计降至O(度数)，整体O(n)/O(n)。CF543D把坏边集合沿根路径最多一条解释为边界切断，等价选择含根的连通核心。

## 例题 1：DP_V Subtree

[原题](https://atcoder.jp/contests/dp/tasks/dp_v)

**题意：** 给每点求该点为黑且全部黑点连通的染色数。

**观察与规模：** 1<M≤10^9且不保证素数，前后缀不能换成逆元；选择的黑点连通，必须包含当前被询问的点。 对每个点分别询问含它的合法连通选择；模数可能合数，不能依赖乘法逆元。

**朴素思路：** 每个点重新根化做一次树DP是O(n^2)；将总乘积除以孩子因子在因子为0或模数非素数时失效。

**关键突破：** 树的每个邻接方向独立，每个方向要么不选，要么选一个与u连通的方案。

**状态与建模：** dp\[u\]为向下包含u的方案数；pd\[u\]为父方向必须连接父端点的方案数，不含“全部不选”选项。ans\[u\]=dp\[u\]×(pd\[u\]+1)。

**本题映射：** 给每点求该点为黑且全部黑点连通的染色数。 黑点集合就是包含指定点的连通点集，每个孩子选或不选。 读mod和树，run，逐行输出ans。

**转移与正确性：** dp\[u\]=Π(dp\[v\]+1)。给孩子v的pd\[v\]=(pd\[u\]+1)×其余孩子因子乘积；pre/suf提供排除单个孩子的乘积。独立方向相乘、不选加1，连通性使分解唯一。

**初始化与顺序：** 叶子dp=1表示只选自己；根pd=0表示父方向不存在。先后序算dp，再先序算pd；pre\[0\]=suf\[m\]=1(mod M)。

**优化与限制：** 前后缀将每点所有孩子的排除乘积总计降至O(度数)，整体O(n)/O(n)。CF543D把坏边集合沿根路径最多一条解释为边界切断，等价选择含根的连通核心。

**本题复杂度：** O(n)时间与空间。

**启发式总结：** 多次“排除一个贡献”的转移优先考虑前后缀；乘法有零或模数合数时尤其不能用除法偷懒。

## 例题 2：CF543D Road Improvement

## 共同思路与易错点

- 不能用逆元除去孩子贡献，非素数模或零贡献时不成立。
- 局部前后缀数组不会被递归覆盖；原共享数组需先算所有孩子再递归。
- 乘法两次取模，避免三个因子直接相乘溢出。

共同启发：多次“排除一个贡献”的转移优先考虑前后缀；乘法有零或模数合数时尤其不能用除法偷懒。
