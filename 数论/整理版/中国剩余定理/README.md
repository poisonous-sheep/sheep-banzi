# 中国剩余定理

**用途与条件：** 逐式合并同余，兼容两两互质CRT与非互质扩展CRT。

**复杂度：** n条同余约O(n log M)时间，额外O(log M)递归空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init()`：初始x=0 mod1
- `merge(r,m)`：合并x=r mod m，矛盾返回false
- `ans/mod`：最小非负解与合并模数

[原题](https://www.luogu.com.cn/problem/P1495)

**题意：** 给若干除数和余数，求满足条件的最小猪数。

**为什么使用：** 各同余两两互质，是普通CRT。

**如何调用：** 读入m,r后merge(r,m)，输出ans。

**复杂度：** O(n log M)时间。

## 易错点

- 最小公倍数须在long long内；中间乘积用__int128。
- 原CRT仅互质，本版merge增加gcd整除判断，保留exgcd解法。
