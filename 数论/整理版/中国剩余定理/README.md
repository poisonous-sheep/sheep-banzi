# 中国剩余定理

**类型：** 模板型

**适用场景：** 逐式合并同余，兼容两两互质CRT与非互质扩展CRT。

**复杂度与条件：** n条同余约O(n log M)时间，额外O(log M)递归空间。

[完整C++17板子](模板.cpp)。

## 核心接口

- `init()`：初始x=0 mod1
- `merge(r,m)`：合并x=r mod m，矛盾返回false
- `ans/mod`：最小非负解与合并模数
