# 扩展Lucas

**类型：** 模板型

**适用场景：** 合数模组合数，按质数幂去除阶乘质因子后CRT；单质数幂<=2e6。

**复杂度与条件：** 预处理O(sqrt M+Σp^e)，每问O(Σlog_p n*log(p^e))，空间O(Σp^e)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `init(M)`：允许M=1；分解并预处理非p因子阶乘
- `binom(n,m)`：合数模组合数

## 共同思路与易错点

- 阶乘单位部分才能求逆；质因子指数单独乘p^exp。
- 大质数幂不能直接开fac；明确O(p^e)限制。
- 重建时parts清空，修复固定大数组与负指数处理风险。
