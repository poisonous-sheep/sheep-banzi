# 扩展Lucas

**用途与条件：** 合数模组合数，按质数幂去除阶乘质因子后CRT；单质数幂<=2e6。

**复杂度：** 预处理O(sqrt M+Σp^e)，每问O(Σlog_p n*log(p^e))，空间O(Σp^e)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(M)`：允许M=1；分解并预处理非p因子阶乘
- `binom(n,m)`：合数模组合数

### P2183 礼物

[原题](https://www.luogu.com.cn/problem/P2183)

**题意：** n件不同礼物分给m人，每人指定件数，模合数p求方案。

**为什么使用：** 多项式系数可写成依次选人的组合数连乘；同一个模数复用预处理。

**如何调用：** 先判断需求总和<=n；逐人binom(remaining,wi)后扣减。

**复杂度：** 预处理一次，加m次组合数查询；空间Σp^e。

## 易错点

- 阶乘单位部分才能求逆；质因子指数单独乘p^exp。
- 大质数幂不能直接开fac；明确O(p^e)限制。
- 重建时parts清空，修复固定大数组与负指数处理风险。
