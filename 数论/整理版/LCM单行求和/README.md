# LCM单行求和

**类型：** 思维型

**适用场景：** 求Σ(1<=i<=n)lcm(i,n)=n*(1+Σ(d|n)d*phi(d))/2。保留课堂按约数累加思路。

**复杂度与条件：** 批量init O(N log N)、O(N)空间；单点calc试除O(sqrt n)、O(log n)空间。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 按g=gcd(i,n)分组，令d=n/g、i=gk，则gcd(k,d)=1且lcm(i,n)=nk。

**状态与建模：** 每个d|n对应一组单位k∈\[1,d\]。d>1时单位成对k与d-k，总和dφ(d)/2；d=1只有k=1，须单独修正。

**优化与限制：** 预处理O(Vlog V)，查询O(1)，空间O(V)；__int128保留中间值。SP5971/P1891是同一公式不同询问规模，作为批量策略对照，不冒充两种推导。

## 例题 1：SP5971 LCMSUM - LCM Sum

[原题](https://www.luogu.com.cn/problem/SP5971)

**题意：** 多组n求lcm(1,n)+...+lcm(n,n)。

**观察与规模：** 批量读询问共用筛，固定n后按gcd分类；与P1891相同公式，仅询问规模不同。 固定n求lcm(1,n)..lcm(n,n)；P1891有30万次询问，n≤10^6，预处理比逐次分解重要。

**朴素思路：** 每问枚举i并求gcd需O(nlog n)，多询问不可行。直接引用公式不解释约数类别容易把phi参数写反。

**关键突破：** 按g=gcd(i,n)分组，令d=n/g、i=gk，则gcd(k,d)=1且lcm(i,n)=nk。

**状态与建模：** 每个d|n对应一组单位k∈\[1,d\]。d>1时单位成对k与d-k，总和dφ(d)/2；d=1只有k=1，须单独修正。

**本题映射：** 多组n求lcm(1,n)+...+lcm(n,n)。 同一筛可预处理全部约数和，适合n<=1e6的多次查询。 读全部n，init(max n)，每次qur并print128。

**转移与正确性：** 答案=n/2×(1+Σ_(d|n)dφ(d))。括号中的额外1正是d=1的修正，各gcd类别互不相交。筛f\[j\]+=dφ(d)得到所有约数和，也可用积性函数按素数幂计算。

**初始化与顺序：** f全0，从d=1枚举到最大询问值，再给所有倍数加贡献。先读全部询问确定上界；n=1答案1。整数先算n×(f\[n\]+1)再精确除2。

**优化与限制：** 预处理O(Vlog V)，查询O(1)，空间O(V)；__int128保留中间值。SP5971/P1891是同一公式不同询问规模，作为批量策略对照，不冒充两种推导。

**本题复杂度：** O(N log N+T)时间、O(N+T)空间。

组合依赖：[莫比乌斯反演与线性筛](../%E8%8E%AB%E6%AF%94%E4%B9%8C%E6%96%AF%E5%8F%8D%E6%BC%94%E4%B8%8E%E7%BA%BF%E6%80%A7%E7%AD%9B/%E6%A8%A1%E6%9D%BF.cpp)的struct定义（去掉其演示solve/main），再与本题代码编译。

[题解及辅助代码](%E4%BE%8B%E9%A2%98/SP5971-LCMSUM%20-%20LCM%20Sum-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 固定参数的GCD/LCM和常按公共因子分类。最终除2应来自配对，d=1这种配对不成立的边界必须单列。

## 共同思路与易错点

- 整数式必须先保留精确分子再除2，不能在偶数模数下直接乘逆元。
- 返回__int128，n<=1e9时可用此范围；打印使用print128。

共同启发：固定参数的GCD/LCM和常按公共因子分类。最终除2应来自配对，d=1这种配对不成立的边界必须单列。
