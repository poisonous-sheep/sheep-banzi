# LCM单行求和

**用途与条件：** 求Σ(1<=i<=n)lcm(i,n)=n*(1+Σ(d|n)d*phi(d))/2。保留课堂按约数累加思路。

**复杂度：** 批量init O(N log N)、O(N)空间；单点calc试除O(sqrt n)、O(log n)空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(N)/qur(n)`：批量筛到N，查询精确128位结果
- `calc(n)`：大n先因式分解，利用积性乘积计算

## 例题

### SP5971 LCMSUM - LCM Sum

[原题](https://www.luogu.com.cn/problem/SP5971)

**题意：** 多组n求lcm(1,n)+...+lcm(n,n)。

**为什么使用：** 同一筛可预处理全部约数和，适合n<=1e6的多次查询。

**如何调用：** 读全部n，init(max n)，每次qur并print128。

**复杂度：** O(N log N+T)时间、O(N+T)空间。

## 易错点

- 整数式必须先保留精确分子再除2，不能在偶数模数下直接乘逆元。
- 返回__int128，n<=1e9时可用此范围；打印使用print128。
