# Lucas定理

**用途与条件：** 大n、小素数p的组合数模p；保留逐p进制位乘binom。

**复杂度：** 预处理O(p)，单问O(log_p n)，空间O(p)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(p)`：素数p，按p实际分配
- `binom(n,m)`：按p进制分解
- `powmod(a,b)`：同模数快速幂

## 例题

### P3807 Lucas定理

[原题](https://www.luogu.com.cn/problem/P3807)

**题意：** 多组求C(n+m,n) mod p。

**为什么使用：** n可大于p，逐位Lucas降为小组合数。

**如何调用：** 每个p重新init，binom(n+m,n)。

**复杂度：** 每组O(p+log_p(n+m))时间、O(p)空间。

### P1313 计算系数

[原题](https://www.luogu.com.cn/problem/P1313)

**题意：** 求(ax+by)^k中x^n*y^m的系数模10007。

**为什么使用：** 二项式定理给C(k,n)*a^n*b^m；Lucas负责组合数部分。

**如何调用：** init(10007)，binom与powmod组合。

**复杂度：** O(10007+log k)时间、O(10007)空间。

## 易错点

- p必须素数；p很大时O(p)预处理会MLE/TLE。
- n+m不得溢出long long。
