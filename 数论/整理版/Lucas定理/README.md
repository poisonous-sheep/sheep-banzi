# Lucas定理

**类型：** 模板型

**适用场景：** 大n、小素数p的组合数模p；保留逐p进制位乘binom。

**复杂度与条件：** 预处理O(p)，单问O(log_p n)，空间O(p)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `init(p)`：素数p，按p实际分配
- `binom(n,m)`：按p进制分解
- `powmod(a,b)`：同模数快速幂

## 共同思路与易错点
