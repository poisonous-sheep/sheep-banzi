# 互质集合与GCD分类计数

**类型：** 思维型

**适用场景：** 统计非空下标子集的gcd；按倍数统计与反演恢复恰好gcd=d的子集权重。

**复杂度与条件：** O(V log V+n)时间、O(V+n)空间，V=max(a)。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** “GCD等于d”难直接数，“所有数被d整除”容易数，再按倍数关系反演。

**状态与建模：** cnt\[d\]是d的倍数元素个数。CF803F统计非空下标子集；CF839D的exact\[d\]是GCD恰为d的所有子集的长度和，不是集合个数。

**优化与限制：** O(Vlog V+n)/O(V+n)，线性筛mu依赖已收录Mobius板子；无需逆元，模数条件比阶乘法宽。元素0不能按正整数倍数枚举。

## 例题 1：CF803F Coprime Subsequences

[原题](https://codeforces.com/contest/803/problem/F)

**题意：** 求gcd为1的非空子序列数。

**观察与规模：** 空子集没有GCD且必须去掉；重复值按不同下标计，频次进入2^cnt而不是只看distinct值。 子序列由选中下标确定，重复数值仍是不同选择；值域允许枚举倍数。

**朴素思路：** 枚举非空子集2^n；直接按GCD做DP在大值域上可能状态和转移过多。

**关键突破：** “GCD等于d”难直接数，“所有数被d整除”容易数，再按倍数关系反演。

**状态与建模：** cnt\[d\]是d的倍数元素个数。CF803F统计非空下标子集；CF839D的exact\[d\]是GCD恰为d的所有子集的长度和，不是集合个数。

**本题映射：** 求gcd为1的非空子序列数。 选择下标后顺序唯一，因此子序列数等于下标子集数。每个d的候选有2^cnt\[d\]-1个。 读数组构造CoprimeSet，输出qur。

**转移与正确性：** CF803F答案Σmu\[d\](2^cnt\[d\]-1)，每个集合贡献Σ_(d|gcd)mu\[d\]，恰gcd=1时为1。CF839D总长度和为c×2^(c-1)，因为固定每个元素有2^(c-1)个包含它的子集；减所有更大倍数exact后乘d累加d>1。

**初始化与顺序：** 频次先按值累加，cnt按倍数求和；pw\[0\]=1。exact从大d到小d计算，c=0贡献0，不能访问pw\[-1\]。模减统一归一化。

**优化与限制：** O(Vlog V+n)/O(V+n)，线性筛mu依赖已收录Mobius板子；无需逆元，模数条件比阶乘法宽。元素0不能按正整数倍数枚举。

**本题复杂度：** O(V log V+n)时间、O(V+n)空间。

组合依赖：[莫比乌斯反演与线性筛](../%E8%8E%AB%E6%AF%94%E4%B9%8C%E6%96%AF%E5%8F%8D%E6%BC%94%E4%B8%8E%E7%BA%BF%E6%80%A7%E7%AD%9B/%E6%A8%A1%E6%9D%BF.cpp)的struct定义（去掉其演示solve/main），再与本题代码编译。

[题解及辅助代码](%E4%BE%8B%E9%A2%98/CF803F-Coprime%20Subsequences-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 计数先写清对象是下标子集，再选择“整除”这一容易统计的上集；带权计数应先推导所有上集的权重和再反演。

## 共同思路与易错点

- 不同下标视为不同选择，重复值不可去重。
- 减法取模需归一化；空集必须扣掉。
- 不是两两互质，而是整个子集gcd为1。

共同启发：计数先写清对象是下标子集，再选择“整除”这一容易统计的上集；带权计数应先推导所有上集的权重和再反演。
