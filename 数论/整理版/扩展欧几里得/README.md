# 扩展欧几里得

**用途与条件：** 求Bezout系数、模逆元与线性同余最小非负解；模数为正。

**复杂度：** O(log m)时间与递归空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `exgcd(a,b,x,y)`：非负a,b，返回gcd并使ax+by=gcd
- `inverse(a,m)`：不存在返回-1
- `linear(a,b,m)`：ax=b mod m，返回最小非负解或-1

### P1082 同余方程

[原题](https://www.luogu.com.cn/problem/P1082)

**题意：** 求ax=1 mod b的最小正整数解。

**为什么使用：** 题目互质，扩展欧几里得系数给逆元。

**如何调用：** inverse(a,b)，将0按正解约定改成b。

**复杂度：** O(log b)时间与空间。

### ABC186E Throne

[原题](https://atcoder.jp/contests/abc186/tasks/abc186_e)

**题意：** 从位置S每次走K，最少几次回到模N的0点。

**为什么使用：** K*x=-S mod N，gcd整除目标才有解。

**如何调用：** 每组linear(K,-S,N)。

**复杂度：** O(T log N)时间、O(log N)空间。

## 易错点

- 取模后需归一化负余数。
- 系数递推与模数合并需评估溢出；乘积取模用__int128。
