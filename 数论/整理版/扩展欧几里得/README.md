# 扩展欧几里得

**类型：** 模板型

**适用场景：** 求Bezout系数、模逆元与线性同余最小非负解；模数为正。

**复杂度与条件：** O(log m)时间与递归空间。

[完整C++17板子](模板.cpp)。

## 核心接口

- `exgcd(a,b,x,y)`：非负a,b，返回gcd并使ax+by=gcd
- `inverse(a,m)`：不存在返回-1
- `linear(a,b,m)`：ax=b mod m，返回最小非负解或-1
