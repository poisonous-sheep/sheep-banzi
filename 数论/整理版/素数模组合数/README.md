# 素数模组合数

**类型：** 模板型

**适用场景：** 阶乘与逆阶乘计算组合数；p为素数，预处理范围n<p。

**复杂度与条件：** 预处理O(n+log p)，每问O(1)，空间O(n)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `init(n,p)`：要求素数p且n<p
- `binom(n,m)`：非法m返回0
- `powmod(a,b)`：b非负
