# 素数模组合数

**用途与条件：** 阶乘与逆阶乘计算组合数；p为素数，预处理范围n<p。

**复杂度：** 预处理O(n+log p)，每问O(1)，空间O(n)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(n,p)`：要求素数p且n<p
- `binom(n,m)`：非法m返回0
- `powmod(a,b)`：b非负

## 例题

### ABC034C 経路

[原题](https://atcoder.jp/contests/abc034/tasks/abc034_c)

**题意：** W乘H网格从左上向右下仅向右或下走，求路径数。

**为什么使用：** 总步数W+H-2，选W-1步向右。

**如何调用：** init(W+H-2)，binom(total,W-1)。

**复杂度：** O(W+H)时间与空间。

### ABC145D Knight

[原题](https://atcoder.jp/contests/abc145/tasks/abc145_d)

**题意：** 每步(1,2)或(2,1)，求走到(X,Y)方案数。

**为什么使用：** 求两种步数a=(2Y-X)/3、b=(2X-Y)/3，非负整数时组合数计排列。

**如何调用：** 检查整除与非负；init(a+b)，binom(a+b,a)。

**复杂度：** O(X+Y)时间与空间上界。

## 易错点

- 跨过模数后阶乘为0，不能求逆，应使用Lucas。
- 普通乘积在本例mod1e9+7内安全；powmod宽整数支持。
