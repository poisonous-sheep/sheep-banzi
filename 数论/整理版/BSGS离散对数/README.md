# BSGS离散对数

**类型：** 模板型

**适用场景：** 求a^x=b mod m的最小非负x；保留map大步小步思路，并扩展非互质约除。

**复杂度与条件：** O(sqrt m log m)时间、O(sqrt m)空间。

[完整C++17板子](模板.cpp)。

## 核心接口

- `solve(a,b,m)`：最小非负解；不存在-1
- `unit(a,b,m)`：内部仅用于gcd(a,m)=1
