# BSGS离散对数

**用途与条件：** 求a^x=b mod m的最小非负x；保留map大步小步思路，并扩展非互质约除。

**复杂度：** O(sqrt m log m)时间、O(sqrt m)空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `solve(a,b,m)`：最小非负解；不存在-1
- `unit(a,b,m)`：内部仅用于gcd(a,m)=1

## 例题

### P3846 可爱的质数

[原题](https://www.luogu.com.cn/problem/P3846)

**题意：** 输入p,b,n，求b^x=n mod p。

**为什么使用：** 素数模下通常互质，直接用BSGS。

**如何调用：** solve(b,n,p)，无解输出no solution。

**复杂度：** O(sqrt p log p)时间、O(sqrt p)空间。

## 易错点

- 先处理x=0与m=1；普通BSGS不能裸用于非互质。
- 重复baby值保留最小指数以保证最小解。
