# 卡特兰数与反射原理

**类型：** 思维型

**适用场景：** 计数栈出入、合法括号与不越界格路径；精确递推与反射法的组合数差。

**复杂度与条件：** exact O(n)时间/O(1)空间；ballot O(n+m)时间/空间。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 把首次跌到-1之前的上/下步交换，得到与非法路径一一对应的无约束路径。

**状态与建模：** P1044是n次入n次出的合法操作序列，与出栈排列一一对应。P1641是n个A上步、m个B下步的合法路径。

**优化与限制：** 精确64位只支持n≤35，计算中间__int128。模组合需素数p且n+m<p；减法加模数归一化。边界限制改变，反射计数也会改变。

## 例题 1：P1044 栈

[原题](https://www.luogu.com.cn/problem/P1044)

**题意：** 顺序入栈的n个数有多少种合法出栈序列。

**观察与规模：** 出栈序列与合法操作路径一一对应，因为入栈顺序固定；精确答案n≤18，无需取模。 入栈/出栈或A/B排列都有“任何前缀余额不负”的限制；总数量只是必要条件。

**朴素思路：** 直接组合数C(n+m,m)包含先出后入或B先占优的非法前缀；枚举串指数级。

**关键突破：** 把首次跌到-1之前的上/下步交换，得到与非法路径一一对应的无约束路径。

**状态与建模：** P1044是n次入n次出的合法操作序列，与出栈排列一一对应。P1641是n个A上步、m个B下步的合法路径。

**本题映射：** 顺序入栈的n个数有多少种合法出栈序列。 入栈和出栈分别是上步和下步，任意前缀不能出栈多于入栈。 调用exact(n)。

**转移与正确性：** 总数C(n+m,m)，非法数C(n+m,m-1)，答案相减；反射的逆映射取首次到+1，证明双射。n=m得Catalan C(2n,n)/(n+1)，也可按第一个匹配对拆成C\[i\]C\[n-1-i\]递推。

**初始化与顺序：** n<m直接0，n=0的Catalan=1。精确递推C_i=C_(i-1)×2(2i-1)/(i+1)，每一步整除；模版用组合差，避免不合法逆元。

**优化与限制：** 精确64位只支持n≤35，计算中间__int128。模组合需素数p且n+m<p；减法加模数归一化。边界限制改变，反射计数也会改变。

**本题复杂度：** O(n)时间、O(1)空间。

[完整函数题解](%E4%BE%8B%E9%A2%98/P1044-%E6%A0%88-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 遇到前缀不等式先转格路，找第一次违反的位置构造双射；不能只背Catalan数字而忽略总步数是否相等。

## 例题 2：P1641 生成字符串

[原题](https://www.luogu.com.cn/problem/P1641)

**题意：** 由n个A和m个B组成字符串，每个前缀A数不少于B数。

**观察与规模：** n和m可不相等，不能使用仅n=m的Catalan公式；答案C(n+m,m)-C(n+m,m-1)。 入栈/出栈或A/B排列都有“任何前缀余额不负”的限制；总数量只是必要条件。

**朴素思路：** 直接组合数C(n+m,m)包含先出后入或B先占优的非法前缀；枚举串指数级。

**关键突破：** 把首次跌到-1之前的上/下步交换，得到与非法路径一一对应的无约束路径。

**本题映射：** 由n个A和m个B组成字符串，每个前缀A数不少于B数。 将A/B映射上/下步；总数减去第一次越界后反射的非法路径数。 ballot(n,m,20100403)，不等数量也可使用。

**转移与正确性：** 总数C(n+m,m)，非法数C(n+m,m-1)，答案相减；反射的逆映射取首次到+1，证明双射。n=m得Catalan C(2n,n)/(n+1)，也可按第一个匹配对拆成C\[i\]C\[n-1-i\]递推。

## 共同思路与易错点

- Catalan(0)=1。35之后精确结果可能超long long。
- 组合数差公式不要求除n+1，可避免该分母模p为0的问题；本实现仍要求总长度<p。

共同启发：遇到前缀不等式先转格路，找第一次违反的位置构造双射；不能只背Catalan数字而忽略总步数是否相等。
