# 卡特兰数与反射原理

**用途与条件：** 计数栈出入、合法括号与不越界格路径；精确递推与反射法的组合数差。

**复杂度：** exact O(n)时间/O(1)空间；ballot O(n+m)时间/空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `exact(n)`：0..35的卡特兰数，返回long long
- `ballot(n,m,p)`：n个上步m个下步且所有前缀不低于0；p为素数且n+m<p

## 例题

### P1044 栈

[原题](https://www.luogu.com.cn/problem/P1044)

**题意：** 顺序入栈的n个数有多少种合法出栈序列。

**为什么使用：** 入栈和出栈分别是上步和下步，任意前缀不能出栈多于入栈。

**如何调用：** 调用exact(n)。

**复杂度：** O(n)时间、O(1)空间。

### P1641 生成字符串

[原题](https://www.luogu.com.cn/problem/P1641)

**题意：** 由n个A和m个B组成字符串，每个前缀A数不少于B数。

**为什么使用：** 将A/B映射上/下步；总数减去第一次越界后反射的非法路径数。

**如何调用：** ballot(n,m,20100403)，不等数量也可使用。

**复杂度：** O(n+m)时间与空间。

## 易错点

- Catalan(0)=1。35之后精确结果可能超long long。
- 组合数差公式不要求除n+1，可避免该分母模p为0的问题；本实现仍要求总长度<p。
