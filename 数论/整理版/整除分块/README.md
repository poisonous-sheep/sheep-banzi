# 整除分块

**类型：** 模板型

**适用场景：** 相同floor(n/i)的连续区间合并；同时支持两个商不变的分块。

**复杂度与条件：** 单商/双商分块O(sqrt n+sqrt m)，额外O(1)空间。

[完整C++17板子](模板.cpp)。

## 核心接口

- `run(n,calc)`：回调(l,r,n/l)
- `run(n,m,calc)`：同时商值不变
- `divisor_sum(n)`：1..n的约数和总和，返回宽整数
