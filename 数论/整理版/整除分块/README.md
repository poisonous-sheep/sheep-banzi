# 整除分块

**用途与条件：** 相同floor(n/i)的连续区间合并；同时支持两个商不变的分块。

**复杂度：** 单商/双商分块O(sqrt n+sqrt m)，额外O(1)空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `run(n,calc)`：回调(l,r,n/l)
- `run(n,m,calc)`：同时商值不变
- `divisor_sum(n)`：1..n的约数和总和，返回宽整数

## 例题

### P1403 约数研究

[原题](https://www.luogu.com.cn/problem/P1403)

**题意：** 求1..n每个数的约数个数之和。

**为什么使用：** 交换求和得到sum floor(n/d)，按相同商合并。

**如何调用：** count_divisors_sum(n)。

**复杂度：** O(sqrt n)时间、O(1)空间。

### P2424 约数和

[原题](https://www.luogu.com.cn/problem/P2424)

**题意：** 求区间[x,y]每个数的约数和之和。

**为什么使用：** 前缀=Σ d*floor(n/d)，块内d的和用等差数列。

**如何调用：** divisor_sum(y)-divisor_sum(x-1)，print宽整数。

**复杂度：** O(sqrt y)时间、O(1)额外空间。
