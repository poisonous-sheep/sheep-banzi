# 莫比乌斯反演与线性筛

**类型：** 模板型

**适用场景：** 线性筛mu与phi；利用互质指示函数和整除分块统计数对；保留原稿模2^32反演接口。

**复杂度与条件：** 筛O(N)时间/空间；coprime O(sqrt(min(a,b)))；invert32 O(N log N)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `init(N)`：筛1..N的最小素因子、mu、phi及mu前缀和
- `coprime(a,b)`：1<=x<=a、1<=y<=b且gcd=1的有序数对
- `invert32(f)`：已知f(n)=Σg(d)，在模2^32环内反演g
