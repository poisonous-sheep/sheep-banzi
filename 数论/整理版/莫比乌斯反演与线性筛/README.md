# 莫比乌斯反演与线性筛

**用途与条件：** 线性筛mu与phi；利用互质指示函数和整除分块统计数对；保留原稿模2^32反演接口。

**复杂度：** 筛O(N)时间/空间；coprime O(sqrt(min(a,b)))；invert32 O(N log N)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(N)`：筛1..N的最小素因子、mu、phi及mu前缀和
- `coprime(a,b)`：1<=x<=a、1<=y<=b且gcd=1的有序数对
- `invert32(f)`：已知f(n)=Σg(d)，在模2^32环内反演g

## 例题

### P2522 ZAP-Queries

[原题](https://www.luogu.com.cn/problem/P2522)

**题意：** 统计1..a和1..b中gcd(x,y)=d的数对。

**为什么使用：** 同时除以d，转为互质矩形计数。

**如何调用：** 离线读多组以求最大min(a/d,b/d)，init后coprime。

**复杂度：** O(N+T sqrt N)时间、O(N+T)空间。

### P3455 Problem b

[原题](https://www.luogu.com.cn/problem/P3455)

**题意：** 统计两个闭区间内gcd=k的数对。

## 易错点

- mu用有符号整数，原rng题unsigned运算用uint32_t保留32位溢出语义。
- 数对结果要求a*b不超long long；任一边为0返回0。
- 分块取两个商共同右端点。
