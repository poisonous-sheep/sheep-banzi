# LCM矩形与集合求和

**类型：** 思维型

**适用场景：** 用h(t)=t*Π(p|t)(1-p)整理莫比乌斯反演；矩形中用三角数，集合中用整倍数权重和。

**复杂度与条件：** 筛O(V)；矩形查询O(sqrt min(a,b))；集合O(V log V+n)；空间O(V+n)。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 把1/g改写成因数卷积：设c(t)=Σ_(k|t)mu(k)k，则Σ_(t|g)c(t)/t=1/g；于是h(t)=t c(t)为可筛积性函数。

**状态与建模：** 矩形的t类权重为h(t)S(floor(n/t))S(floor(m/t))，S(x)=x(x+1)/2。数组s\[t\]=Σ_(t|a_i)a_i/t，有序对贡献h(t)s\[t\]^2。

**优化与限制：** 矩形预处理O(V)，每问整除分块；数组O(Vlog V+N)。数组除2要求奇模数，矩形整数三角和不要求2可逆。乘法使用__int128，值域大仍有内存限制。

## 例题 1：P1829 Crash的数字表格

[原题](https://www.luogu.com.cn/problem/P1829)

**题意：** 求n乘m表格内全部lcm(i,j)，模20101009。

**观察与规模：** 矩形包含全部有序对，包括i=j；不能扣对角和除2。两个floor商必须同时在分块区间内恒定。 矩形求所有有序(i,j)，数组求下标无序对；两者都含lcm=ij/gcd，但计数对象不同。

**朴素思路：** 直接枚举全部数对O(nm)或O(N^2)；使用1/gcd的模逆既不普适又掩盖整除结构。

**关键突破：** 把1/g改写成因数卷积：设c(t)=Σ_(k|t)mu(k)k，则Σ_(t|g)c(t)/t=1/g；于是h(t)=t c(t)为可筛积性函数。

**状态与建模：** 矩形的t类权重为h(t)S(floor(n/t))S(floor(m/t))，S(x)=x(x+1)/2。数组s\[t\]=Σ_(t|a_i)a_i/t，有序对贡献h(t)s\[t\]^2。

**本题映射：** 求n乘m表格内全部lcm(i,j)，模20101009。 反演后仅需Σh(t)S(n/t)S(m/t)，两个商相同的区间可合并。 init(min(n,m),20101009)，输出qur(n,m)。

**转移与正确性：** 交换有限求和得到上述式；素数幂h(p^e)=p^e(1-p)，据此线性筛。数组先减Σa_i去掉i=j，再乘2的逆元，把两个方向合为一个i<j，不遗漏重复值不同下标。

**初始化与顺序：** h\[1\]=1，线性筛积性递推，pre求前缀。矩形按两个商都相同的区间聚合h；数组频次按倍数累加。S(x)先把偶因子除2，再取模。

**优化与限制：** 矩形预处理O(V)，每问整除分块；数组O(Vlog V+N)。数组除2要求奇模数，矩形整数三角和不要求2可逆。乘法使用__int128，值域大仍有内存限制。

**本题复杂度：** O(min(n,m))预处理，O(sqrt min(n,m))查询，O(min(n,m))空间。

## 共同思路与易错点

- h的负数需要归一化；课堂模2^60变体不能直接用有符号溢出替代。
- 三角数先整数除2再取模，支持偶数mod的矩形查询。
- pairs扣去对角再乘2的逆元，所以限定奇数mod。
