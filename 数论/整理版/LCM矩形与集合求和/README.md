# LCM矩形与集合求和

**用途与条件：** 用h(t)=t*Π(p|t)(1-p)整理莫比乌斯反演；矩形中用三角数，集合中用整倍数权重和。

**复杂度：** 筛O(V)；矩形查询O(sqrt min(a,b))；集合O(V log V+n)；空间O(V+n)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(V,mod)`：线性筛积性h及前缀和
- `qur(a,b)`：Σ1<=i<=a,1<=j<=b lcm(i,j)模mod
- `pairs(a)`：数组无序下标对i<j的LCM和；mod须为奇数

## 例题

### P1829 Crash的数字表格

[原题](https://www.luogu.com.cn/problem/P1829)

**题意：** 求n乘m表格内全部lcm(i,j)，模20101009。

**为什么使用：** 反演后仅需Σh(t)S(n/t)S(m/t)，两个商相同的区间可合并。

**如何调用：** init(min(n,m),20101009)，输出qur(n,m)。

**复杂度：** O(min(n,m))预处理，O(sqrt min(n,m))查询，O(min(n,m))空间。

### AGC038C LCMs

[原题](https://atcoder.jp/contests/agc038/tasks/agc038_c)

**题意：** 求数组中所有i<j的lcm(ai,aj)之和，模998244353。

**为什么使用：** 倍数元素的单位权重和S(d)替代矩形三角数；同一h反演后用平方统计有序对，再扣对角除2。

**如何调用：** init(max a,998244353)，pairs(a)。

**复杂度：** O(V log V+n)时间，O(V+n)空间。

## 易错点

- h的负数需要归一化；课堂模2^60变体不能直接用有符号溢出替代。
- 三角数先整数除2再取模，支持偶数mod的矩形查询。
- pairs扣去对角再乘2的逆元，所以限定奇数mod。
