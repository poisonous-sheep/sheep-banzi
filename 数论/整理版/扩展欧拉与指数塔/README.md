# 扩展欧拉与指数塔

**类型：** 模板型

**适用场景：** 固定2的无限幂塔，以及正整数数组区间幂塔模m；通过phi链与真实阈值判定。

**复杂度与条件：** phi试除按链各层求和；缓存后每问按O(log m)级链深递归及截断幂比较，空间为链深。

[完整C++17板子](模板.cpp)。

## 核心接口

- `calc(m)`：无限2指数塔
- `init(a)`：1-based且a[i]>=1
- `qur(l,r,m)`：右结合a[l]^(a[l+1]^...)
- `cap(l,r,limit)`：判断真实值是否达到limit

## 共同思路与易错点

- 非互质时只有指数足够大才加phi，不能无条件加。
- 不要从取模后的指数推断真实大小；cap独立判断。
- 本版约定m<=1e9，正底数，0^0不属于适用范围。
