# 扩展欧拉与指数塔

**用途与条件：** 固定2的无限幂塔，以及正整数数组区间幂塔模m；通过phi链与真实阈值判定。

**复杂度：** phi试除按链各层求和；缓存后每问按O(log m)级链深递归及截断幂比较，空间为链深。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `calc(m)`：无限2指数塔
- `init(a)`：1-based且a[i]>=1
- `qur(l,r,m)`：右结合a[l]^(a[l+1]^...)
- `cap(l,r,limit)`：判断真实值是否达到limit

### CF906D Power Tower

[原题](https://codeforces.com/problemset/problem/906/D)

**题意：** 数组上给区间，求该区间指数塔模固定m。

**为什么使用：** 区间长度可大，但phi链很短；底数为1时cap直接结束。

**如何调用：** init(a)，每问qur(l,r,m)。

**复杂度：** 预处理phi链，查询沿短链与阈值递归；空间O(n+log m)。

## 易错点

- 非互质时只有指数足够大才加phi，不能无条件加。
- 不要从取模后的指数推断真实大小；cap独立判断。
- 本版约定m<=1e9，正底数，0^0不属于适用范围。
