# 原根

**用途与条件：** 寻找最小原根并列举全部原根；从原素数版扩展至2、4、p^k、2p^k。

**复杂度：** 试除O(sqrt m)，找根O(G*omega(phi)*log m)，枚举O(phi(m)log phi(m))及排序，空间O(phi(m))。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `find(m)`：不存在返回-1
- `all(m)`：升序全部原根
- `exists(m)`：按原根存在条件判断

### P6091 原根

[原题](https://www.luogu.com.cn/problem/P6091)

**题意：** 求全部原根数量，并输出排序后每第d个原根。

**为什么使用：** 求一原根后，互质指数生成全部原根。

**如何调用：** all(n)，输出size与下标d-1,2d-1,...。

**复杂度：** 按模板找根与枚举复杂度。

### CF284A Cows and Primitive Roots

[原题](https://codeforces.com/problemset/problem/284/A)

**题意：** 素数p下有多少个原根。

## 易错点

- 非所有模数都有原根。
- 原根个数是phi(phi(m))；枚举需数据规模允许。
