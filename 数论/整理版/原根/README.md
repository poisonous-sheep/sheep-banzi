# 原根

**类型：** 模板型

**适用场景：** 寻找最小原根并列举全部原根；从原素数版扩展至2、4、p^k、2p^k。

**复杂度与条件：** 试除O(sqrt m)，找根O(G*omega(phi)*log m)，枚举O(phi(m)log phi(m))及排序，空间O(phi(m))。

[完整C++17板子](模板.cpp)。

## 核心接口

- `find(m)`：不存在返回-1
- `all(m)`：升序全部原根
- `exists(m)`：按原根存在条件判断
