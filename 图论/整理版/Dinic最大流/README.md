# Dinic最大流

**类型：** 模板型

**适用场景：** 整数非负容量网络最大流；保留head/dis/cur/e与递归DFS。

**复杂度与条件：** 一般O(V^2 E)时间、O(V+E)空间；单位容量二分匹配有更强界。

[完整C++17板子](模板.cpp)。

## 核心接口

- `init(s,t,V)`：清空所有旧残量，s!=t
- `addedge(u,v,c)`：返回前etot是正向边号，反向边号i^1
- `dinic()`：本次新增流量；首次init后即完整最大流
- `cut_side()`：完整最大流后取源侧残量可达点
