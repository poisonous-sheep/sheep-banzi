# Dinic最大流

**用途与条件：** 整数非负容量网络最大流；保留head/dis/cur/e与递归DFS。

**复杂度：** 一般O(V^2 E)时间、O(V+E)空间；单位容量二分匹配有更强界。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(s,t,V)`：清空所有旧残量，s!=t
- `addedge(u,v,c)`：返回前etot是正向边号，反向边号i^1
- `dinic()`：本次新增流量；首次init后即完整最大流
- `cut_side()`：完整最大流后取源侧残量可达点

## 易错点

- 原容量与残量不能混用；方案恢复要保存正向边号。
- 容量总和和流量累计不得溢出long long；极深增广路有递归栈风险。
