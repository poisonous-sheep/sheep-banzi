# 割边

**类型：** 模板型

**适用场景：** 无向图桥检测，按唯一边号跳过父边；支持重边和自环。

**复杂度与条件：** O(n+m)时间与空间。

[完整C++17板子](模板.cpp)。

## 核心接口

- `addedge(u,v)`：自动分配0-based边号
- `run()`：dfs森林；bridge[id]标记桥
- `edges/e`：原边端点与邻接表

## 例题 2：CF118E Bertown Roads

[原题](https://codeforces.com/problemset/problem/118/E)

**题意：** 把连通无向图定向为强连通图。

**观察与建模：** 存在桥时不可能；无桥时DFS树边向下、返祖边向上可得强连通方向。

**初始化、数据组织、接口与答案：** 先run判桥；沿dfn更早到更晚识别树边，另一次DFS每边只定向一次。

**本题复杂度：** O(n+m)时间与空间。

## 共同思路与易错点

- 跳过父边号而非父节点，否则重边会误判。
- bridge判low[v]>dfn[u]，严格大于。
- 深链递归有栈风险。
