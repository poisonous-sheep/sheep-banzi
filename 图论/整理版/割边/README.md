# 割边

**用途与条件：** 无向图桥检测，按唯一边号跳过父边；支持重边和自环。

**复杂度：** O(n+m)时间与空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `addedge(u,v)`：自动分配0-based边号
- `run()`：dfs森林；bridge[id]标记桥
- `edges/e`：原边端点与邻接表

### P1656 炸铁路

[原题](https://www.luogu.com.cn/problem/P1656)

**题意：** 输出删除后使图不连通的铁路。

**为什么使用：** 这正是桥的定义。

**如何调用：** run后筛bridge，端点排序后按字典序输出。

**复杂度：** O(n+m+k log k)时间、O(n+m)空间。

### CF118E Bertown Roads

[原题](https://codeforces.com/problemset/problem/118/E)

**题意：** 把连通无向图定向为强连通图。

**为什么使用：** 存在桥时不可能；无桥时DFS树边向下、返祖边向上可得强连通方向。

**如何调用：** 先run判桥；沿dfn更早到更晚识别树边，另一次DFS每边只定向一次。

**复杂度：** O(n+m)时间与空间。

## 易错点

- 跳过父边号而非父节点，否则重边会误判。
- bridge判low[v]>dfn[u]，严格大于。
- 深链递归有栈风险。
