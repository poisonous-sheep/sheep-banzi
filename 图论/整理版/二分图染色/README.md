# 二分图染色

**用途与条件：** 判断无向图是否可二染色，并统计每个连通块的两色数量。

**复杂度：** O(n+m)时间与空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(n)`：颜色-1代表未访问
- `addedge(u,v)`：无向边
- `run()`：不可染返回false；cnt记录各块两色数

## 例题

### ABC327D Good Tuple Problem

[原题](https://atcoder.jp/contests/abc327/tasks/abc327_d)

**题意：** 给定成对约束X[Ai]!=X[Bi]，判断是否存在0/1赋值。

**为什么使用：** 每对不等约束就是边的两端必须不同色。

**如何调用：** 分别读取A和B数组后addedge，run输出Yes/No。

**复杂度：** O(n+m)时间与空间。

### P1330 封锁阳光大学

[原题](https://www.luogu.com.cn/problem/P1330)

**题意：** 选择点封锁边，并要求相连点不能同时被选，最少选多少。

**为什么使用：** 每条边恰有一端被选，每个块只能选二分图的一侧；取较小侧。

**如何调用：** run判奇环，无解Impossible；累加min(cnt[0],cnt[1])。

**复杂度：** O(n+m)时间与空间。

## 易错点

- 遍历全部连通块；自环必然矛盾。
- 深链递归有RE风险，运行环境需足够栈。
