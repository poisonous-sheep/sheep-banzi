# 二分图染色

**类型：** 模板型

**适用场景：** 判断无向图是否可二染色，并统计每个连通块的两色数量。

**复杂度与条件：** O(n+m)时间与空间。

[完整C++17板子](模板.cpp)。

## 核心接口

- `init(n)`：颜色-1代表未访问
- `addedge(u,v)`：无向边
- `run()`：不可染返回false；cnt记录各块两色数

## 例题 2：P1330 封锁阳光大学

[原题](https://www.luogu.com.cn/problem/P1330)

**题意：** 选择点封锁边，并要求相连点不能同时被选，最少选多少。

**观察与建模：** 每条边恰有一端被选，每个块只能选二分图的一侧；取较小侧。

**初始化、数据组织、接口与答案：** run判奇环，无解Impossible；累加min(cnt[0],cnt[1])。

**本题复杂度：** O(n+m)时间与空间。
