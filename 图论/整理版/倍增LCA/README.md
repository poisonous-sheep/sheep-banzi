# 倍增LCA

**用途与条件：** 有根树最近公共祖先与边数距离；1-based，0为虚祖先。

**复杂度：** 预处理O(n log n)，查询O(log n)，空间O(n log n)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(n)`：按n选择倍增层数
- `build(root)`：树上递归预处理
- `lca(u,v)`：最近公共祖先
- `distance(u,v)`：无权树距离

### CF1328E Tree Queries

[原题](https://codeforces.com/problemset/problem/1328/E)

**题意：** 若干点各自至多向父移动一次，能否落在同一条根到某点路径上。

**为什么使用：** 把点移到父后，所有点需成为最深点的祖先；用LCA判祖先。

**如何调用：** 根的父替换为自身；取最深点v，检查lca(u,v)==u。

**复杂度：** O(n log n+总查询点数log n)时间、O(n log n)空间。

## 易错点

- 仅在树上使用；图中环会导致递归失控。
- LOG包括足够层数；深链最大n=5e5存在栈风险。
