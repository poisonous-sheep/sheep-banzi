# 倍增LCA

**类型：** 模板型

**适用场景：** 有根树最近公共祖先与边数距离；1-based，0为虚祖先。

**复杂度与条件：** 预处理O(n log n)，查询O(log n)，空间O(n log n)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `init(n)`：按n选择倍增层数
- `build(root)`：树上递归预处理
- `lca(u,v)`：最近公共祖先
- `distance(u,v)`：无权树距离

## 例题 2：CF1328E Tree Queries

[原题](https://codeforces.com/problemset/problem/1328/E)

**题意：** 若干点各自至多向父移动一次，能否落在同一条根到某点路径上。

**观察与建模：** 把点移到父后，所有点需成为最深点的祖先；用LCA判祖先。

**初始化、数据组织、接口与答案：** 根的父替换为自身；取最深点v，检查lca(u,v)==u。

**本题复杂度：** O(n log n+总查询点数log n)时间、O(n log n)空间。
