# 无向欧拉路径

**用途与条件：** 唯一边号标记、当前弧DFS，返回字典序最小无向欧拉路径。

**复杂度：** O(m log m+n)时间、O(n+m)空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `addedge(u,v)`：同一无向边的两向共享id
- `run()`：检查奇度数量及全边覆盖
- `path`：从最小可行起点出发

## 例题

### P2731 Riding the Fences

[原题](https://www.luogu.com.cn/problem/P2731)

**题意：** 按字典序输出经过每条栅栏一次的路线。

**为什么使用：** 栅栏是无向多重边，选择最小奇度点或最小有边点出发。

**如何调用：** init(500)、addedge、run，按点逐行输出。

**复杂度：** O(m log m+500)时间、O(m+500)空间。

### P1341 无序字母对

[原题](https://www.luogu.com.cn/problem/P1341)

**题意：** 把无序字母对拼成字典序最小字符串，每对用一次。

**为什么使用：** 字母是节点，字母对是无向边；字符ASCII顺序就是要求的字典序。

**如何调用：** 字符号加1避免节点0，run后逐点输出字符。

**复杂度：** O(m log m+128)时间、O(m+128)空间。

## 易错点

- 不能仅标记某一方向。
- 有边点须在同一个连通块；用路径长度验证。
- 深度可达m，保留递归并明确栈限制。
