# 无向欧拉路径

**类型：** 模板型

**适用场景：** 唯一边号标记、当前弧DFS，返回字典序最小无向欧拉路径。

**复杂度与条件：** O(m log m+n)时间、O(n+m)空间。

[完整C++17板子](模板.cpp)。

## 核心接口

- `addedge(u,v)`：同一无向边的两向共享id
- `run()`：检查奇度数量及全边覆盖
- `path`：从最小可行起点出发

[原题](https://www.luogu.com.cn/problem/P2731)

**题意：** 按字典序输出经过每条栅栏一次的路线。

**观察与建模：** 栅栏是无向多重边，选择最小奇度点或最小有边点出发。

**初始化、数据组织、接口与答案：** init(500)、addedge、run，按点逐行输出。

**本题复杂度：** O(m log m+500)时间、O(m+500)空间。

## 例题 2：P1341 无序字母对

[原题](https://www.luogu.com.cn/problem/P1341)

**题意：** 把无序字母对拼成字典序最小字符串，每对用一次。

## 共同思路与易错点

- 不能仅标记某一方向。
- 有边点须在同一个连通块；用路径长度验证。
- 深度可达m，保留递归并明确栈限制。
