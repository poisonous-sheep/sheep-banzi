# Kruskal重构树

**用途与条件：** 按权值排序建立连通块合并历史；支持不连通森林与LCA瓶颈查询。

**复杂度：** 排序O(m log m)，仅路径压缩的并查集按O((n+m)log n)保守估计，倍增O(n log n)；空间O(n log n+m)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `build(false)`：升序：最小化路径最大边
- `build(true)`：降序：最大化路径最小边
- `lca(u,v)`：不连通返回0
- `qur(u,v)`：LCA权值，不连通-1，同点约定0

## 例题

### P2245 星际导航

[原题](https://www.luogu.com.cn/problem/P2245)

**题意：** 求两点间路径最大边尽可能小的值。

**为什么使用：** 升序合并首次连通的权值就是所需最大边阈值。

**如何调用：** build(false)，qur；不连通按题面输出impossible。

**复杂度：** O(m log m+n log n+q log n)时间、O(m+n log n)空间。

## 易错点

- 森林必须逐根预处理，不能只dfs(tot)。
- 同点的空路径瓶颈由题目约定；本接口返回0。
- 归并代表形成长链，递归find/dfs有栈风险；每次新建图先init。
