# Kruskal重构树

**类型：** 混合型

**适用场景：** 按权值排序建立连通块合并历史；支持不连通森林与LCA瓶颈查询。

**复杂度与条件：** 排序O(m log m)，仅路径压缩的并查集按O((n+m)log n)保守估计，倍增O(n log n)；空间O(n log n+m)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `build(false)`：升序：最小化路径最大边
- `build(true)`：降序：最大化路径最小边
- `lca(u,v)`：不连通返回0
- `qur(u,v)`：LCA权值，不连通-1，同点约定0

## 例题 1：P2245 星际导航

[原题](https://www.luogu.com.cn/problem/P2245)

**题意：** 求两点间路径最大边尽可能小的值。

**观察与规模：** 求两点间路径最大边尽可能小的值。 升序合并首次连通的权值就是所需最大边阈值。 询问路径上的最大/最小边界，普通最短距离与瓶颈值不是同一目标。

**朴素思路：** 每次跑瓶颈搜索O(qm)，或者沿生成树逐边找极值，询问多时不可行。

**关键突破：** 按阈值加边的连通分量只会合并；把每次合并记为一个新父节点，形成阈值历史树。

**状态与建模：** 原顶点作叶子，新点值是当前合并边权，两个分量根接为孩子。相同原分量无需新建；不连通得到森林。

**本题映射：** 求两点间路径最大边尽可能小的值。 升序合并首次连通的权值就是所需最大边阈值。 build(false)，qur；不连通按题面输出impossible。

**转移与正确性：** 升序Kruskal时两点首次连通阈值即最小可能的路径最大边；降序时为最大可能的路径最小边。首次同属一个分量的新点正是重构树LCA。

**初始化与顺序：** DSU初始化原点，边排序后merge创建新点，再对每棵根树build倍增。查询先判原图是否连通，同点按题目约定处理。

**优化与限制：** 建树O(m log m+(n+m)log n)保守上界，查询O(log n)；原实现仅压缩路径，不声称凭空获得秩合并复杂度。重构树可深O(n)，递归栈风险明确保留。

**本题复杂度：** O(m log m+n log n+q log n)时间、O(m+n log n)空间。

## 共同思路与易错点

- 森林必须逐根预处理，不能只dfs(tot)。
- 同点的空路径瓶颈由题目约定；本接口返回0。
- 归并代表形成长链，递归find/dfs有栈风险；每次新建图先init。

共同启发：离线阈值连通性可以变为可查询的合并历史；先确定是最小化最大边还是最大化最小边，再决定排序方向。
