# 有向欧拉路径

**类型：** 模板型

**适用场景：** Hierholzer递归删边与逆序；验证度条件和全边覆盖。

**复杂度与条件：** 不排序O(n+m)，字典序排序O(m log m)，空间O(n+m)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `addedge(u,v)`：允许重复边与自环
- `run(lex)`：破坏邻接表，得到path；失败不可使用
- `path`：顺序路径点数m+1

## 共同思路与易错点

- 只判断出入度不足够，还要检查path.size()==m+1。
- 每边只pop一次；递归深度最坏m，有RE风险。
