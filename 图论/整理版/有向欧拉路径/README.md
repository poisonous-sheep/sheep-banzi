# 有向欧拉路径

**用途与条件：** Hierholzer递归删边与逆序；验证度条件和全边覆盖。

**复杂度：** 不排序O(n+m)，字典序排序O(m log m)，空间O(n+m)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `addedge(u,v)`：允许重复边与自环
- `run(lex)`：破坏邻接表，得到path；失败不可使用
- `path`：顺序路径点数m+1

## 例题

### P7771 欧拉路径

[原题](https://www.luogu.com.cn/problem/P7771)

**题意：** 输出字典序最小有向欧拉路，没有则No。

**为什么使用：** 度数唯一决定非回路起点；降序邻接pop_back优先小点。

**如何调用：** run(true)后输出path。

**复杂度：** O(m log m+n)时间、O(n+m)空间。

### CF508D Tanya and Password

[原题](https://codeforces.com/contest/508/problem/D)

**题意：** 用三字符子串多重集还原原字符串。

**为什么使用：** 每个两字符串是节点，三字符串是前两位到后两位的有向边；所有子串恰用一次。

**如何调用：** 字母数字映射62进制节点；run(false)；输出首节点两位，再输出后续节点末位。

**复杂度：** O(n+62^2)时间与空间。

## 易错点

- 只判断出入度不足够，还要检查path.size()==m+1。
- 每边只pop一次；递归深度最坏m，有RE风险。
