# 最小割建模

**用途与条件：** 复用Dinic，支持最大权闭合子图、二元选择与二分图最大权独立集。

**复杂度：** 最大流一般O(V^2 E)，源侧恢复O(V+E)；空间O(V+E)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `dinic()`：最大流值等于最小割
- `cut_side()`：1为源侧，0为汇侧
- `addedge(u,v,INF)`：禁止把u源侧、v汇侧；INF须超过有限割上界

### P4126 最小割边判定

[原题](https://www.luogu.com.cn/problem/P4126)

**题意：** 判断每条边是否可出现在某个或所有最小割中。

**为什么使用：** 最大流后残量SCC：饱和且两端不同SCC可属于某割；起点在源SCC且终点在汇SCC属于所有割。

**如何调用：** dinic后将正残量边加入SCC；按保存原边号检查f=0和col条件。

**复杂度：** 最大流一般O(V²E)，SCC O(V+E)，O(V+E)空间。
