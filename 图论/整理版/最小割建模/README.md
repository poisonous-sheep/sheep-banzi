# 最小割建模

**类型：** 混合型

**适用场景：** 复用Dinic，支持最大权闭合子图、二元选择与二分图最大权独立集。

**复杂度与条件：** 最大流一般O(V^2 E)，源侧恢复O(V+E)；空间O(V+E)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `dinic()`：最大流值等于最小割
- `cut_side()`：1为源侧，0为汇侧
- `addedge(u,v,INF)`：禁止把u源侧、v汇侧；INF须超过有限割上界

## 例题 1：P2774 方格取数问题

[原题](https://www.luogu.com.cn/problem/P2774)

**题意：** 选不相邻的格子，使权值和最大。

**观察与规模：** 选不相邻的格子，使权值和最大。 棋盘二分图最大权独立集=总权-最小点覆盖；冲突边给INF。 取舍收益与两对象不可同时选择的冲突，能映射到s/t两侧；不是所有独立集都可用二分图最小割。

**朴素思路：** 枚举所有选择2^n；逐个选最大收益会与多个中等收益冲突。

**关键突破：** 总收益固定时，最大合法收益=总收益-最小舍弃代价。用无限容量边禁止非法的跨割关系。

**状态与建模：** P2774黑白格二分图，s到黑、白到t容量为点权，黑到相邻白为INF。P2762项目在源侧表示选，依赖设备也须在源侧：项目到设备INF。

**本题映射：** 选不相邻的格子，使权值和最大。 棋盘二分图最大权独立集=总权-最小点覆盖；冲突边给INF。 S到黑格点权，白格到T点权，黑到相邻白INF，输出total-dinic。

**转移与正确性：** 有限割对应合法选择，割掉的点/项目/设备边准确计损失或成本；任意合法方案也有同费用割，双向对应证明最优。P4126对最大流后残量图缩SCC判断边能否/是否必在最小割。

**初始化与顺序：** init(n,s,t)，全部add后flow，答案总收益-flow。需要恢复方案时从s沿正残量走出源侧；P4126要额外使用SCC板子，不能把原容量图缩点。

**优化与限制：** INF取严格大于任意有限可行割上界，求和避免溢出；最大流复杂度沿本册Dinic说明。冲突图非二分时P2774模型失效。

**本题复杂度：** O(V^2 E)时间、O(V+E)空间。

**启发式总结：** 先明确每个点在两侧的含义，再对每类边写割费用；不依赖一句“建图跑流”。恢复方案与多种最小割判断还需残量结构。
