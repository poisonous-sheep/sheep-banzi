# 有上下界可行流与最大流

**用途与条件：** 先强制下界并记录节点净流入差，超级源汇补平衡；有源汇加t->s并在可行残量上继续增广。

**复杂度：** 一般Dinic O(V²E)时间、O(V+E)空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `add_edge(u,v,l,r)`：记录0<=l<=流量<=r，返回原边序号
- `feasible()`：无源汇环流判可行，只调用一次
- `maxflow(s,t)`：有源汇非负最大流，nullopt表示不可行
- `value(k)`：可行之后读取原第k条边实际流量

## 例题

### CF510E Fox And Dinner

[原题](https://codeforces.com/contest/510/problem/E)

**题意：** 将年龄数排成若干长度至少3的圆桌，相邻和为素数。

**为什么使用：** 年龄>=2使素数边只可能连接奇偶；每点恰好两条选择边，转为上下界为2的二分图度约束。

**如何调用：** 源到奇点[2,2]，素数边[0,1]，偶点到汇[2,2]，汇到源[0,2n]，feasible后value恢复环。

**复杂度：** 建边O(n² sqrt A)，最大流一般O(V²E)，O(n²)空间。

### P5192 Shoot the Bullet

[原题](https://www.luogu.com.cn/problem/P5192)

**题意：** 每天拍摄总量上限、每次对象数量区间、每位少女总需求下限，最大拍摄量。

**为什么使用：** 每项区间对应一天到少女的上下界边，少女到汇的下界代表需求，属于有源汇上下界最大流。

**如何调用：** S->天[0,D]，天->少女[L,R]，少女->T[G,INF]，maxflow。重复少女边分别保留。

**复杂度：** 一般O(V²E)时间、O(V+E)空间。

## 易错点

- balance正值接S->u，负值接u->T；容易接反。
- 第二次增广前必须同时清空所有辅助边的正反残量。
- INF需超过需求与可行总流，不能使用LLONG_MAX参与加法。
