# 最小费用最大流

**用途与条件：** 逐次最短增广；费用势使残量边非负，用Dijkstra取最便宜增广路，支持无负环的负费用初始网络。

**复杂度：** 初始非负费用免预处理；有负费用时O(VE)建势，之后O(A*E log V)，A为增广次数；O(V+E)空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `add_edge(u,v,f,c)`：容量f非负，费用c；自动配反向边
- `run(s,t,limit)`：返回新增流量及新增最小费用，默认最大流

## 例题

### P3381 最小费用最大流

[原题](https://www.luogu.com.cn/problem/P3381)

**题意：** 有向容量费用网络求最小费用最大流。

**为什么使用：** 费用最短的残量增广路保证每个流量阶段费用最小。

**如何调用：** add_edge(u,v,w,c)，run(s,t)。

**复杂度：** O(AE log V)时间，O(V+E)空间；此题初始c>=0。

### P4015 运输问题

[原题](https://www.luogu.com.cn/problem/P4015)

**题意：** 运输供需平衡的货物，求最小和最大费用。

**为什么使用：** 仓库到商店边的流量代表货运量，负费用后最小值对应最大费用。

**如何调用：** 分别重建正费用、负费用网络；输出run的费用及负号恢复。

**复杂度：** O(VE+AE log V)时间、O(V+E)空间。

## 易错点

- 初始正容量子图不允许负费用环；需要消负环的环流问题须另写算法。
- 最大费用可取相反费用重建网络，不能在同一已流过的网络直接换号。
- 容量*费用及累计费用必须在long long内。
