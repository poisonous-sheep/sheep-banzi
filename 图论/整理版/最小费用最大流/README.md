# 最小费用最大流

**类型：** 模板型

**适用场景：** 逐次最短增广；费用势使残量边非负，用Dijkstra取最便宜增广路，支持无负环的负费用初始网络。

**复杂度与条件：** 初始非负费用免预处理；有负费用时O(VE)建势，之后O(A*E log V)，A为增广次数；O(V+E)空间。

[完整C++17板子](模板.cpp)。

## 核心接口

- `add_edge(u,v,f,c)`：容量f非负，费用c；自动配反向边
- `run(s,t,limit)`：返回新增流量及新增最小费用，默认最大流

## 共同思路与易错点

- 初始正容量子图不允许负费用环；需要消负环的环流问题须另写算法。
- 最大费用可取相反费用重建网络，不能在同一已流过的网络直接换号。
- 容量*费用及累计费用必须在long long内。
