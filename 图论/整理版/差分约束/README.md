# 差分约束

**类型：** 模板型

**适用场景：** 一般上界差分约束用Bellman-Ford判负环；非正权上界特例提供SCC+DAG最小正值变体。

**复杂度与条件：** solve为O(nm)时间；minimum_positive为O(n+m)时间；空间O(n+m)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `add_constraint(u,v,w)`：x[v]-x[u]<=w
- `solve()`：任意可行x或false
- `minimum_positive()`：仅w<=0；返回x=-a且a[i]>=1的最小解

## 共同思路与易错点

- 先写不等式再确定边方向；严格整数差用1而非浮点epsilon。
- 一般有正/负权时不能用SCC特例；大规模一般图Bellman-Ford会TLE。
