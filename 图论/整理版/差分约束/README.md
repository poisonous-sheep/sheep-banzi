# 差分约束

**用途与条件：** 一般上界差分约束用Bellman-Ford判负环；非正权上界特例提供SCC+DAG最小正值变体。

**复杂度：** solve为O(nm)时间；minimum_positive为O(n+m)时间；空间O(n+m)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `add_constraint(u,v,w)`：x[v]-x[u]<=w
- `solve()`：任意可行x或false
- `minimum_positive()`：仅w<=0；返回x=-a且a[i]>=1的最小解

## 例题

### P5960 差分约束

[原题](https://www.luogu.com.cn/problem/P5960)

**题意：** 求形如x[c]-x[c2]<=y的不等式组可行解。

**为什么使用：** 边c2->c权y，用全零初值等价于超级源连到全部点。

**如何调用：** add_constraint(c2,c,y)，solve后输出x。

**复杂度：** O(nm)时间、O(n+m)空间。

### P3275 糖果

[原题](https://www.luogu.com.cn/problem/P3275)

**题意：** 每人至少1颗糖，满足五类大小关系，最少糖果总数。

**为什么使用：** 取x=-糖果数后全部边权0或-1；同SCC负边意味着矛盾，缩点最长路求最小糖果。

**如何调用：** 映射五类约束后minimum_positive；输出-sum(x)。

**复杂度：** O(n+m)时间与空间。

## 易错点

- 先写不等式再确定边方向；严格整数差用1而非浮点epsilon。
- 一般有正/负权时不能用SCC特例；大规模一般图Bellman-Ford会TLE。
