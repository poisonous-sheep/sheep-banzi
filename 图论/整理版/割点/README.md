# 割点

**用途与条件：** 无向图割点与删点分块大小统计；根与非根分开判定。

**复杂度：** O(n+m)时间与空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `cut[u]`：割点标记
- `parts[u]`：low[v]>=dfn[u]的子树大小
- `sz[u]`：DFS子树大小

### P3469 BLO-Blockade

[原题](https://www.luogu.com.cn/problem/P3469)

**题意：** 分别封锁每个点的所有边，统计不连通有序点对。

**为什么使用：** 原图连通，删边后分块；总点对减去各块内部点对。

**如何调用：** 利用parts[u]与剩余块n-1-sum(parts)，再加2(n-1)。

**复杂度：** O(n+m)时间与空间。

## 易错点

- 根需至少两个DFS儿子；非根条件为low[v]>=dfn[u]。
- BLO删除边后仍保留被隔离顶点，必须计入涉及该点的有序点对。
