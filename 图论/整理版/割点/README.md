# 割点

**类型：** 模板型

**适用场景：** 无向图割点与删点分块大小统计；根与非根分开判定。

**复杂度与条件：** O(n+m)时间与空间。

复用[割边完整板子](../%E5%89%B2%E8%BE%B9/%E6%A8%A1%E6%9D%BF.cpp)，同一算法定义只收录一次。

## 核心接口

- `cut[u]`：割点标记
- `parts[u]`：low[v]>=dfn[u]的子树大小
- `sz[u]`：DFS子树大小

## 共同思路与易错点

- 根需至少两个DFS儿子；非根条件为low[v]>=dfn[u]。
- BLO删除边后仍保留被隔离顶点，必须计入涉及该点的有序点对。
