# Prim最小生成树

**类型：** 模板型

**适用场景：** 堆优化Prim无向图最小生成树；负边也可用；返回连通性与权值和。

**复杂度与条件：** O(m log m)堆操作上界，空间O(n+m)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `addedge(u,v,w)`：无向边
- `run(s)`：返回{是否全图连通,生成树权重}

## 共同思路与易错点

- 不要把边权当成Dijkstra距离；每次选跨割的最小边。
- 不连通时返回的是源所在块生成树和，不能当全图MST。
