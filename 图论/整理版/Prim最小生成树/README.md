# Prim最小生成树

**用途与条件：** 堆优化Prim无向图最小生成树；负边也可用；返回连通性与权值和。

**复杂度：** O(m log m)堆操作上界，空间O(n+m)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `addedge(u,v,w)`：无向边
- `run(s)`：返回{是否全图连通,生成树权重}

## 例题

### P3366 最小生成树

[原题](https://www.luogu.com.cn/problem/P3366)

**题意：** 求MST，不连通输出orz。

**为什么使用：** 无向图跨割最小边贪心满足MST性质。

**如何调用：** init、addedge、run，先判断bool。

**复杂度：** O(m log m)时间、O(n+m)空间。

### ABC065D Built

[原题](https://atcoder.jp/contests/abc065/tasks/arc076_b)

**题意：** 平面点间建路，代价min(|dx|,|dy|)，求最小总费用。

**为什么使用：** 按x/y排序的相邻点边足以保留MST；把完全图稀疏化后运行Prim。

**如何调用：** 两种排序加相邻边，权值取真实min差；run。

**复杂度：** O(n log n)时间、O(n)空间。

## 易错点

- 不要把边权当成Dijkstra距离；每次选跨割的最小边。
- 不连通时返回的是源所在块生成树和，不能当全图MST。
