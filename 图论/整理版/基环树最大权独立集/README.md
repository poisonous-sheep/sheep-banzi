# 基环树最大权独立集

**类型：** 混合型

**适用场景：** 每个函数图分量一个环；外挂树选/不选DP后，环枚举首点选择并检查首尾冲突。

**复杂度与条件：** O(n)时间与空间。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 先剥离附着树，得到环，再固定环首点是否选，使环上选择变成链DP。

**状态与建模：** 树f0/f1分别是不选/选根的最大权；环每个点用附着树的两个代价作局部权，链状态记录上一个环点是否选。

**优化与限制：** O(n)/O(n)，负权允许全不选，题意若要求非空需另设状态。FunctionalGraph分解模块与独立集转移分开阅读；旧继承版本保留，函数版不用继承。

## 例题 1：P2607 骑士

[原题](https://www.luogu.com.cn/problem/P2607)

**题意：** 每位骑士有收益和一个不能同时选的对象，最大总收益。

**观察与规模：** 每位骑士有收益和一个不能同时选的对象，最大总收益。 每点恰好一条指向冲突对象的边，弱分量是基环树。 每点指定一个冲突关系，底层每个分量至多一环；独立集不能选相邻点。

**朴素思路：** 枚举点子集2^n；直接树DP遇到环会反复访问并违反首尾约束。

**关键突破：** 先剥离附着树，得到环，再固定环首点是否选，使环上选择变成链DP。

**状态与建模：** 树f0/f1分别是不选/选根的最大权；环每个点用附着树的两个代价作局部权，链状态记录上一个环点是否选。

**本题映射：** 每位骑士有收益和一个不能同时选的对象，最大总收益。 每点恰好一条指向冲突对象的边，弱分量是基环树。 输入收益val及后继p，run。

**转移与正确性：** 树f0=Σmax(child0,child1)，f1=a+Σchild0。环转移未选取两态最大，选只接前一个未选；固定首态后最后检查首尾不能都选。各连通分量答案相加。

**初始化与顺序：** 树叶f0=0、f1=a；链不可达-INF。边id用于区分反向边，不能仅用父顶点跳边；自环禁止选其唯一点，平行双边环也须识别。

**优化与限制：** O(n)/O(n)，负权允许全不选，题意若要求非空需另设状态。FunctionalGraph分解模块与独立集转移分开阅读；旧继承版本保留，函数版不用继承。

**本题复杂度：** O(n)时间/空间。

**启发式总结：** 环把局部树接口闭合成首尾约束；只要接口状态很小，枚举首态即可消掉环的耦合。

## 共同思路与易错点

- 自环点不能选；二点互指构成重边环，也不能同时选。
- 压平原vector<vector<ll>>的两状态表减少百万点内存，递归树DP和环递推保持。
- orient仅接受每个分量恰好一个环；树或多环图不适用。

共同启发：环把局部树接口闭合成首尾约束；只要接口状态很小，枚举首态即可消掉环的耦合。
