# 基环树最大权独立集

**用途与条件：** 每个函数图分量一个环；外挂树选/不选DP后，环枚举首点选择并检查首尾冲突。

**复杂度：** O(n)时间与空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `p/val`：每点唯一后继与点收益；1基
- `orient(edges)`：无向基环森林转为函数图，边为{u,v,w}
- `run()`：重建反向边并求全图最大独立集权和

[原题](https://www.luogu.com.cn/problem/P2607)

**题意：** 每位骑士有收益和一个不能同时选的对象，最大总收益。

**如何调用：** 输入收益val及后继p，run。

## 易错点

- 自环点不能选；二点互指构成重边环，也不能同时选。
- 压平原vector<vector<ll>>的两状态表减少百万点内存，递归树DP和环递推保持。
- orient仅接受每个分量恰好一个环；树或多环图不适用。
