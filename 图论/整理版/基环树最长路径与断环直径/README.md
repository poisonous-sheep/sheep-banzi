# 基环树最长路径与断环直径

**用途与条件：** 外挂树求向下最长链与内部直径；环复制后滑窗维护d[j]-前缀距离，最长简单路径可取长弧。

**复杂度：** O(n)时间与空间；断环版本用双栈聚合队列同为O(n)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `p/w`：函数图后继与该后继边非负权
- `run()`：返回全部分量最长简单路径长度之和
- `orient/minimum_cut_diameter`：一个无向基环图中切掉一条环边，使所得树直径最小

## 例题

### P4381 Island

[原题](https://www.luogu.com.cn/problem/P4381)

**题意：** 多个基环分量各取最长简单路径，再把长度相加。

**为什么使用：** 路径要么在一个外挂树内，要么经环连接不同树根，分别计算取最大。

**如何调用：** 输入p[u],w[u]，run。

**复杂度：** O(n)时间与空间。

### CF835F Roads in the Kingdom

[原题](https://codeforces.com/contest/835/problem/F)

**题意：** 删去基环图的一条边保持连通，使剩余图最大点距最小。

**为什么使用：** 只能删环边；每种断法对应复制环的k点连续窗口，窗口内最长路径由有序聚合信息维护。

**如何调用：** 读边orient；调用minimum_cut_diameter，与树内直径取max。

**复杂度：** O(n)时间与空间。

## 易错点

- 最长简单路径与最短路意义的直径不同，前者可以选择较长环弧。
- 环滑窗严格排除两端同环点，不能绕完整一圈。
- 断环队列信息有方向，左右merge顺序不能交换。
