# 基环树最长路径与断环直径

**类型：** 混合型

**适用场景：** 外挂树求向下最长链与内部直径；环复制后滑窗维护d[j]-前缀距离，最长简单路径可取长弧。

**复杂度与条件：** O(n)时间与空间；断环版本用双栈聚合队列同为O(n)。

本节围绕题目推导组织，函数版题解不强行封装成struct。旧`模板.cpp`仅作历史对照（若存在），不作为本版推荐复制入口。

## 模型识别与变体

**关键突破：** 附着树只向环输出向下最长距离及内部直径；环上跨附着树的路径由两端距离和连续环段组成。

**状态与建模：** 每个环点h为附着树最长下行，inside为附着树内部直径；将环权前缀坐标化，候选h\[i\]+h\[j\]+dist(i,j)。

**优化与限制：** 原实现按对应接口给出线性/带log的界，附着树递归O(n)栈风险。不能将“原图最长路”作为“断一边后最小直径”；权值需非负才能使用这些距离最优性质。

## 例题 1：P4381 Island

[原题](https://www.luogu.com.cn/problem/P4381)

**题意：** 多个基环分量各取最长简单路径，再把长度相加。

**观察与规模：** 多个基环分量各取最长简单路径，再把长度相加。 路径要么在一个外挂树内，要么经环连接不同树根，分别计算取最大。 Island求每个分量最长简单路之和；CF835F选一环边断开后求最小直径，优化目标不同。

**朴素思路：** 枚举所有简单路径指数级；每次删一边重算树直径需O(n^2)。

**关键突破：** 附着树只向环输出向下最长距离及内部直径；环上跨附着树的路径由两端距离和连续环段组成。

**状态与建模：** 每个环点h为附着树最长下行，inside为附着树内部直径；将环权前缀坐标化，候选h\[i\]+h\[j\]+dist(i,j)。

**本题映射：** 多个基环分量各取最长简单路径，再把长度相加。 路径要么在一个外挂树内，要么经环连接不同树根，分别计算取最大。 输入p\[u\],w\[u\]，run。

**转移与正确性：** 最长简单路在环上不能走满一圈，双倍环用窗口长度小于环长维护最大h\[i\]-pos\[i\]。断环时每个起点窗口表示剩余链，链内最远对可用区间合并信息最大化，再对所有切边取最小。

**初始化与顺序：** 附着树先后序算两条最长分支；非环分量路径退化为树直径。自环不属于可走简单路，平行双边有两种不同边长可选。

**优化与限制：** 原实现按对应接口给出线性/带log的界，附着树递归O(n)栈风险。不能将“原图最长路”作为“断一边后最小直径”；权值需非负才能使用这些距离最优性质。

**本题复杂度：** O(n)时间与空间。

[完整函数题解](%E4%BE%8B%E9%A2%98/P4381-Island-%E9%A2%98%E8%A7%A3.cpp)。

**启发式总结：** 先把复杂图拆成小环与独立树，再用树输出的接口简化环问题；极大化与切边后极小化分别推导，不能凭同名直径混用。

## 共同思路与易错点

- 最长简单路径与最短路意义的直径不同，前者可以选择较长环弧。
- 环滑窗严格排除两端同环点，不能绕完整一圈。
- 断环队列信息有方向，左右merge顺序不能交换。

共同启发：先把复杂图拆成小环与独立树，再用树输出的接口简化环问题；极大化与切边后极小化分别推导，不能凭同名直径混用。
