# 点双连通分量

**用途与条件：** Tarjan点栈构造点双；割点可属于多个块，孤立点单独成块。

**复杂度：** O(n+m)时间与空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(n)`：清空状态
- `addedge(u,v,id)`：无向边唯一编号，忽略自环
- `run()`：得到bcc与cut

### P3225 矿场搭建

[原题](https://www.luogu.com.cn/problem/P3225)

**题意：** 设置最少出口，保证任一矿点坍塌后仍可逃离，统计方案数。

**为什么使用：** 块无割点需2出口；叶子块有1割点需在非割点中选1出口。

**如何调用：** 按边中出现的编号建图，run后逐bcc统计cut数并乘方案。

**复杂度：** O(n+m)时间与空间，方案数按题目保证使用unsigned long long。
