# 点双连通分量

**类型：** 模板型

**适用场景：** Tarjan点栈构造点双；割点可属于多个块，孤立点单独成块。

**复杂度与条件：** O(n+m)时间与空间。

[完整C++17板子](模板.cpp)。

## 核心接口

- `init(n)`：清空状态
- `addedge(u,v,id)`：无向边唯一编号，忽略自环
- `run()`：得到bcc与cut
