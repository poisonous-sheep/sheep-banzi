# DFS增广路匹配

**用途与条件：** 保留原逐左点DFS增广写法；接口与HK统一，便于比较两种算法。

**复杂度：** O(V_left*E)时间、O(V+E)空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(n,m)`：独立左右编号
- `add(u,v)`：合法匹配边
- `matching()`：每轮清vis再增广
