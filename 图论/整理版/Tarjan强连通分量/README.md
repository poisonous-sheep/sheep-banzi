# Tarjan强连通分量

**类型：** 模板型

**适用场景：** 有向图强连通分量划分与缩点；支持重边、自环及不连通图。

**复杂度与条件：** O(n+m)时间与空间，递归栈O(n)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `init(n)`：清空旧图
- `addedge(u,v)`：有向边
- `run()`：求SCC，每次建图仅运行一次
- `bel[u]/cnt/scc`：归属编号、数量与分量成员

## 共同思路与易错点

- Tarjan只使用仍在栈中的点更新low；Kosaraju第二遍走反图。
- 两算法分量编号顺序不同，不把编号当统一拓扑序；应用显式拓扑排序。
- 深链递归有RE风险。
