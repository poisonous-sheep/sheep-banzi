# Tarjan强连通分量

**用途与条件：** 有向图强连通分量划分与缩点；支持重边、自环及不连通图。

**复杂度：** O(n+m)时间与空间，递归栈O(n)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(n)`：清空旧图
- `addedge(u,v)`：有向边
- `run()`：求SCC，每次建图仅运行一次
- `bel[u]/cnt/scc`：归属编号、数量与分量成员

### P3387 缩点

[原题](https://www.luogu.com.cn/problem/P3387)

**题意：** 有向图走一条路线，点权最多可取得多少；每点只计一次。

**为什么使用：** 正权SCC内可遍历全部点，缩为DAG做最长路。

**如何调用：** run、汇总点权、建立分量边，用Kahn顺序转移dp。

**复杂度：** O(n+m)时间与空间。

## 易错点

- Tarjan只使用仍在栈中的点更新low；Kosaraju第二遍走反图。
- 两算法分量编号顺序不同，不把编号当统一拓扑序；应用显式拓扑排序。
- 深链递归有RE风险。
