# 拓扑排序

**用途与条件：** Kahn拓扑序，保留原队列写法；可选最小堆得到字典序最小拓扑序。

**复杂度：** 队列O(n+m)，字典序O((n+m)log n)，空间O(n+m)。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `toposort(false)`：返回拓扑序，少于n表示有环
- `toposort(true)`：字典序最小
- `d`：原始入度保留，重复调用不消耗

## 例题

### P1137 旅行计划

[原题](https://www.luogu.com.cn/problem/P1137)

**题意：** DAG中每个终点最多经过多少城市。

**为什么使用：** 拓扑顺序做最长路，dp[v]=max(dp[v],dp[u]+1)。

**如何调用：** 按toposort遍历，输出每点dp。

**复杂度：** O(n+m)时间与空间。

### ABC223D Restricted Permutation

[原题](https://atcoder.jp/contests/abc223/tasks/abc223_d)

**题意：** 给先后约束，求字典序最小排列，无解-1。

**为什么使用：** 每步取当前所有零入度点中的最小点。

**如何调用：** toposort(true)，长度<n判环。

**复杂度：** O((n+m)log n)时间、O(n+m)空间。
