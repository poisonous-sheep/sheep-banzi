# 拓扑排序

**类型：** 模板型

**适用场景：** Kahn拓扑序，保留原队列写法；可选最小堆得到字典序最小拓扑序。

**复杂度与条件：** 队列O(n+m)，字典序O((n+m)log n)，空间O(n+m)。

[完整C++17板子](模板.cpp)。

## 核心接口

- `toposort(false)`：返回拓扑序，少于n表示有环
- `toposort(true)`：字典序最小
- `d`：原始入度保留，重复调用不消耗
