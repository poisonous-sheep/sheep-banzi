# 2-SAT

**类型：** 模板型

**适用场景：** 二元布尔变量OR子句与蕴含约束；内部独立Tarjan SCC。

**复杂度与条件：** O(变量数+子句数)时间与空间。

[完整C++17板子](模板.cpp)。

## 核心接口

- `init_sat(n)`：n个变量，1-based
- `add_or(a,A,b,B)`：(a=A)或(b=B)
- `imply(u,v)`：自动添加逆否边
- `solve_sat()`：可行后ans保存0/1解

[原题](https://www.luogu.com.cn/problem/P4782)
