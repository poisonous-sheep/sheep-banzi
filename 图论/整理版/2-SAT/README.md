# 2-SAT

**用途与条件：** 二元布尔变量OR子句与蕴含约束；内部独立Tarjan SCC。

**复杂度：** O(变量数+子句数)时间与空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init_sat(n)`：n个变量，1-based
- `add_or(a,A,b,B)`：(a=A)或(b=B)
- `imply(u,v)`：自动添加逆否边
- `solve_sat()`：可行后ans保存0/1解

## 例题

### P4782 2-SAT

[原题](https://www.luogu.com.cn/problem/P4782)

**题意：** 给OR子句求一个可行布尔赋值。

**为什么使用：** 每条OR拆成两个蕴含，变量两取值不能在同一SCC。

**如何调用：** add_or建图，solve_sat后输出ans。

**复杂度：** O(n+m)时间与空间。

### P4171 满汉全席

[原题](https://www.luogu.com.cn/problem/P4171)

**题意：** 每种材料做满式或汉式，满足每位评委至少喜欢一种菜。

**为什么使用：** 评委条件是两个取值命题的OR子句。

**如何调用：** h映射1、m映射0；每组init后add_or并判定。

**复杂度：** O(总变量+总条件)时间与空间。

## 易错点

- 取值公式依赖Tarjan的反拓扑分量编号，不能直接替换为Kosaraju。
- 每次判定需重新初始化图；矛盾时ans无效。
