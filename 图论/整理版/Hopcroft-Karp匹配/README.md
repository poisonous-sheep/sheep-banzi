# Hopcroft-Karp匹配

**类型：** 模板型

**适用场景：** 二分图最大匹配；左右编号独立且从1开始，0表示未匹配。

**复杂度与条件：** O(E sqrt V)时间、O(V+E)空间。

[完整C++17板子](模板.cpp)。

## 核心接口

- `init(n1,n2)`：清空图和匹配
- `add(u,v)`：左部到右部的边
- `matching()`：最大匹配数，重复调用不重复累计
- `ml/mr`：匹配关系

## 共同思路与易错点

- 只用于二分图，不用于一般图匹配。
- 递归增广路深度最坏O(V)，极深数据有栈风险。
