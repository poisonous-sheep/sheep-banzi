# Hopcroft-Karp匹配

**用途与条件：** 二分图最大匹配；左右编号独立且从1开始，0表示未匹配。

**复杂度：** O(E sqrt V)时间、O(V+E)空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `init(n1,n2)`：清空图和匹配
- `add(u,v)`：左部到右部的边
- `matching()`：最大匹配数，重复调用不重复累计
- `ml/mr`：匹配关系

## 易错点

- 只用于二分图，不用于一般图匹配。
- 递归增广路深度最坏O(V)，极深数据有栈风险。
