# 边双连通分量

**用途与条件：** 去掉所有桥后得到边双分量，缩点得到桥森林。

**复杂度：** O(n+m)时间与空间。

[完整模板](模板.cpp)；模板solve采用第一例题或注明的演示输入。

## 接口

- `run()`：先判桥再paint非桥边
- `bel[u]`：边双编号1..cnt
- `bcc`：分量成员表

## 例题

[原题](https://www.luogu.com.cn/problem/P8436)

**如何调用：** run后输出bcc。

### P2860 Redundant Paths

[原题](https://www.luogu.com.cn/problem/P2860)

**题意：** 最少加边让任意两点有两条边不重叠路径。

**为什么使用：** 缩为桥树后，配对叶子可消除所有桥；答案ceil(叶子数/2)。

**如何调用：** 用原边与bel计算桥树度数，数度1点。

**复杂度：** O(n+m)时间与空间。

## 易错点

- 桥树不是原图生成树，分量内可能有很多环。
- Redundant Paths保证连通；不连通情况不能直接套叶子公式。
