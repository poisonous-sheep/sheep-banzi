# 边双连通分量

**类型：** 模板型

**适用场景：** 去掉所有桥后得到边双分量，缩点得到桥森林。

**复杂度与条件：** O(n+m)时间与空间。

复用[割边完整板子](../%E5%89%B2%E8%BE%B9/%E6%A8%A1%E6%9D%BF.cpp)，同一算法定义只收录一次。

## 核心接口

- `run()`：先判桥再paint非桥边
- `bel[u]`：边双编号1..cnt
- `bcc`：分量成员表

## 例题 2：P2860 Redundant Paths

[原题](https://www.luogu.com.cn/problem/P2860)

**题意：** 最少加边让任意两点有两条边不重叠路径。

## 共同思路与易错点

- 桥树不是原图生成树，分量内可能有很多环。
- Redundant Paths保证连通；不连通情况不能直接套叶子公式。
